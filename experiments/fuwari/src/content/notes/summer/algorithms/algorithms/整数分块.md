设固定整数为 `x`，枚举范围为：

```text
1 <= k <= A
```

整数分块的核心是：

> 对于连续的一段 `k`，整数除法的结果完全相同，因此可以一次处理整个区间，不必逐个枚举。

常见的两种形式：

```text
floor(x / k)
ceil(x / k)
```

其中：

- `floor(x / k)` 表示向下取整；
    
- `ceil(x / k)` 表示向上取整。
    

---

<div id="section-1" class="note-anchor"></div>

## 一、向下取整整数分块

对下面的式子进行整数分块：

```text
floor(x / k)
```

<div id="section-2" class="note-anchor"></div>

### 1. 当前块左端点

设当前块左端点为 `l`。

当前块的值：

```text
q = floor(x / l)
```

因为 C++ 整数除法自动向下取整，所以代码是：

```cpp
int q=x/l;
```

---

<div id="section-3" class="note-anchor"></div>

### 2. 当前块右端点

希望求出最大的 `r`，使得对于任意：

```text
k ∈ [l,r]
```

都有：

```text
floor(x / k) = q
```

当 `q > 0` 时：

```text
r = floor(x / q)
```

代码：

```cpp
int r=x/q;
```

如果枚举范围最大为 `A`：

```cpp
r=min(r,A);
```

合起来：

```cpp
int r=min(A,x/q);
```

---

<div id="section-4" class="note-anchor"></div>

### 3. 为什么右端点是 x / q

当前商：

```text
q = floor(x / l)
```

为了让 `floor(x / k)` 仍然等于 `q`，需要满足：

```text
x / k >= q
```

移项得到：

```text
k <= x / q
```

所以最大的整数 `k` 是：

```text
r = floor(x / q)
```

<div id="section-5" class="note-anchor"></div>

#### 例子

设：

```text
x = 10
l = 4
```

当前商：

```text
q = floor(10 / 4) = 2
```

右端点：

```text
r = floor(10 / 2) = 5
```

检查：

```text
floor(10 / 4) = 2
floor(10 / 5) = 2
floor(10 / 6) = 1
```

所以当前块为：

```text
[4,5]
```

---

<div id="section-6" class="note-anchor"></div>

### 4. 当 q = 0 时

如果枚举范围 `A` 可能大于 `x`，那么当：

```text
l > x
```

时：

```text
q = floor(x / l) = 0
```

此时从 `l` 到 `A` 的商全部都是 `0`，所以：

```text
r = A
```

代码：

```cpp
if(q==0){
    r=A;
}
```

如果题目保证：

```text
A <= x
```

就不会出现 `q == 0`。

---

<div id="section-7" class="note-anchor"></div>

### 5. 向下取整分块模板

<div id="section-8" class="note-anchor"></div>

#### 通用模板

```cpp
for(int l=1;l<=A;){
    int q=x/l;
    int r;

    if(q==0){
        r=A;
    }
    else{
        r=min(A,x/q);
    }

    // 对区间 [l,r] 进行处理
    // 对任意 k∈[l,r]，都有 floor(x/k)=q

    l=r+1;
}
```

<div id="section-9" class="note-anchor"></div>

#### 保证 A <= x 时

```cpp
for(int l=1;l<=A;){
    int q=x/l;
    int r=min(A,x/q);

    // 对区间 [l,r] 进行处理
    // 对任意 k∈[l,r]，都有 floor(x/k)=q

    l=r+1;
}
```

---

<div id="section-10" class="note-anchor"></div>

### 6. 向下取整区间差分

如果区间 `[l,r]` 中每个位置统一增加：

```text
c * q
```

可以使用差分：

```cpp
d[l]+=c*q;
d[r+1]-=c*q;
```

最后求前缀和：

```cpp
for(int k=1;k<=A;k++){
    d[k]+=d[k-1];
}
```

---

<div id="section-11" class="note-anchor"></div>

### 7. 同时对两个向下取整式分块

有时需要同时保证：

```text
floor(x / k)
floor(y / k)
```

在同一个区间中保持不变。

当前块左端点为 `l`。

先计算当前两个商：

```text
qx = floor(x / l)
qy = floor(y / l)
```

代码：

```cpp
int qx=x/l;
int qy=y/l;
```

对于 `x`，当前商可以保持到：

```text
rx = floor(x / qx)
```

对于 `y`，当前商可以保持到：

```text
ry = floor(y / qy)
```

两个条件必须同时成立，所以：

```text
r = min(A,rx,ry)
```

代码：

```cpp
for(int l=1;l<=A;){
    int qx=x/l;
    int qy=y/l;

    int rx=x/qx;
    int ry=y/qy;

    int r=min({A,rx,ry});

    // 对任意 k∈[l,r]
    // floor(x/k)=qx
    // floor(y/k)=qy

    l=r+1;
}
```

也可以写成：

```cpp
for(int l=1;l<=A;){
    int r=min({
        A,
        x/(x/l),
        y/(y/l)
    });

    // 对区间 [l,r] 进行处理

    l=r+1;
}
```

第一种写法更容易理解。

---

<div id="section-12" class="note-anchor"></div>

### 8. 向下取整核心公式

```text
q = floor(x / l)

r = floor(x / q)    当 q > 0 时

q = 0               则 r = A

l = r + 1
```

## 二、向上取整整数分块

对下面的式子进行整数分块：

```text
ceil(x / k)
```

---

<div id="section-14" class="note-anchor"></div>

### 1. 当前块左端点

设当前块左端点为 `l`。

当前块的值：

```text
q = ceil(x / l)
```

正整数向上取整可以写成：

```text
ceil(x / l) = floor((x + l - 1) / l)
```

代码：

```cpp
int q=(x+l-1)/l;
```

---

<div id="section-15" class="note-anchor"></div>

### 2. 当前块右端点

当：

```text
q > 1
```

时，当前块右端点：

```text
r = floor((x - 1) / (q - 1))
```

代码：

```cpp
int r=(x-1)/(q-1);
```

如果枚举范围最大为 `A`：

```cpp
r=min(r,A);
```

合起来：

```cpp
int r=min(A,(x-1)/(q-1));
```

---

<div id="section-16" class="note-anchor"></div>

### 3. 为什么右端点是 (x - 1) / (q - 1)

当前块需要满足：

```text
ceil(x / k) = q
```

根据向上取整的定义：

```text
q - 1 < x / k <= q
```

为了寻找右端点，主要使用：

```text
q - 1 < x / k
```

移项得到：

```text
k < x / (q - 1)
```

因为 `k` 是整数，所以：

```text
k <= floor((x - 1) / (q - 1))
```

因此：

```text
r = floor((x - 1) / (q - 1))
```

---

<div id="section-17" class="note-anchor"></div>

### 4. 当 q = 1 时

如果：

```text
q = 1
```

说明：

```text
ceil(x / k) = 1
```

后面的所有 `k` 都属于当前块，所以：

```text
r = A
```

代码：

```cpp
if(q==1){
    r=A;
}
```

此时不能计算：

```cpp
(x-1)/(q-1)
```

因为 `q-1=0`，会出现除零。

---

<div id="section-18" class="note-anchor"></div>

### 5. 向上取整分块模板

```cpp
for(int l=1;l<=A;){
    int q=(x+l-1)/l;
    int r;

    if(q==1){
        r=A;
    }
    else{
        r=min(A,(x-1)/(q-1));
    }

    // 对区间 [l,r] 进行处理
    // 对任意 k∈[l,r]，都有 ceil(x/k)=q

    l=r+1;
}
```

---

<div id="section-19" class="note-anchor"></div>

### 6. 向上取整区间差分

如果区间 `[l,r]` 中每个位置统一增加：

```text
c * q
```

使用差分：

```cpp
d[l]+=c*q;
d[r+1]-=c*q;
```

最后求前缀和：

```cpp
for(int k=1;k<=A;k++){
    d[k]+=d[k-1];
}
```

---

<div id="section-20" class="note-anchor"></div>

### 7. 向上取整核心公式

```text
q = ceil(x / l)
  = floor((x + l - 1) / l)

r = floor((x - 1) / (q - 1))    当 q > 1 时

q = 1                            则 r = A

l = r + 1
```

---

<div id="section-21" class="note-anchor"></div>

## 三、向下取整与向上取整对比

|类型|当前块值|当前块右端点|特殊情况|
|---|---|---|---|
|向下取整|`q=x/l`|`r=x/q`|`q=0` 时，`r=A`|
|向上取整|`q=(x+l-1)/l`|`r=(x-1)/(q-1)`|`q=1` 时，`r=A`|

代码对比：

```cpp
// 向下取整
int q=x/l;
int r=(q==0?A:min(A,x/q));
```

```cpp
// 向上取整
int q=(x+l-1)/l;
int r=(q==1?A:min(A,(x-1)/(q-1)));
```

## 四、为什么分块数量是 O(sqrt(x))

以向下取整为例。

当：

```text
k <= sqrt(x)
```

时，`k` 的数量最多为 `sqrt(x)`。

当：

```text
k > sqrt(x)
```

时：

```text
floor(x / k) < sqrt(x)
```

此时商的不同取值最多也只有 `sqrt(x)` 个。

因此总块数为：

```text
O(sqrt(x))
```

向上取整的分块数量同样为：

```text
O(sqrt(x))
```

## 五、记忆方式

<div id="section-24" class="note-anchor"></div>

### 向下取整

```cpp
q=x/l;
r=x/q;
```

记忆：

> 当前商是 `q`，这个商能保持到 `x/q`。

<div id="section-25" class="note-anchor"></div>

### 向上取整

```cpp
q=(x+l-1)/l;
r=(x-1)/(q-1);
```

记忆：

> 当前向上取整结果是 `q`，需要满足 `x/k > q-1`，所以右端点是 `(x-1)/(q-1)`。

<div id="section-26" class="note-anchor"></div>

### 统一流程

```cpp
for(int l=1;l<=A;){
    // 计算当前块的值 q
    // 计算当前块的右端点 r
    // 一次处理整个区间 [l,r]

    l=r+1;
}
```

整数分块的本质：

```text
把连续且整数除法结果相同的位置合并处理。
```
