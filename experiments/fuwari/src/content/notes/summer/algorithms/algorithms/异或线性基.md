> **线性基解决什么问题？**
> 给你一组整数，可以从中任选若干个数进行异或，求能够得到的最大异或值。
>
> 例如：
>
> ```text
> 数组：1，2，4
> ```
>
> 可以选择全部三个数：
>
> ```text
> 1 XOR 2 XOR 4 = 7
> ```
>
> 因此最大子集异或值为 `7`。

---

<div id="section-1" class="note-anchor"></div>

## 一、学习线性基前，需要掌握什么

只需要知道异或的基本性质。

<div id="section-2" class="note-anchor"></div>

### 1. 异或规则

```text
0 XOR 0 = 0
0 XOR 1 = 1
1 XOR 0 = 1
1 XOR 1 = 0
```

可以记成：

```text
相同为 0，不同为 1
```

例如：

```text
5 = 101
3 = 011
---------
    110 = 6
```

所以：

```text
5 XOR 3 = 6
```

---

<div id="section-3" class="note-anchor"></div>

### 2. 一个数异或自己等于 0

```text
x XOR x = 0
```

例如：

```text
101 XOR 101 = 000
```

这个性质在线性基里非常重要，因为我们会用一个数去“消掉”另一个数的最高位。

---

<div id="section-4" class="note-anchor"></div>

### 3. 一个数异或 0 不变

```text
x XOR 0 = x
```

---

<div id="section-5" class="note-anchor"></div>

### 4. 异或满足交换律和结合律

```text
a XOR b = b XOR a
```

```text
(a XOR b) XOR c = a XOR (b XOR c)
```

所以从数组中选择若干个数时，异或顺序并不重要。

---

<div id="section-6" class="note-anchor"></div>

## 二、线性基到底解决什么问题

给定数组：

```text
a[1], a[2], ..., a[n]
```

我们可以任选若干个数，求它们的异或值。

例如：

```text
数组：3，5，6
```

可以得到：

```text
不选任何数：0
只选 3：3
只选 5：5
只选 6：6
选择 3、5：3 XOR 5 = 6
选择 3、6：3 XOR 6 = 5
选择 5、6：5 XOR 6 = 3
选择 3、5、6：0
```

所有可能的异或结果只有：

```text
0，3，5，6
```

虽然数组有三个数，但 `6` 可以由：

```text
3 XOR 5 = 6
```

得到。

所以 `6` 没有提供新的异或结果，它是一个“多余”的数。

线性基的作用就是：

> 从原数组中保留少量关键数字，使这些关键数字能够组合出原数组的所有子集异或结果。

---

<div id="section-7" class="note-anchor"></div>

## 三、什么叫“线性无关”

不需要先学习线性代数，可以直接这样理解。

<div id="section-8" class="note-anchor"></div>

### 1. 可以被已有数字异或出来

假设我们已经保存了：

```text
3，5
```

现在来了一个数：

```text
6
```

因为：

```text
3 XOR 5 = 6
```

所以 `6` 可以由已有数字异或得到。

这种数是“可以被表示的”，不需要再次保存。

---

<div id="section-9" class="note-anchor"></div>

### 2. 不能被已有数字异或出来

假设我们已经保存了：

```text
3，5
```

现在来了一个数：

```text
4
```

已有数字能够得到：

```text
0
3
5
3 XOR 5 = 6
```

不能得到 `4`。

所以 `4` 提供了新的信息，需要把它加入线性基。

---

> **简单理解**
>
> - 能被已有数字异或出来：多余，不加入。
> - 不能被已有数字异或出来：有用，加入。
> - 线性基保存的就是一组互相不能表示的关键数字。

---

<div id="section-10" class="note-anchor"></div>

## 四、线性基长什么样

假设数字不超过 `2^30`，我们建立：

```cpp
long long basis[30];
```

其中：

```text
basis[i]
```

表示：

> 最高的二进制 `1` 位在第 `i` 位的线性基元素。

例如：

```text
basis[4] = 10110
```

这个数的最高位 `1` 在第 `4` 位。

注意二进制位从右往左编号：

```text
二进制：1 0 1 1 0
位编号：4 3 2 1 0
```

---

<div id="section-11" class="note-anchor"></div>

### 为什么要按照最高位保存

因为一个二进制数的高位比所有低位都重要。

例如：

```text
1000 = 8
0111 = 7
```

只要第 `3` 位是 `1`，这个数就一定大于所有第 `3` 位为 `0` 的数。

所以线性基处理数字时，要从最高位开始。

---

<div id="section-12" class="note-anchor"></div>

## 五、线性基最核心的操作：插入

假设要把数字 `x` 插入线性基。

我们从最高位向最低位检查。

---

<div id="section-13" class="note-anchor"></div>

### 情况一：x 的当前位是 0

这一位不用处理，继续检查更低位。

```cpp
if (((x >> i) & 1) == 0) {
    continue;
}
```

---

<div id="section-14" class="note-anchor"></div>

### 情况二：x 的当前位是 1，basis[i] 为空

说明当前还没有最高位为 `i` 的基底。

直接把 `x` 放进去：

```cpp
basis[i] = x;
return;
```

---

<div id="section-15" class="note-anchor"></div>

### 情况三：x 的当前位是 1，basis[i] 已经有数

因为：

```text
x 的第 i 位是 1
basis[i] 的第 i 位也是 1
```

两者异或以后：

```text
1 XOR 1 = 0
```

所以可以使用：

```cpp
x ^= basis[i];
```

把 `x` 的第 `i` 位消掉。

然后继续处理更低位。

---

<div id="section-16" class="note-anchor"></div>

## 六、手动模拟一次插入

插入数组：

```text
3，5，6
```

它们的二进制是：

```text
3 = 011
5 = 101
6 = 110
```

---

<div id="section-17" class="note-anchor"></div>

### 第一步：插入 3

```text
3 = 011
```

最高位 `1` 在第 `1` 位。

当前：

```text
basis[1] = 0
```

所以直接放进去：

```text
basis[1] = 3
```

现在：

```text
basis[2] = 0
basis[1] = 3 = 011
basis[0] = 0
```

---

<div id="section-18" class="note-anchor"></div>

### 第二步：插入 5

```text
5 = 101
```

最高位 `1` 在第 `2` 位。

当前：

```text
basis[2] = 0
```

所以：

```text
basis[2] = 5
```

现在：

```text
basis[2] = 5 = 101
basis[1] = 3 = 011
basis[0] = 0
```

---

<div id="section-19" class="note-anchor"></div>

### 第三步：插入 6

```text
6 = 110
```

先检查第 `2` 位。

```text
6 的第 2 位是 1
basis[2] = 5
```

因此异或：

```text
6 XOR 5
= 110 XOR 101
= 011
= 3
```

现在 `x` 变成：

```text
x = 3 = 011
```

继续检查第 `1` 位。

```text
x 的第 1 位是 1
basis[1] = 3
```

继续异或：

```text
3 XOR 3 = 0
```

最终：

```text
x = 0
```

这说明原来的 `6` 可以由已有线性基表示：

```text
6 = 3 XOR 5
```

所以不需要把 `6` 加入线性基。

<div id="section-20" class="note-anchor"></div>

## 七、插入代码模板

```cpp
const int MAX_BIT = 62;

long long basis[MAX_BIT + 1];

void insertBasis(long long x) {
    // 从最高位向最低位处理
    for (int i = MAX_BIT; i >= 0; i--) {

        // x 的第 i 位是 0，不需要处理
        if (((x >> i) & 1LL) == 0) {
            continue;
        }

        // 当前没有最高位为 i 的基底
        if (basis[i] == 0) {
            basis[i] = x;
            return;
        }

        // 当前位已经有基底，用它消掉 x 的第 i 位
        x ^= basis[i];
    }

    // 如果最后 x 变成 0，
    // 说明原来的 x 可以由已有线性基表示
}
```

如果题目中的数字满足：

```text
a[i] < 2^30
```

也可以只开 30 位：

```cpp
const int MAX_BIT = 29;
```

---

<div id="section-21" class="note-anchor"></div>

## 八、为什么必须从高位往低位处理

假设：

```text
x = 11010
```

它的最高位是第 `4` 位。

我们首先要决定能不能消掉第 `4` 位。

如果可以消掉，`x` 才会变成一个更小的数，再继续处理下面的位。

整个过程类似：

```text
11010
↓ 消掉第 4 位
01001
↓ 消掉第 3 位
00110
↓ 继续处理
```

每次都让最高位不断降低。

如果从低位开始，就不能保证线性基拥有清晰的“最高位结构”，后面也很难贪心求最大值。

---

<div id="section-22" class="note-anchor"></div>

## 九、如何用线性基求最大子集异或

线性基建立完成后，从最高位往最低位遍历。

初始：

```text
ans = 0
```

对于每个 `basis[i]`，比较：

```text
ans
```

和：

```text
ans XOR basis[i]
```

谁更大。

代码为：

```cpp
ans = max(ans, ans ^ basis[i]);
```

完整代码：

```cpp
long long queryMax() {
    long long ans = 0;

    for (int i = MAX_BIT; i >= 0; i--) {
        ans = max(ans, ans ^ basis[i]);
    }

    return ans;
}
```

## 十、手动模拟最大异或

线性基中有：

```text
basis[2] = 5 = 101
basis[1] = 3 = 011
```

初始：

```text
ans = 0 = 000
```

---

<div id="section-24" class="note-anchor"></div>

### 第一步：处理 basis[2]

比较：

```text
ans = 000 = 0
```

和：

```text
ans XOR basis[2]
= 000 XOR 101
= 101
= 5
```

选择更大的：

```text
ans = 5
```

---

<div id="section-25" class="note-anchor"></div>

### 第二步：处理 basis[1]

比较：

```text
ans = 101 = 5
```

和：

```text
ans XOR basis[1]
= 101 XOR 011
= 110
= 6
```

因为：

```text
6 > 5
```

所以：

```text
ans = 6
```

最终最大子集异或值为：

```text
6
```

---

<div id="section-26" class="note-anchor"></div>

## 十一、为什么这样贪心是正确的

关键原因是：

```text
basis[i] 的最高位是第 i 位
```

当我们处理第 `i` 位时，`basis[i]` 不会影响任何比 `i` 更高的二进制位。

因此，之前已经确定的更高位不会被破坏。

例如当前处理第 `4` 位：

```text
如果能让答案第 4 位从 0 变成 1，
就一定应该变成 1。
```

因为：

```text
第 4 位的价值 = 16
所有低位总和最多 = 15
```

所以一个更高位的 `1`，比所有低位全部为 `1` 都更大。

这就是从高位到低位贪心的原因。

<div id="section-27" class="note-anchor"></div>

## 十二、完整入门代码

下面的程序求一个数组的最大子集异或值。

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

const int MAX_BIT = 62;

ll basis[MAX_BIT + 1];

// 插入一个数字
void insertBasis(ll x) {
    for (int i = MAX_BIT; i >= 0; i--) {

        // x 的第 i 位不是 1
        if (((x >> i) & 1LL) == 0) {
            continue;
        }

        // 当前位还没有基底
        if (basis[i] == 0) {
            basis[i] = x;
            return;
        }

        // 使用已有基底消掉 x 的当前最高位
        x ^= basis[i];
    }
}

// 查询最大子集异或值
ll queryMax() {
    ll ans = 0;

    for (int i = MAX_BIT; i >= 0; i--) {
        ans = max(ans, ans ^ basis[i]);
    }

    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    for (int i = 1; i <= n; i++) {
        ll x;
        cin >> x;

        insertBasis(x);
    }

    cout << queryMax() << '\n';

    return 0;
}
```

## 十五、判断一个数能不能被表示

假设已经建立线性基，现在想判断数字 `x` 能不能由原数组中的若干个数异或得到。

做法与插入几乎相同：

```cpp
bool canRepresent(long long x) {
    for (int i = MAX_BIT; i >= 0; i--) {
        if (((x >> i) & 1LL) == 0) {
            continue;
        }

        if (basis[i] == 0) {
            return false;
        }

        x ^= basis[i];
    }

    return true;
}
```

如果最后可以消成 `0`，说明能够表示。

例如线性基中有：

```text
3，5
```

判断 `6`：

```text
6 XOR 5 = 3
3 XOR 3 = 0
```

所以 `6` 可以表示。

## 十六、线性基的秩

线性基中非零元素的数量，叫作线性基的秩。

代码：

```cpp
int rank = 0;

for (int i = 0; i <= MAX_BIT; i++) {
    if (basis[i] != 0) {
        rank++;
    }
}
```

如果秩为 `rank`，能够得到的不同异或结果数量为：

```text
2^rank
```

为什么？

因为每一个线性基元素都有两种状态：

```text
选择
不选择
```

一共有 `rank` 个线性基元素，所以方案数量为：

```text
2 * 2 * ... * 2
= 2^rank
```

而且因为这些元素互相独立，不同选择方案得到的异或值也不同。

<div id="section-32" class="note-anchor"></div>

## 十七、线性基和 01 Trie 的区别

| 数据结构 | 选择对象 | 典型问题 |
|---|---|---|
| 01 Trie | 从集合中选择一个真实存在的数 | 求 `x XOR a[i]` 的最大值 |
| 线性基 | 从集合中任选若干个数异或 | 求最大子集异或值 |

例如数组：

```text
1，2，4
```

使用 01 Trie，只能从原数组中选择一个数：

```text
1
2
4
```

使用线性基，可以选择多个数：

```text
1 XOR 2 XOR 4 = 7
```

所以一定要记住：

```text
01 Trie：选择一个数和 x 异或。

线性基：选择任意多个数互相异或。
```

## 十八、什么时候应该想到线性基

看到下面这些关键词时，可以考虑线性基。

<div id="section-34" class="note-anchor"></div>

### 类型一：最大子集异或

```text
从数组中任选若干个数，使异或和最大。
```

这是最标准的线性基题。

---

<div id="section-35" class="note-anchor"></div>

### 类型二：判断某个异或值能否得到

```text
能否选择若干个数，使异或结果等于 x？
```

建立线性基后，将 `x` 消元即可。

---

<div id="section-36" class="note-anchor"></div>

### 类型三：求不同子集异或值的数量

如果线性基的秩是 `rank`：

```text
不同异或结果数量 = 2^rank
```

---

<div id="section-37" class="note-anchor"></div>

### 类型四：分组后最大化异或相关结果

例如把数组分成两组。

设第一组异或为：

```text
x
```

所有数总异或为：

```text
s
```

那么第二组异或一定为：

```text
s XOR x
```

如果最后能把问题转化为：

```text
任选若干个数，使它们的异或值最大
```

就可以使用线性基。

---

<div id="section-38" class="note-anchor"></div>

## 十九、刚才那道分组题为什么使用线性基

设两组异或值分别为：

```text
x，y
```

所有数总异或为：

```text
s
```

因为每个数恰好进入一个集合，所以：

```text
x XOR y = s
```

因此：

```text
y = s XOR x
```

目标：

```text
最大化 x + y
```

利用公式：

```text
x + y = (x XOR y) + 2 * (x AND y)
```

得到：

```text
x + y = s + 2 * (x AND y)
```

只有 `s` 中为 `0` 的二进制位，才可能同时出现在 `x` 和 `y` 中。

因此把每个数处理为：

```text
a[i] & (~s)
```

然后从这些数中任选若干个，使异或值最大。

这就是：

```text
最大子集异或
```

所以使用线性基。

核心代码：

```cpp
ll totalXor = 0;

for (ll x : a) {
    totalXor ^= x;
}

ll mask = ((1LL << 30) - 1) ^ totalXor;

for (ll x : a) {
    insertBasis(x & mask);
}

ll best = queryMax();

ll answer = totalXor + 2 * best;
```

## 二十、常见错误

<div id="section-40" class="note-anchor"></div>

### 错误一：从低位向高位插入

错误：

```cpp
for (int i = 0; i <= MAX_BIT; i++)
```

正确：

```cpp
for (int i = MAX_BIT; i >= 0; i--)
```

因为我们需要优先处理最高位。

---

<div id="section-41" class="note-anchor"></div>

### 错误二：多个测试用例没有清空线性基

每个测试用例开始前需要：

```cpp
memset(basis, 0, sizeof basis);
```

否则前一个测试用例的数据会影响后面的答案。

---

<div id="section-42" class="note-anchor"></div>

### 错误三：把异或写成加法

错误：

```cpp
x += basis[i];
```

正确：

```cpp
x ^= basis[i];
```

线性基处理的是异或关系，不是普通加法。

---

<div id="section-43" class="note-anchor"></div>

### 错误四：位数范围开小

如果：

```text
a[i] < 2^30
```

最高位是第 `29` 位。

可以写：

```cpp
for (int i = 29; i >= 0; i--)
```

如果数据可能达到 `10^18`，应该处理到第 `60` 位左右。

通用写法：

```cpp
const int MAX_BIT = 62;
```

---

<div id="section-44" class="note-anchor"></div>

### 错误五：不理解 x 变成 0 的意义

插入过程中，如果：

```text
x = 0
```

不是程序出错。

它表示：

> 原来的数字可以由已有线性基中的数字异或得到。

因此它是冗余数字，不需要加入。

## 二十一、时间复杂度

设数字有 `B` 个二进制位。

插入一个数最多检查 `B` 位：

```text
O(B)
```

插入 `n` 个数：

```text
O(nB)
```

对于 `long long`：

```text
B 大约是 63
```

所以可以看成：

```text
O(63n)
```

基本接近线性复杂度。

线性基数组只需要保存大约 63 个数：

```text
空间复杂度 O(B)
```

## 二十二、线性基万能基础模板

```cpp
struct LinearBasis {
    static const int MAX_BIT = 62;

    long long basis[MAX_BIT + 1];

    LinearBasis() {
        clear();
    }

    void clear() {
        memset(basis, 0, sizeof basis);
    }

    // 插入一个数
    bool insert(long long x) {
        for (int i = MAX_BIT; i >= 0; i--) {
            if (((x >> i) & 1LL) == 0) {
                continue;
            }

            if (basis[i] == 0) {
                basis[i] = x;
                return true;
            }

            x ^= basis[i];
        }

        return false;
    }

    // 最大子集异或值
    long long getMax() {
        long long ans = 0;

        for (int i = MAX_BIT; i >= 0; i--) {
            ans = max(ans, ans ^ basis[i]);
        }

        return ans;
    }

    // 判断 x 能不能被表示
    bool canRepresent(long long x) {
        for (int i = MAX_BIT; i >= 0; i--) {
            if (((x >> i) & 1LL) == 0) {
                continue;
            }

            if (basis[i] == 0) {
                return false;
            }

            x ^= basis[i];
        }

        return true;
    }

    // 返回线性基的秩
    int getRank() {
        int rank = 0;

        for (int i = 0; i <= MAX_BIT; i++) {
            if (basis[i] != 0) {
                rank++;
            }
        }

        return rank;
    }
};
```

使用：

```cpp
LinearBasis lb;

lb.insert(3);
lb.insert(5);
lb.insert(4);

cout << lb.getMax() << '\n';
```

输出：

```text
7
```

## 二十四、最核心总结

<div id="section-50" class="note-anchor"></div>

### 线性基是什么

```text
保留一组关键数字，
使它们能够组合出原数组的所有子集异或结果。
```

<div id="section-51" class="note-anchor"></div>

### 如何插入

```text
从最高位向最低位检查。

当前位为空：
    把 x 放进去。

当前位已有基底：
    x XOR basis[i]，消掉当前位。

最后 x = 0：
    x 可以被已有线性基表示。
```

<div id="section-52" class="note-anchor"></div>

### 如何求最大异或

```text
从最高位向最低位遍历：

ans = max(ans, ans XOR basis[i])
```

<div id="section-53" class="note-anchor"></div>

### 与 01 Trie 的区别

```text
01 Trie：选择一个原数组中的数。

线性基：选择任意多个数进行异或。
```

---

> **一句话记忆**
>
> 线性基就是“异或版本的高斯消元”：
>
> ```text
> 每个最高位只保留一个代表，
> 用已有代表消掉新数字的最高位，
> 最后从高位到低位贪心得到最大异或值。
> ```
