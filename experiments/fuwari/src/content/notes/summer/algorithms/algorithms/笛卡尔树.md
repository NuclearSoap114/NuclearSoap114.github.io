Cartesian Tree

> **笔记定位  **
> **类型：** 算法知识点笔记  
> **前置知识：** 二叉树、堆、单调栈  
> **一句话定位：** 用一棵二叉树保存数组的原始顺序与区间最值之间的递归关系。

---

<div id="section-1" class="note-anchor"></div>

### 抽象问题

给定一个数组，希望把其中的“区间最大值 / 最小值关系”组织成一棵树，同时不能破坏原数组的左右顺序。

笛卡尔树要求：

1. 中序遍历等于原数组顺序；
    
2. 同时满足堆性质。
    

---

<div id="section-2" class="note-anchor"></div>

### 一句话本质

> **笛卡尔树就是把“区间最值不断把区间分成左右两部分”的递归结构显式建成一棵树。**

对于大根笛卡尔树：

> 每棵子树的根，都是这棵子树对应连续区间中的最大值。

---

<div id="section-3" class="note-anchor"></div>

## 核心定义

对于数组

```
a[1], a[2], ..., a[n]
```

每个位置对应树上的一个节点。

笛卡尔树同时满足两个性质。

<div id="section-4" class="note-anchor"></div>

#### 1. 中序遍历保持原数组顺序

```
左子树 -> 根 -> 右子树
```

得到的节点顺序恰好是：

```
1, 2, 3, ..., n
```

因此树上的一棵子树对应原数组中的一个**连续区间**。

<div id="section-5" class="note-anchor"></div>

#### 2. 满足堆性质

大根笛卡尔树：

```
父节点值 > 子节点值
```

小根笛卡尔树：

```
父节点值 < 子节点值
```

如果数组元素互不相同，则笛卡尔树唯一。

---

<div id="section-6" class="note-anchor"></div>

## 从朴素思路到关键转折

最直观的构造方式是递归。

以大根笛卡尔树为例：

1. 找整个区间最大值；
    
2. 最大值作为根；
    
3. 左半部分递归成为左子树；
    
4. 右半部分递归成为右子树。
    

例如：

```
a = [4,5,3,6,2,1]
```

整个数组最大值为 `6`：

```
4 5 3 | 6 | 2 1
```

所以：

```
        6
       / \
 [4,5,3] [2,1]
```

左边最大值为 `5`，右边最大值为 `2`：

```
        6
       / \
      5   2
     / \   \
    4   3   1
```

问题在于：

> 如果每次都在线性扫描当前区间寻找最大值，最坏情况下复杂度达到 (O(n^2))。

例如：

```
1 2 3 4 5 6 ...
```

每次最大值都在端点。

真正的转折是：

> **构造过程中真正需要知道的，其实是当前元素左侧哪些元素会被它“压到下面”。**

这个关系可以使用单调栈维护，于是建树降为：

[  
O(n)  
]

---

<div id="section-7" class="note-anchor"></div>

## 本笔记最值得迁移的东西

<div id="section-8" class="note-anchor"></div>

### 1. 区间最值递归可以转化成树结构

当问题反复出现：

```
找到当前区间最大值
↓
把区间分成左边和右边
↓
继续对子区间处理
```

不要每次真的递归扫描最大值。

可以考虑：

> **一次性建立笛卡尔树，把所有区间最值之间的包含关系预先组织起来。**

例如：

```
4 5 3 6 2 1
```

变成：

```
        6
       / \
      5   2
     / \   \
    4   3   1
```

以后所有“最大值 → 左右子区间”的递归，都可以变成树上的：

```
父节点 -> 左右儿子
```

<div id="section-9" class="note-anchor"></div>

#### 识别信号

当看到：

- 最大值把区间分成两部分；
    
- 对左右区间继续执行相同操作；
    
- 每个元素和左右第一个更大元素有关；
    

可以主动想到笛卡尔树。

---

<div id="section-10" class="note-anchor"></div>

### 2. 单调栈弹出的不是“没用了”，而是在确定父子关系

这是构造中最重要的理解。

处理当前节点 `i`：

```
while(!st.empty() && a[st.top()] < a[i]){
    last = st.top();
    st.pop();
}
```

对于大根笛卡尔树，栈维护值单调递减。

连续被弹出的节点并不是直接丢弃。

最后一个被弹出的：

```
last
```

代表：

> 被当前节点 `i` 整体压到左下方的那棵子树的根。

因此：

```
ls[i] = last;
```

例如处理：

```
4 5 3 6
```

在 `6` 出现前已经形成：

```
  5
 / \
4   3
```

栈中：

```
5 3
```

处理 `6`：

```
弹 3
弹 5
```

最终：

```
last = 5
```

所以：

```
    6
   /
  5
 / \
4   3
```

而不是让 `3` 成为 `6` 的左儿子。

<div id="section-11" class="note-anchor"></div>

#### 最容易错的地方

`last` 必须在每轮处理新元素时：

```
int last = 0;
```

重新初始化。

---

<div id="section-12" class="note-anchor"></div>

### 3. 弹栈结束后的栈顶与当前节点形成另一条父子关系

弹完以后，如果：

```
!st.empty()
```

说明：

```
a[st.top()] > a[i]
```

并且 `st.top()` 是当前节点左边最合适的更大祖先。

由于当前节点在它右侧，因此：

```
rs[st.top()] = i;
```

所以构造可以压缩成两句话：

```
最后被弹出的节点
    -> 当前节点的左儿子

弹完以后剩下的栈顶
    -> 当前节点的父亲
    -> 当前节点成为它的右儿子
```

这是单调栈建笛卡尔树最值得记住的部分。

---

<div id="section-13" class="note-anchor"></div>

## 为什么单调栈构造正确

仍以大根笛卡尔树为例。

处理 `a[i]` 时，栈内满足：

```
a[st[0]] > a[st[1]] > ... > a[st.top()]
```

<div id="section-14" class="note-anchor"></div>

#### 情况一：弹出了一些节点

这些节点全部：

```
< a[i]
```

又因为它们都出现在 `i` 左边，所以如果它们仍属于当前新形成的子树，只能位于 `i` 的左子树中。

最后一个被弹出的节点是这些节点当前形成子树的根，因此：

```
ls[i] = last;
```

<div id="section-15" class="note-anchor"></div>

#### 情况二：弹完以后栈非空

此时：

```
a[st.top()] > a[i]
```

因此 `i` 不能成为它的祖先。

同时 `i` 在它右侧，所以按照中序遍历顺序，`i` 应进入它的右子树。

当前 `i` 又是右侧最新、最靠近它的合法节点，因此：

```
rs[st.top()] = i;
```

这样既保持：

```
父 > 子
```

又保持：

```
中序遍历 = 原数组顺序
```

两个条件同时满足，因此得到正确的大根笛卡尔树。

## 与最近更大元素的关系

对于大根笛卡尔树中的节点 `i`：

寻找：

```
L = 左边第一个比 a[i] 大的元素
R = 右边第一个比 a[i] 大的元素
```

如果两者都存在，那么父亲是：

> `L`、`R` 中值较小的那个。

例如：

```
4 5 3 6
    ↑
    3
```

对于 `3`：

```
左边最近更大 = 5
右边最近更大 = 6
```

因为：

```
5 < 6
```

所以：

```
father[3] = 5
```

因此看到：

> “每个元素左右第一个更大 / 更小元素”

也应该联想到笛卡尔树。

<div id="section-24" class="note-anchor"></div>

## 重要性质

<div id="section-25" class="note-anchor"></div>

### 子树对应连续区间

由于中序遍历就是原数组顺序：

> 每个节点的整棵子树一定对应原数组的一段连续区间。

---

<div id="section-26" class="note-anchor"></div>

### 子树根就是区间最值

大根笛卡尔树：

> 子树根 = 对应区间最大值。

小根笛卡尔树：

> 子树根 = 对应区间最小值。

---

<div id="section-27" class="note-anchor"></div>

### 区间 RMQ 与 LCA

对于大根笛卡尔树：

```
区间 [l,r] 最大值
```

对应：

```
笛卡尔树中节点 l 与 r 的 LCA
```

因为它是同时覆盖 `l,r` 的最深区间最大值节点。

因此笛卡尔树可以把：

```
RMQ
```

转化为：

```
LCA
```

---

<div id="section-28" class="note-anchor"></div>

## 大根与小根

<div id="section-29" class="note-anchor"></div>

#### 大根笛卡尔树

```
while(!st.empty() && a[st.top()] < a[i])
```

维护：

```
单调递减栈
```

每个区间：

```
最大值为根
```

---

<div id="section-30" class="note-anchor"></div>

#### 小根笛卡尔树

改成：

```
while(!st.empty() && a[st.top()] > a[i])
```

维护：

```
单调递增栈
```

每个区间：

```
最小值为根
```

两者本质完全相同，只是比较方向相反。

---

<div id="section-31" class="note-anchor"></div>

## 复杂度

每个节点：

```
入栈一次
出栈最多一次
```

所以虽然代码中存在：

```
while(...)
```

但所有 `while` 的总执行次数最多为 (n)。

因此：

[  
T(n)=O(n)  
]

树本身需要：

```
ls[n]
rs[n]
```

所以：

[  
S(n)=O(n)  
]

相比递归寻找区间最值的最坏：

[  
O(n^2)  
]

单调栈消除了对子区间反复寻找最大值的重复工作。

## 识别信号

以后遇到下面的结构，可以考虑笛卡尔树：

<div id="section-33" class="note-anchor"></div>

#### 信号 1

当：

> 当前区间的最大值 / 最小值把问题分成左右两个子问题。

---

<div id="section-34" class="note-anchor"></div>

#### 信号 2

当：

> 问题需要反复处理“区间最大值 → 左右剩余区间”。

---

<div id="section-35" class="note-anchor"></div>

#### 信号 3

当：

> 每个元素和左右最近的更大 / 更小元素关系很重要。

---

<div id="section-36" class="note-anchor"></div>

#### 信号 4

当：

> 原数组的相对位置不能改变，同时又存在明显的堆式大小关系。

---

<div id="section-37" class="note-anchor"></div>

#### 信号 5

当：

> 一个看起来是区间递归的问题，希望转化成树上 DP、最长链、子树统计等问题。

常见思维路线：

```
区间最值递归
    ↓
最大值把区间一分为二
    ↓
形成天然父子关系
    ↓
笛卡尔树
```

---

<div id="section-38" class="note-anchor"></div>

## 适用边界

<div id="section-39" class="note-anchor"></div>

### 元素存在相等值

如果数组存在相同值：

```
2 2 3
```

笛卡尔树不再天然唯一。

必须明确规定：

```
< 还是 <=
```

也就是相同元素之间谁作为祖先。

不同写法可能生成不同的树。

---

<div id="section-40" class="note-anchor"></div>

### 不是所有“最近更大”问题都需要建树

如果题目只要求：

```
每个元素左边第一个更大元素
```

直接单调栈即可。

只有当：

> 这些最近更大关系形成的层次结构本身有用

时，才有必要显式建立笛卡尔树。

---

<div id="section-41" class="note-anchor"></div>

### 极度退化时注意递归深度

例如：

```
1 2 3 4 5 ...
```

大根笛卡尔树会退化成一条链。

树高可能达到：

[  
O(n)  
]

如果：

```
n = 5e5
```

递归 DFS 可能爆栈。

实际竞赛中应考虑：

- 非递归 DFS；
    
- BFS；
    
- 建树过程中直接维护答案；
    
- 或其他避免深递归的方法。
    

---

<div id="section-42" class="note-anchor"></div>

## 本次学习过程中真正暴露的问题

最开始已经想到：

> “维护每个元素左右第一个比它大的元素。”

这说明已经注意到了单调栈结构。

但当时仍把这些关系理解成：

> 每个位置独立进行局部决策。

没有进一步发现：

> 左右最近更大关系实际上可以形成一个完整的父子层次，而这个层次正是区间最大值递归结构。

因此以后遇到单调栈题时，可以多问一步：

> **我现在算出的最近更大 / 更小关系，只是答案本身，还是实际上形成了一棵树？**

这是从“会单调栈”进一步走向“识别笛卡尔树”的关键。

---

<div id="section-43" class="note-anchor"></div>

## 实现最容易错的地方

<div id="section-44" class="note-anchor"></div>

#### 1. 栈中存下标，不是值

应该：

```
st.push(i);
```

比较：

```
a[st.top()]
```

因为之后需要建立：

```
ls[i]
rs[i]
```

这些都是节点编号。

---

<div id="section-45" class="note-anchor"></div>

#### 2. `last` 每轮重新初始化

```
rep(i,1,n){
    int last = 0;
}
```

不能放在循环外沿用。

---

<div id="section-46" class="note-anchor"></div>

#### 3. 两条边的方向不要写反

大根树：

```
if(!st.empty()) rs[st.top()] = i;

if(last) ls[i] = last;
```

记忆方式：

```
剩下的栈顶在当前元素左边
→ 当前元素成为它的右儿子

被弹出的整棵结构也在当前元素左边
→ 它成为当前元素的左子树
```

---

<div id="section-47" class="note-anchor"></div>

#### 4. 多组数据必须清空儿子数组

至少：

```
ls[i] = rs[i] = 0;
```

否则上一组数据的边可能残留。

---

<div id="section-48" class="note-anchor"></div>

#### 5. 递归 DFS 可能爆栈

笛卡尔树并不保证平衡。

最坏树高：

[  
O(n)  
]

不能把它当普通平衡树使用。

## 复习时反问

1. 为什么“区间最大值作为根，左右区间递归”一定同时保证堆性质和中序遍历等于原数组？
    
2. 单调栈构造时，为什么是**最后一个被弹出的节点**成为当前节点的左儿子，而不是第一个被弹出的节点？
    
3. 为什么弹栈结束后的栈顶可以成为当前节点的父亲？它和“左右最近更大元素”有什么联系？
    
4. 如果把比较条件从 `<` 改成 `<=`，当数组存在相等元素时，生成的笛卡尔树结构会发生什么变化？

## 完整代码

大根笛卡尔树模板：

```
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define rep(i,l,r) for(int i=(l);i<=(r);i++)
#define rep_(i,l,r) for(int i=(l);i>=(r);i--)
#define pii pair<int,int>
#define V vector
#define F first
#define S second
#define pb push_back
#define is insert
const int inf = 1LL << 62,N = 5e5 + 10;
const double pi = acos(-1);
// --------------- AC ---------------
int n,a[N],ls[N],rs[N];

void build(){
    stack<int> st;

    rep(i,1,n){
        ls[i] = rs[i] = 0;

        int last = 0;

        while(!st.empty() && a[st.top()] < a[i]){
            last = st.top();
            st.pop();
        }

        if(!st.empty()){
            rs[st.top()] = i;
        }

        if(last){
            ls[i] = last;
        }

        st.push(i);
    }
}

signed main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;

    rep(i,1,n){
        cin >> a[i];
    }

    build();

    return 0;
}
```

> **最后只记三句话**
> 
> 1. **大根笛卡尔树 = 区间最大值作为根，左右区间递归。**
>     
> 2. **最后一个被弹出的节点 → 当前节点左儿子。**
>     
> 3. **弹完后的栈顶 → 当前节点父亲，当前节点成为它的右儿子。**
>
