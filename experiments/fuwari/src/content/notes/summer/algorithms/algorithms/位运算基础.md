## 常用操作

| 作用 | 写法 |
|---|---|
| 取末 `k` 位 | `x & ((1 << k) - 1)` |
| 取右数第 `k` 位 | `(x >> (k - 1)) & 1` |
| 把末 `k` 位变成 `1` | `x \| ((1 << k) - 1)` |
| 末 `k` 位取反 | `x ^ ((1 << k) - 1)` |
| 把右边连续的 `1` 变成 `0` | `x & (x + 1)` |
| 把右起第一个 `0` 变成 `1` | `x \| (x + 1)` |
| 把右边连续的 `0` 变成 `1` | `x \| (x - 1)` |
| 取出右边连续的 `1` | `(x ^ (x + 1)) >> 1` |
