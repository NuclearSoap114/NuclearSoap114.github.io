> **前置知识**
> 已掌握 `lowbit`、单点加、前缀和，以及用 `ask(r)-ask(l-1)` 求区间和。

树状数组（Fenwick Tree，BIT）的核心能力是：**在 $O(\log n)$ 内修改和查询前缀信息**。

基础模板：

```cpp
const int N=2e5+10;
int n;
long long tr[N];

int lowbit(int x){
    return x&-x;
}

void add(int p,long long x){
    for(;p<=n;p+=lowbit(p)) tr[p]+=x;
}

long long ask(int p){
    long long res=0;
    for(;p;p-=lowbit(p)) res+=tr[p];
    return res;
}

long long query(int l,int r){
    return ask(r)-ask(l-1);
}
```

复杂度：单次修改、查询均为 $O(\log n)$，空间为 $O(n)$。

## 1. 区间加 + 单点查：差分 + BIT

<div id="section-2" class="note-anchor"></div>

### 1.1 思想

定义原数组 $a$ 的差分数组：


$$
d_i=a_i-a_{i-1},\qquad a_i=\sum_{j=1}^{i}d_j
$$


如果把区间 $[l,r]$ 中每个数都加上 $x$，差分数组只需改变两个位置：


$$
d_l\mathrel{+}=x,\qquad d_{r+1}\mathrel{-}=x
$$


因此用树状数组维护 $d$：

- 区间加：`add(l,x), add(r+1,-x)`；
- 单点查：$a_p=\sum_{i=1}^{p}d_i=$ `ask(p)`。

<div id="section-3" class="note-anchor"></div>

### 1.2 模板

```cpp
const int N=2e5+10;
int n;
long long tr[N];

int lowbit(int x){ return x&-x; }

void add(int p,long long x){
    for(;p<=n;p+=lowbit(p)) tr[p]+=x;
}

long long ask(int p){
    long long res=0;
    for(;p;p-=lowbit(p)) res+=tr[p];
    return res;
}

void range_add(int l,int r,long long x){
    add(l,x);
    if(r+1<=n) add(r+1,-x);
}

long long point_query(int p){
    return ask(p);
}
```

<div id="section-4" class="note-anchor"></div>

### 1.3 初始化

可以把差分值逐个加入：

```cpp
for(int i=1;i<=n;i++){
    cin>>a[i];
    add(i,a[i]-a[i-1]);
}
```

> **识别信号**
> 题目反复对一段连续区间加数，但只询问某个位置的当前值，可以想到“差分 + 树状数组”。

## 2. 区间加 + 区间和：双树状数组

<div id="section-6" class="note-anchor"></div>

### 2.1 为什么一棵树不够

仍令 $d_i=a_i-a_{i-1}$，则：


$$
a_i=\sum_{j=1}^{i}d_j
$$


要求原数组前缀和：


$$
S(x)=\sum_{i=1}^{x}a_i
$$


代入差分：


$$
\begin{aligned}
S(x)
&=\sum_{i=1}^{x}\sum_{j=1}^{i}d_j\\
&=d_1\cdot x+d_2\cdot(x-1)+\cdots+d_x\cdot1\\
&=\sum_{j=1}^{x}d_j(x-j+1)\\
&=(x+1)\sum_{j=1}^{x}d_j-\sum_{j=1}^{x}j d_j
\end{aligned}
$$


于是分别维护：

- $B_1$：$d_j$；
- $B_2$：$j d_j$。

便有：


$$
S(x)=(x+1)\operatorname{ask}(B_1,x)-\operatorname{ask}(B_2,x)
$$


有些模板令第二棵树维护 $(j-1)d_j$，公式会写成：


$$
S(x)=x\operatorname{ask}(B_1,x)-\operatorname{ask}(B_2,x)
$$


两种写法本质相同，**不要把维护方式和公式混用**。下面采用第二种。

<div id="section-7" class="note-anchor"></div>

### 2.2 区间修改的推导

给 $[l,r]$ 加 $v$，差分变化为：


$$
d_l\mathrel{+}=v,\qquad d_{r+1}\mathrel{-}=v
$$


因此：

- $B_1$ 在 $l$ 加 $v$，在 $r+1$ 加 $-v$；
- $B_2$ 在 $l$ 加 $(l-1)v$，在 $r+1$ 加 $-rv$。

此时：


$$
S(x)=x\operatorname{ask}(B_1,x)-\operatorname{ask}(B_2,x)
$$


最终：


$$
\operatorname{sum}(l,r)=S(r)-S(l-1)
$$


<div id="section-8" class="note-anchor"></div>

### 2.3 C++17 模板

```cpp
const int N=2e5+10;
int n;
long long tr1[N],tr2[N];

int lowbit(int x){ return x&-x; }

void add(long long tr[],int p,long long x){
    for(;p<=n;p+=lowbit(p)) tr[p]+=x;
}

long long ask(long long tr[],int p){
    long long res=0;
    for(;p;p-=lowbit(p)) res+=tr[p];
    return res;
}

void range_add(int l,int r,long long x){
    add(tr1,l,x);
    add(tr2,l,x*(l-1));
    if(r+1<=n){
        add(tr1,r+1,-x);
        add(tr2,r+1,-x*r);
    }
}

long long prefix_sum(int p){
    return 1LL*p*ask(tr1,p)-ask(tr2,p);
}

long long range_sum(int l,int r){
    return prefix_sum(r)-prefix_sum(l-1);
}
```

初始化原数组时，可以把每个 $a_i$ 看成一次 `[i,i]` 区间加：

```cpp
for(int i=1;i<=n;i++){
    long long x;
    cin>>x;
    range_add(i,i,x);
}
```

若数据规模大，可在读入时根据差分直接建树，或使用 $O(n)$ 建树优化；多数题中 $O(n\log n)$ 初始化已经足够。

> **识别信号**
> 同时出现“区间加”和“区间求和”，且没有区间赋值、区间最值等操作，优先考虑双树状数组。

## 3. 逆序对：离散化 + 频次 BIT

<div id="section-10" class="note-anchor"></div>

### 3.1 定义

若 $i<j$ 且 $a_i>a_j$，则 $(i,j)$ 是一个逆序对。

从左到右扫描 $a_i$。处理到 $i$ 时，前面已经有 $i-1$ 个数：


$$
\text{前面大于 }a_i\text{ 的数量}
=(i-1)-\text{前面小于等于 }a_i\text{ 的数量}
$$


让树状数组维护“每个值已经出现了几次”，则：

```cpp
ans+=(i-1)-ask(rank[i]);
add(rank[i],1);
```

值域可能很大、为负数或不连续，所以先离散化。

<div id="section-11" class="note-anchor"></div>

### 3.2 离散化

```cpp
vector<long long> b(a+1,a+n+1);
sort(b.begin(),b.end());
b.erase(unique(b.begin(),b.end()),b.end());

int get(long long x){
    return lower_bound(b.begin(),b.end(),x)-b.begin()+1;
}
```

离散化只改变大小对应的编号，不改变数值之间的大小关系。相同的值会得到相同编号。

<div id="section-12" class="note-anchor"></div>

### 3.3 完整模板

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll=long long;

const int N=2e5+10;
int n,tr[N];
ll a[N];
vector<ll> b;

int lowbit(int x){ return x&-x; }

void add(int p,int x){
    for(;p<=n;p+=lowbit(p)) tr[p]+=x;
}

int ask(int p){
    int res=0;
    for(;p;p-=lowbit(p)) res+=tr[p];
    return res;
}

int get(ll x){
    return lower_bound(b.begin(),b.end(),x)-b.begin()+1;
}

int main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin>>n;
    for(int i=1;i<=n;i++) cin>>a[i];
    b.assign(a+1,a+n+1);
    sort(b.begin(),b.end());
    b.erase(unique(b.begin(),b.end()),b.end());

    ll ans=0;
    for(int i=1;i<=n;i++){
        int p=get(a[i]);
        ans+=(i-1)-ask(p); // 前面严格大于 a[i] 的数量
        add(p,1);
    }
    cout<<ans<<'\n';
    return 0;
}
```

也可以从右向左扫，此时累加右侧严格小于 $a_i$ 的数量：

```cpp
for(int i=n;i>=1;i--){
    int p=get(a[i]);
    ans+=ask(p-1);
    add(p,1);
}
```

注意严格关系：

- `< x`：`ask(rank(x)-1)`；
- `<= x`：`ask(rank(x))`；
- `> x`：`已加入总数-ask(rank(x))`；
- `>= x`：`已加入总数-ask(rank(x)-1)`。

> **答案要用 `long long`**
> 逆序对最多约为 $\frac{n(n-1)}2$，当 $n$ 较大时会超过 `int`。

## 4. 动态第 k 小：树状数组二进制倍增

<div id="section-14" class="note-anchor"></div>

### 4.1 问题形式

树状数组维护非负频次：


$$
c_i=\text{值 }i\text{ 当前出现的次数}
$$


第 $k$ 小等价于寻找最小位置 $p$，满足：


$$
\operatorname{ask}(p)\ge k
$$


普通二分每次调用 `ask`，复杂度是 $O(\log^2 n)$。利用树状数组内部结构，可以直接在树上倍增，做到 $O(\log n)$。

<div id="section-15" class="note-anchor"></div>

### 4.2 思路

维护：

- `p`：当前确定的、前缀和仍然 `< k` 的最大位置；
- `sum`：`ask(p)`。

从最大的二进制步长开始尝试跳到 `p+step`：

- 若该位置合法，且加入对应树节点后仍 `< k`，说明答案还在右边，接受这一步；
- 否则缩小步长。

最终 `p+1` 就是第一个前缀和 `>= k` 的位置。

<div id="section-16" class="note-anchor"></div>

### 4.3 模板

```cpp
// 要求 tr 维护非负频次，且 1<=k<=ask(n)
int kth(int k){
    int p=0,sum=0;
    int step=1;
    while((step<<1)<=n) step<<=1;
    for(;step;step>>=1){
        int np=p+step;
        if(np<=n&&sum+tr[np]<k){
            p=np;
            sum+=tr[np];
        }
    }
    return p+1;
}
```

如果总频次可能超过 `int`，把 `k` 和 `sum` 改为 `long long`。

<div id="section-17" class="note-anchor"></div>

### 4.4 动态第 k 小的操作

若值域已经离散化：

```cpp
add(rank(x),1);   // 插入 x
add(rank(x),-1);  // 删除 x，必须保证 x 当前存在
int p=kth(k);     // 第 k 小的离散排名
long long value=b[p-1];
```

<div id="section-18" class="note-anchor"></div>

### 4.5 使用条件

`kth` 依赖前缀和单调不减，因此树状数组中维护的实际频次不能为负。若维护的是一般正负权值，前缀和未必单调，不能用该方法。

> **识别信号**
> 动态插入、删除，并反复询问第 $k$ 小；或要求“最小的 $p$ 使前缀累计值达到 $k$”。

## 5. 二维树状数组

一维 BIT 维护前缀 `[1,x]`，二维 BIT 维护左上角矩形：


$$
[1,x]\times[1,y]
$$


<div id="section-20" class="note-anchor"></div>

### 5.1 单点加 + 矩形和

```cpp
const int N=1010,M=1010;
int n,m;
long long tr[N][M];

int lowbit(int x){ return x&-x; }

void add(int x,int y,long long v){
    for(int i=x;i<=n;i+=lowbit(i))
        for(int j=y;j<=m;j+=lowbit(j))
            tr[i][j]+=v;
}

long long ask(int x,int y){
    long long res=0;
    for(int i=x;i;i-=lowbit(i))
        for(int j=y;j;j-=lowbit(j))
            res+=tr[i][j];
    return res;
}
```

用二维前缀和的容斥求矩形 $(x_1,y_1)$ 到 $(x_2,y_2)$：

```cpp
long long query(int x1,int y1,int x2,int y2){
    return ask(x2,y2)-ask(x1-1,y2)-ask(x2,y1-1)+ask(x1-1,y1-1);
}
```

复杂度：

- 单点加：$O(\log n\log m)$；
- 矩形查询：$O(\log n\log m)$；
- 空间：$O(nm)$。

二维 BIT 也能扩展为矩形加、单点查；若要矩形加、矩形和，需要维护四棵二维树状数组，公式较繁琐，通常按具体题目现推或查模板。

> **空间很容易爆**
> `long long tr[5000][5000]` 约占 200 MB。坐标范围很大但有效点很少时，需要离散化、离线处理或动态结构。

## 6. 常见坑

<div id="section-22" class="note-anchor"></div>

### 6.1 下标必须从 1 开始

`lowbit(0)=0`。如果执行 `add(0,x)`：

```cpp
for(;p<=n;p+=lowbit(p))
```

`p` 永远不变，会死循环。离散化排名通常要 `+1`。

<div id="section-23" class="note-anchor"></div>

### 6.2 `add` 应该返回 `void`

修改操作没有返回值：

```cpp
void add(int p,int x);
```

<div id="section-24" class="note-anchor"></div>

### 6.3 注意 `long long`

以下位置尤其容易溢出：

- 区间和与答案；
- 逆序对数量；
- 双 BIT 中的 `x*(l-1)`、`x*r`、`p*ask(...)`。

乘法前保证至少一个操作数是 `long long`：

```cpp
1LL*p*ask(tr1,p)
```

<div id="section-25" class="note-anchor"></div>

### 6.4 多组数据要清空

```cpp
fill(tr,tr+n+1,0);
```

双树状数组两棵都要清。若值域大小是离散化后的 `m`，清到 `m` 即可。

<div id="section-26" class="note-anchor"></div>

### 6.5 严格大于还是大于等于

逆序对要求 `a[i]>a[j]`，相等不算。是否查询 `rank` 或 `rank-1` 要根据严格性决定。

<div id="section-27" class="note-anchor"></div>

### 6.6 `r+1` 越界

区间差分修改会访问 `r+1`。可以：

- 数组开到 `n+2`，并让修改函数自然忽略 `p>n`；或
- 显式判断 `if(r+1<=n)`。

<div id="section-28" class="note-anchor"></div>

### 6.7 双 BIT 公式不能混用

两套常见定义：

| 第二棵树维护 | 前缀和公式 |
|---|---|
| $i d_i$ | $(x+1)Q_1(x)-Q_2(x)$ |
| $(i-1)d_i$ | $xQ_1(x)-Q_2(x)$ |

选择一套固定记忆。

<div id="section-29" class="note-anchor"></div>

### 6.8 `kth` 的前提

- 实际频次非负；
- `1<=k<=ask(n)`；
- 若有删除，不能把某个值的频次删成负数。

<div id="section-30" class="note-anchor"></div>

### 6.9 树状数组不擅长什么

树状数组最适合具有“可合并、可作差”的前缀信息，例如和、频次、异或。遇到这些操作时通常考虑线段树：

- 区间赋值；
- 区间最大值/最小值并带复杂修改；
- 需要维护多种复杂区间信息。

## 7. 题目识别信号

| 题目操作 | 转化方式 | 数据结构 |
|---|---|---|
| 单点加，区间和 | 两个前缀和作差 | 一棵 BIT |
| 区间加，单点查 | 维护差分数组 | 一棵 BIT |
| 区间加，区间和 | 差分并推导原数组前缀和 | 两棵 BIT |
| 静态逆序对 | 离散化后统计频次 | 一棵 BIT |
| 动态插入/删除、第 k 小 | 维护离散值频次 | BIT + 二进制倍增 |
| 单点改，子矩形和 | 二维前缀容斥 | 二维 BIT |

看到以下关键词时，可以尝试往“前缀信息”转化：

- 大量在线修改与查询；
- 动态统计“比某个值小/大”的元素数量；
- 求逆序对、排名、第 $k$ 小；
- 区间加能够转成差分数组的两个单点修改；
- 二维点修改和矩形统计。

## 8. 速记

```text
基础 BIT：       单点加，前缀和
区间加单点查：   差分 + 一棵 BIT
区间加区间和：   差分 + 两棵 BIT
逆序对：         离散化 + 频次 BIT
动态第 k 小：    频次 BIT + 树上倍增
二维 BIT：       两层 lowbit + 四项容斥
```

最重要的不是背所有变形，而是先问：

> 能否把题目维护的信息转成“某种前缀信息”？

如果可以，再判断用差分、离散化、频次统计还是二维容斥来完成转化。
