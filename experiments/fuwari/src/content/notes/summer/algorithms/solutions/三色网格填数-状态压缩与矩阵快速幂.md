> **存放建议  **
> **等级：** A 类·高难突破题  
> **CF 等效评分：** 约 2000～2100  
> **理由：** 需要先设计按列 DP，再利用颜色重命名的对称性把状态数从 $3\cdot2^{n-1}$ 压缩到 $2^{n-2}$，最后将固定的列间转移转化为矩阵快速幂。

<div id="section-1" class="note-anchor"></div>

## 抽象题目

给定一个 $n\times m$ 的网格，每个格子填入 $0,1,2$ 中的一个数。

要求任意两个共享边的格子数字不同，求合法填法数量，对 $998244353$ 取模。

其中 $n<10$，但 $m$ 非常大。

---

<div id="section-2" class="note-anchor"></div>

## 一句话本质

把每一列看成一个状态，利用颜色名称之间的对称性只记录列内部的相等关系，再用转移矩阵统计相邻列之间的合法接法，通过矩阵快速幂完成大量重复转移。

---

<div id="section-3" class="note-anchor"></div>

## 本题学到的具体东西

<div id="section-4" class="note-anchor"></div>

### 1. 不记录具体颜色，只记录颜色之间的关系

一列满足相邻位置颜色不同。

确定前两个颜色后，对于第 $i$ 个位置，只有两种选择：

- 与第 $i-2$ 个位置相同；
- 使用与前两个位置都不同的第三种颜色。

因此只需要用一位记录：


$$
bit_{i-2}=[a_i=a_{i-2}]
$$


整列只需要 $n-2$ 位，状态数从：


$$
3\cdot2^{n-1}
$$


压缩为：


$$
S=2^{n-2}
$$


识别信号：题目中的具体标签可以整体重命名，并且重命名后合法性不变，此时应考虑保存“关系”而不是“标签值”。

---

<div id="section-5" class="note-anchor"></div>

### 2. 转移矩阵是“一步转移方案数表”

`trans[from][to]` 表示：

> 当前列形状为 `from` 时，下一列形状为 `to` 有多少种具体颜色填法。

它不是简单的能否转移，所以不一定只有 $0$ 或 $1$。

固定当前形状的一列代表方案后，枚举下一形状对应的 $6$ 个具体列，统计其中有多少列与当前列每一行都不同。

这个数量就是 `trans[from][to]`。

---

<div id="section-6" class="note-anchor"></div>

### 3. 矩阵乘法是在拼接多段转移

假设从状态 $a$ 到状态 $b$ 有 $A[a][b]$ 种方法，从状态 $b$ 到状态 $c$ 有 $B[b][c]$ 种方法。

固定中间状态 $b$ 时，前后两步可以自由组合，所以方案数相乘：


$$
A[a][b]\cdot B[b][c]
$$


中间状态可能有很多种，因此需要全部相加：


$$
C[a][c]=\sum_b A[a][b]\cdot B[b][c]
$$


这正是矩阵乘法。

所以：

- `trans` 表示走一步；
- `trans^2` 表示走两步；
- `trans^k` 表示走 $k$ 步。

---

<div id="section-7" class="note-anchor"></div>

## 从朴素思路到关键转折

最直接的做法是按列状压 DP。

一列第一个格子有 $3$ 种选择，之后每个格子有 $2$ 种选择，所以合法列数量为：


$$
3\cdot2^{n-1}
$$


当 $n=9$ 时，共有 $768$ 种列状态。

由于 $m$ 很大，需要对 $768\times768$ 的矩阵做快速幂，复杂度约为：


$$
O(768^3\log m)
$$


无法通过。

真正的关键是：

> 颜色 $0,1,2$ 的名称不重要，重要的是同一列中哪些位置颜色相同。

将只差颜色重命名的列合并后，状态数降为：


$$
2^{n-2}\le128
$$


这样矩阵快速幂才能通过。

---

<div id="section-8" class="note-anchor"></div>

## 核心推导

<div id="section-9" class="note-anchor"></div>

### 1. 定义压缩状态

对于一列：


$$
a_0,a_1,\ldots,a_{n-1}
$$


相邻位置必须不同。

对于每个 $i\ge2$：

- 若状态位为 $1$，令 $a_i=a_{i-2}$；
- 若状态位为 $0$，令 $a_i$ 为另外一种颜色。

由于 $a_{i-1}\ne a_{i-2}$，第三种颜色可以直接计算为：


$$
a_i=3-a_{i-1}-a_{i-2}
$$


因此一个 `mask` 可以在给定前两个颜色后唯一还原整列。

---

<div id="section-10" class="note-anchor"></div>

### 2. 为什么每种形状对应 6 个具体列

当 $n\ge2$ 时，前两个位置必须不同。

第一个位置有 $3$ 种选择，第二个位置有 $2$ 种选择，因此共有：


$$
3\cdot2=6
$$


种。

前两个颜色和 `mask` 确定后，后面所有颜色都唯一确定。

---

<div id="section-11" class="note-anchor"></div>

### 3. 构造一步转移矩阵

枚举当前形状 `from`，固定它前两个颜色为 `0、1`，还原当前列。

再枚举下一形状 `to`，并枚举下一列前两个颜色的 $6$ 种选择。

如果两列每一行都满足：


$$
now_i\ne next_i
$$


则：

```cpp
trans[from][to]++;
```

同一个形状的不同具体列之间只是颜色整体重命名，所以固定当前列为 `0、1` 开头不会改变合法下一列的数量。

---

<div id="section-12" class="note-anchor"></div>

### 4. 使用矩阵快速幂

设：

```text
ways = trans^(m-1)
```

那么：

```text
ways[from][to]
```

表示第一列形状为 `from`，经过 $m-1$ 次列间转移后，第 $m$ 列形状为 `to` 的方案数。

第一列形状可以任意选择，最后一列形状也可以任意选择，因此先计算：


$$
res=\sum_{from}\sum_{to} ways[from][to]
$$


构造时第一列前两个颜色固定为 `0、1`，实际共有 $6$ 种选择，所以：


$$
answer=6\cdot res
$$


这里只乘一次 $6$。

第 $2$ 列到第 $m$ 列的具体颜色选择已经全部包含在 `trans` 的转移数量中。

---

<div id="section-13" class="note-anchor"></div>

## 为什么正确

<div id="section-14" class="note-anchor"></div>

### 压缩没有丢失信息

一列合法颜色方案可以唯一分解为：

- 前两个具体颜色；
- 后面每个位置是否等于前两个位置之前的颜色。

所以每个具体列都能对应唯一形状，给定形状和前两个颜色后也能唯一还原具体列。

---

<div id="section-15" class="note-anchor"></div>

### 转移矩阵完整统计所有下一列

对于固定的当前列和下一形状，代码枚举了下一形状的全部 $6$ 种具体颜色版本。

每个版本都检查了所有行的左右相邻限制，因此：

- 合法的下一列不会遗漏；
- 非法的下一列不会被统计；
- 每个具体下一列只被统计一次。

---

<div id="section-16" class="note-anchor"></div>

### 矩阵幂完整统计所有列序列

对于任意中间形状 $k$：


$$
A[from][k]\cdot B[k][to]
$$


表示先完成前一段转移，再完成后一段转移的组合数量。

对所有中间形状求和，就覆盖了全部可能的中间列状态。

因此 `trans^k[from][to]` 恰好表示走 $k$ 次列间转移的方案数。

---

<div id="section-17" class="note-anchor"></div>

## 复杂度

令：


$$
S=2^{n-2}
$$


由于 $n<10$：


$$
S\le128
$$


构造转移矩阵时，枚举两个形状、下一列的 $6$ 种具体颜色和 $n$ 行：


$$
O(S^2\cdot6n)
$$


矩阵快速幂复杂度为：


$$
O(S^3\log m)
$$


空间复杂度为：


$$
O(S^2)
$$


---

<div id="section-18" class="note-anchor"></div>

## 识别信号

当题目同时出现以下结构时，可以考虑这种方法：

- 一维长度很小，另一维非常大；
- 每一层只和上一层发生局部关系；
- 每一层之间使用完全相同的转移规则；
- 普通状压 DP 可以做，但层数太大；
- 状态中的具体颜色、编号或标签可以整体重命名；
- 只差重命名的状态具有完全相同的转移性质。

对应路线通常是：

```text
按层状压 DP
-> 对称性压缩状态
-> 构造固定转移矩阵
-> 矩阵快速幂
```

---

<div id="section-19" class="note-anchor"></div>

## 适用边界

<div id="section-20" class="note-anchor"></div>

### 颜色数量改变

本题只有三种颜色，所以知道连续两个不同颜色后，第三种颜色是唯一的。

如果颜色数量大于 $3$，状态位为 $0$ 时可能有多种新颜色，当前的二进制形状不足以描述整列。

<div id="section-21" class="note-anchor"></div>

### 相邻规则改变

如果除了上下左右，还要求对角线不同，那么下一列是否合法可能依赖更多信息，需要重新设计状态。

<div id="section-22" class="note-anchor"></div>

### 每列规则不同

矩阵快速幂依赖每一列之间使用同一个转移矩阵。

如果不同列有不同限制，就不能直接计算一个固定矩阵的幂。

---

<div id="section-23" class="note-anchor"></div>

## 本题暴露的问题

已经理解了状压状态和矩阵快速幂模板，但一开始把矩阵只理解为斐波那契递推式中的代数系数，没有把矩阵理解成：

> 状态之间的一步转移方案数表。

因此对 `trans` 和 `ways` 的含义不够明确：

- `trans[from][to]` 是走一步的方案数；
- `ways[from][to]` 是走 $m-1$ 步的方案数；
- 矩阵乘法中的中间下标，就是中间一列的形状。

真正需要补上的不是矩阵快速幂代码，而是“矩阵乘法为什么能拼接状态转移”的组合意义。

---

<div id="section-24" class="note-anchor"></div>

## 实现时最容易错的地方

1. `n=1` 时没有前两个颜色，必须单独计算：

   
$$
3\cdot2^{m-1}
$$


2. `trans[from][to]` 记录的是方案数量，不是 `0/1`。

3. 从第 $1$ 列到第 $m$ 列只转移 $m-1$ 次。

4. 最后只乘一次 $6$，不能每列都乘。

5. 代码中矩阵下标统一为：

   ```text
   行：from
   列：to
   ```

6. 状态位的含义必须统一：

   ```text
   1：当前颜色等于前两个位置之前的颜色
   0：当前颜色使用第三种颜色
   ```

---

<div id="section-25" class="note-anchor"></div>

## 复习时反问

1. 为什么确定一列的前两个颜色后，只需要 $n-2$ 个二进制位就能还原整列？

2. 为什么固定当前列前两个颜色为 `0、1`，不会影响它到其他形状的转移数量？

3. 为什么矩阵乘法中的“先乘后加”分别对应同一路线的组合和不同中间状态的合并？

4. 为什么最终只需要乘一次 $6$，而不是乘 $6^m$？

## 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define rep(i,l,r) for(int i=(l);i<=(r);i++)
#define V vector

const int mod = 998244353;

using Matrix = V<V<int>>;

int n,m;

// --------------- 矩阵乘法 ---------------
Matrix mul(const Matrix &A,const Matrix &B){
    int sz = A.size();
    Matrix C(sz,V<int>(sz,0));

    rep(i,0,sz - 1){
        rep(k,0,sz - 1){
            if(A[i][k] == 0)continue;

            rep(j,0,sz - 1){
                C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % mod;
            }
        }
    }

    return C;
}

// --------------- 矩阵快速幂 ---------------
Matrix qp(Matrix A,int p){
    int sz = A.size();
    Matrix res(sz,V<int>(sz,0));

    rep(i,0,sz - 1){
        res[i][i] = 1;
    }

    while(p){
        if(p & 1){
            res = mul(res,A);
        }

        A = mul(A,A);
        p >>= 1;
    }

    return res;
}

// --------------- 普通快速幂 ---------------
int qpnum(int a,int p){
    int res = 1;

    while(p){
        if(p & 1){
            res = res * a % mod;
        }

        a = a * a % mod;
        p >>= 1;
    }

    return res;
}

// --------------- 根据形状还原一列 ---------------
V<int> buildCol(int mask,int first,int second){
    V<int> col(n);

    col[0] = first;
    col[1] = second;

    for(int i=2;i<n;i++){
        int bit = (mask >> (i - 2)) & 1;

        if(bit == 1){
            col[i] = col[i - 2];
        }
        else{
            col[i] = 3 - col[i - 1] - col[i - 2];
        }
    }

    return col;
}

// --------------- 判断两列能否相邻 ---------------
bool check(const V<int> &a,const V<int> &b){
    rep(i,0,n - 1){
        if(a[i] == b[i]){
            return false;
        }
    }

    return true;
}

// --------------- 构造一步转移矩阵 ---------------
Matrix buildTrans(){
    int sz = 1LL << (n - 2);
    Matrix trans(sz,V<int>(sz,0));

    rep(from,0,sz - 1){
        V<int> now = buildCol(from,0,1);

        rep(to,0,sz - 1){
            rep(first,0,2){
                rep(second,0,2){
                    if(first == second)continue;

                    V<int> nxt = buildCol(to,first,second);

                    if(check(now,nxt)){
                        trans[from][to]++;
                    }
                }
            }
        }
    }

    return trans;
}

// --------------- 解决单行情况 ---------------
void solveOneRow(){
    int ans = 3 * qpnum(2,m - 1) % mod;

    cout << ans << '\n';
}

// --------------- 计算答案 ---------------
void O_o(){
    cin >> n >> m;

    if(n == 1){
        solveOneRow();
        return;
    }

    int sz = 1LL << (n - 2);

    Matrix trans = buildTrans();

    Matrix ways = qp(trans,m - 1);

    int ans = 0;

    rep(from,0,sz - 1){
        rep(to,0,sz - 1){
            ans = (ans + ways[from][to]) % mod;
        }
    }

    ans = ans * 6 % mod;

    cout << ans << '\n';
}

// --------------- 主函数 ---------------
signed main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    O_o();

    return 0;
}
```
