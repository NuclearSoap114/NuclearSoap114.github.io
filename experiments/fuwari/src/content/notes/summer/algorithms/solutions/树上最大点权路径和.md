## 树上最大点权路径和

> **存放建议  **
> **等级：** A 类·核心突破题  
> **理由：** 关键突破是把任意树上路径拆成“某个最高点 + 至多两条向下链”，并理解 `dp[u]` 向父亲只能传递一个方向，而全局答案可以连接两个方向。

<div id="section-2" class="note-anchor"></div>

## 抽象题目

给定一棵含有 $n$ 个节点的树，每个节点有一个可能为负数的权值。

选择树上的一条非空简单路径，使路径上所有节点的权值之和最大，求这个最大值。

<div id="section-3" class="note-anchor"></div>

## 一句话本质

任意一条树上简单路径，都可以在它的最高节点处分成来自两个不同子树的向下链，因此每个节点只需要知道儿子中最大的两个有效贡献。

<div id="section-4" class="note-anchor"></div>

## 从朴素思路到关键转折

最直接的方法是枚举路径的两个端点，再计算两点之间的路径和。

树上共有 $O(n^2)$ 对端点，即使能够快速计算每条路径的权值，也无法满足较大的数据范围。

容易想到照搬树的直径做法，进行两次 DFS。但当点权存在负数时，从任意起点到某个优秀路径端点的过程中，可能必须经过一个很大的负权节点。

例如：

```text
-10 -- 6 -- 6 -- -100 -- 40 -- 40
```

真正的最大路径是：

```text
40 -- 40
```

路径和为 $80$。

但从左端点出发时，右侧的 $40$ 会被中间的 $-100$ 拖累，第一次 DFS 不一定能找到真正最大路径的端点。

真正的转折是：

> 不再寻找全局端点，而是枚举每条路径的最高节点。

将树以任意节点为根。对于一条简单路径，它一定存在唯一的最高节点 $u$，路径在 $u$ 的两侧分别进入至多一个儿子子树。

结构只有三种：

```text
只选择 u

u -> 某个子树

某个子树 -> u -> 另一个子树
```

因此只要计算每个节点的两条最大向下贡献，就能覆盖所有路径。

<div id="section-5" class="note-anchor"></div>

## 核心推导

<div id="section-6" class="note-anchor"></div>

### 1. 定义子树向父亲汇报的信息

定义：


$$
dp[u]=\text{从 }u\text{ 出发，只向其子树中的一个方向延伸的最大路径和}
$$


这条路径必须包含节点 $u$。

之所以只能向一个儿子方向延伸，是因为 `dp[u]` 还要交给父节点使用。

父节点连接 `u` 时，路径必须保持为一条链：

```text
父亲 -> u -> 一个儿子方向
```

如果 `dp[u]` 同时进入两个儿子子树，再接到父亲，就会形成三叉结构，不再是一条简单路径。

---

<div id="section-7" class="note-anchor"></div>

### 2. 计算一个儿子的有效贡献

完成 `dfs(v,u)` 后，`dp[v]` 表示从儿子 `v` 开始向下延伸的最大路径和。

如果：

```text
dp[v] > 0
```

接上这条链可以使路径和增大。

如果：

```text
dp[v] <= 0
```

接上它只会使路径和减小，因此可以不进入这个子树。

所以儿子 `v` 对节点 `u` 的有效贡献是：


$$
x_v=\max(0,dp[v])
$$


这里的 $0$ 不是一条权值为 $0$ 的路径，而是：

> 不选择这个儿子方向。

---

<div id="section-8" class="note-anchor"></div>

### 3. 保存最大的两个儿子贡献

设所有儿子的有效贡献中，最大值和第二大值分别是：

```text
mx1
mx2
```

那么从 `u` 出发、向父亲汇报的链只能选择一个方向：


$$
dp[u]=a[u]+mx1
$$


因为 `mx1` 是所有可选儿子方向中贡献最大的一个。

---

<div id="section-9" class="note-anchor"></div>

### 4. 用两个方向组成经过 u 的完整路径

一条以 `u` 为最高点的完整路径，可以同时进入两个不同的儿子子树：

```text
第一条向下链 -> u -> 第二条向下链
```

其最大权值为：


$$
a[u]+mx1+mx2
$$


因此：


$$
ans=\max(ans,a[u]+mx1+mx2)
$$


当没有正贡献儿子时：

```text
mx1 = 0
mx2 = 0
```

此时路径只选择节点 `u`，值为 `a[u]`。

所以即使整棵树全部是负数，也不会错误地得到 $0$。

<div id="section-10" class="note-anchor"></div>

## 为什么正确

考虑任意一条合法简单路径 $P$。

把树固定根以后，$P$ 上一定存在唯一一个深度最小的节点 $u$，也就是这条路径的最高点。

从 $u$ 出发，路径的两个方向只能出现以下情况：

- 两边都不进入儿子子树，只选择 $u$；
- 只进入一个儿子子树；
- 分别进入两个不同的儿子子树。

不可能进入三个儿子子树，否则路径会产生分叉。

对于每个儿子 $v$，`dp[v]` 已经给出了从 `v` 出发向下的最大合法链，因此 `max(0,dp[v])` 是进入这个子树能够获得的最佳贡献。

在所有儿子中选择最大的两个贡献，就能得到以 $u$ 为最高点的最大路径：


$$
a[u]+mx1+mx2
$$


算法对每个节点都进行了这样的计算，因此所有可能的最高点都被枚举，所有合法路径都会被覆盖。

同时，`mx1` 和 `mx2` 来自两个不同儿子，连接后确实形成一条简单路径，因此计算出的每个候选答案都能够实际构造出来。

所以最终得到的 `ans` 正是树上的最大点权路径和。

<div id="section-11" class="note-anchor"></div>

## 复杂度

每个节点只进入 DFS 一次，每条无向边在两个方向上各遍历一次。

维护 `mx1` 和 `mx2` 时，每个儿子只处理一次，因此总时间复杂度为：


$$
O(n)
$$


邻接表、`dp` 数组以及 DFS 递归栈占用：


$$
O(n)
$$


相比枚举两个路径端点的 $O(n^2)$，这里消掉了端点组合的枚举，改为按照路径的唯一最高点统一结算。

<div id="section-12" class="note-anchor"></div>

## 识别信号

以后看到以下结构时，可以考虑这种树形 DP：

- 要在树上选择一条简单路径，并最大化或最小化路径贡献；
- 一条完整路径可以在某个节点处分成两个向下方向；
- 子树向父亲只能提供一条链，但当前节点计算全局答案时可以连接两条链；
- 节点或边存在负权，不能直接套用普通两次 DFS 求直径；
- 问题要求的是任意起点、任意终点，而不是固定根到某点。

核心识别句：

> 向父亲传一个方向，在当前节点结算两个方向。

<div id="section-13" class="note-anchor"></div>

## 适用边界

本方法依赖以下条件：

1. 图必须是一棵树，任意两点之间路径唯一；
2. 目标结构必须是一条简单路径，不能出现分叉；
3. 路径允许只包含一个节点；
4. 路径贡献可以由经过节点的权值直接相加。

如果路径必须至少包含一条边，就不能直接允许 `mx1 = mx2 = 0` 后把单个节点作为答案，需要额外保证答案连接了至少一个儿子或单独处理边。

如果要求选择一个连通子图，而不是一条链，一个节点可能需要同时保留超过两个儿子，当前状态会失效。

如果原图存在环，任意两点之间的路径不唯一，简单的父子树结构也不再成立。

如果所有权值均非负，两次 DFS 可以用于普通直径思路；一旦允许负权，第一次找到的“最远点”不一定是最优路径端点。

<div id="section-14" class="note-anchor"></div>

## 本题暴露的问题

最开始使用了下面这种写法：

```cpp
ans = max(ans,dp[u] + dp[v]);
dp[u] = max(dp[u],a[u] + dp[v]);
```

它虽然正确，但 `dp[u]` 的含义会随着儿子遍历过程不断变化：

> 更新前的 `dp[u]` 只代表已经处理过的儿子中的最佳方向。

这种写法把“寻找第一大、第二大贡献”的过程隐藏在循环顺序中，导致难以直接说明状态含义，也容易担心更新顺序是否会重复使用当前儿子。

改成显式维护 `mx1`、`mx2` 后，逻辑变成：

```text
先收集所有儿子贡献
找到最大和第二大
一个方向更新 dp[u]
两个方向更新 ans
```

还出现了两个容易过度推广的误区：

- 担心 `mx1` 初始化为 $0$ 会漏掉全负数情况，没有区分“儿子贡献为 $0$”和“不选择儿子”；
- 想把普通树直径的两次 DFS 直接推广到负点权路径，但负权会破坏“任意点的最远点一定是直径端点”的性质。

<div id="section-15" class="note-anchor"></div>

## 实现时最容易错的地方

- `ans` 必须初始化为负无穷，不能初始化为 $0$，否则全负数时会错误输出 $0$；
- DFS 时必须跳过父节点，否则无向树会无限递归；
- 必须先递归计算 `dp[v]`，再使用儿子贡献；
- 更新第一大贡献时，要先把原来的 `mx1` 放入 `mx2`；
- `dp[u]` 只能使用 `mx1`，不能使用 `mx1 + mx2`；
- `ans` 才能使用 `mx1 + mx2`；
- 如果存在多组数据，需要清空邻接表并重新初始化 `ans`；
- 当树退化成长度为 $n$ 的链时，递归深度可能达到 $n$，部分环境可能出现栈溢出。

<div id="section-16" class="note-anchor"></div>

## 复习时反问

1. 为什么 `dp[u]` 向父亲只能传递一个儿子方向，而计算全局答案时可以使用两个方向？
2. `max(0,dp[v])` 中的 $0$ 表示什么？为什么整棵树全是负数时答案仍然不会变成 $0$？
3. 如何证明任意树上简单路径都会在某个节点的 `a[u] + mx1 + mx2` 中被统计？
4. 如果题目要求路径至少包含一条边，当前初始化和答案更新需要怎样改变？

<div id="section-17" class="note-anchor"></div>

## 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define rep(i,l,r) for(int i=(l);i<=(r);i++)
const int inf = 1e18,N = 1e5 + 10;
int T,n,ans;
int a[N],dp[N];
vector<int> G[N];

void dfs(int u,int fa){
    int mx1 = 0;
    int mx2 = 0;

    for(int v : G[u]){
        if(v == fa)continue;

        dfs(v,u);

        int x = max(0LL,dp[v]);

        if(x >= mx1){
            mx2 = mx1;
            mx1 = x;
        }else if(x > mx2){
            mx2 = x;
        }
    }

    dp[u] = a[u] + mx1;
    ans = max(ans,a[u] + mx1 + mx2);
}

void O_o(){
    cin >> n;

    rep(i,1,n)cin >> a[i];

    rep(i,1,n - 1){
        int u,v;
        cin >> u >> v;
        G[u].pb(v);
        G[v].pb(u);
    }

    ans = -inf;
    dfs(1,0);

    cout << ans << '\n';
}

signed main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    T = 1;
    while(T--)O_o();

    return 0;
}
```
