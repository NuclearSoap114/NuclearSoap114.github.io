> **存放建议  **
> **等级：** B 类·进阶模型题  
> **CF 等效评分：** 约 1800～1900（估计）  
> **理由：** 需要依次完成 gcd 转化、质因子集合容斥、莫比乌斯函数压缩容斥，以及整除分块优化多组询问，属于多种数论技巧的组合题。

题目对应 POI 2007 ZAP-Queries，也常见为 AcWing 215「破译密码」；数据范围为最多 50000 组询问，`a,b,d <= 50000`。

<div id="section-1" class="note-anchor"></div>

## 抽象题目

给定多组 `a,b,d`，统计满足：

```text
1 <= x <= a
1 <= y <= b
gcd(x,y) = d
```

的有序整数对 `(x,y)` 数量。

询问数量和数值范围都达到 50000，不能逐对枚举，也不能在每组询问中线性枚举所有可能公因数。

---

<div id="section-2" class="note-anchor"></div>

## 一句话本质

先将 `gcd(x,y)=d` 转化为一个矩形范围内的互质数对计数，再用莫比乌斯函数完成公共质因子的容斥，最后利用 `X/k`、`Y/k` 在连续区间内不变的性质进行整除分块。

---

<div id="section-3" class="note-anchor"></div>

## 本题学到的具体东西

<div id="section-4" class="note-anchor"></div>

### 1. `X/k * Y/k` 统计的是“共同含有因子 k”的数对

固定整数 `k`：

```text
X / k = 1~X 中 k 的倍数数量
Y / k = 1~Y 中 k 的倍数数量
```

所以：

```text
(X / k) * (Y / k)
```

表示满足：

```text
k | x
k | y
```

的数对数量。

它不是统计：

```text
gcd(x,y) = k
```

而是统计：

```text
k | gcd(x,y)
```

对固定的一个 `k`，这个乘法没有重复；重复发生在不同 `k` 之间。

例如 `(6,12)` 会被 `k=1,2,3,6` 分别统计，因为这些数都是 `gcd(6,12)=6` 的约数。

**识别信号：**

当题目要求统计 gcd 条件，但“gcd 恰好等于某值”难以直接计算时，可以先统计“某个数同时整除两个变量”的方案数。

---

<div id="section-5" class="note-anchor"></div>

### 2. 莫比乌斯函数把质因子子集容斥压缩为枚举整数 k

不互质表示 `x,y` 至少有一个公共质因子。

理论上可以枚举所有公共质因子的非空子集：

```text
选择 1 个质因子：加到 bad
选择 2 个质因子：减去重复
选择 3 个质因子：再加回来
……
```

若子集中的质数乘积为 `k`，它的贡献为：

```text
(X / k) * (Y / k)
```

但质数子集数量太多，不能真的枚举。

莫比乌斯函数将这个子集信息记录在 `mu[k]` 中：

```text
mu[1] = 1

k 含奇数个不同质因子：mu[k] = -1
k 含偶数个不同质因子：mu[k] = 1
k 含有某个质数的平方：mu[k] = 0
```

于是互质数对数量可以直接写成：

```text
answer = Σ mu[k] * (X / k) * (Y / k)
```

其中 `k=1` 的贡献是：

```text
mu[1] * X * Y = X * Y
```

所以这个求和已经包含：

```text
全部数对 - 不互质数对
```

不需要再写：

```text
X * Y - ans
```

---

<div id="section-6" class="note-anchor"></div>

### 3. 两个整数除法必须同时分块

公式中同时出现：

```text
X / k
Y / k
```

因此一块 `[l,r]` 必须保证这两个商都不变化。

当前左端点为 `l`：

```cpp
int qx=X/l;
int qy=Y/l;
```

`X/k` 保持为 `qx` 的最远位置：

```cpp
int rx=X/qx;
```

`Y/k` 保持为 `qy` 的最远位置：

```cpp
int ry=Y/qy;
```

两个条件必须同时满足：

```cpp
int r=min(rx,ry);
```

即：

```cpp
int r=min(X/(X/l),Y/(Y/l));
```

这一块的贡献为：

```cpp
(pre[r]-pre[l-1])*(X/l)*(Y/l);
```

因为在 `[l,r]` 内，两个商固定，只有 `mu[k]` 在变化。

**最容易错：**

不能只对：

```cpp
lim/k
```

分块。即使 `lim=min(X,Y)`，`lim/k` 不变，也不能保证另一边的 `X/k` 或 `Y/k` 不变。

<div id="section-7" class="note-anchor"></div>

## 从朴素思路到关键转折

<div id="section-8" class="note-anchor"></div>

### 1. 直接枚举数对

枚举所有：

```text
1 <= x <= X
1 <= y <= Y
```

并判断 `gcd(x,y)==1`。

单组复杂度：

```text
O(X * Y * log V)
```

最大约有 `2.5e9` 个数对，无法接受。

<div id="section-9" class="note-anchor"></div>

### 2. 枚举公共因子 k

固定 `k` 后，共同含有因子 `k` 的数对数量可以直接计算：

```text
(X / k) * (Y / k)
```

通过莫比乌斯函数容斥，得到：

```text
answer = Σ mu[k] * (X / k) * (Y / k)
```

但每组询问线性枚举到 `min(X,Y)`，总复杂度仍可能达到：

```text
50000 * 50000
```

仍然超时。

<div id="section-10" class="note-anchor"></div>

### 3. 合并商相同的连续区间

整数除法 `X/k`、`Y/k` 在很多连续区间内不变。

因此将这一整段一次计算，只需通过莫比乌斯前缀和得到：

```text
mu[l] + mu[l+1] + ... + mu[r]
```

从而把单组询问优化到约 `O(sqrt(V))`。

<div id="section-11" class="note-anchor"></div>

## 核心推导

<div id="section-12" class="note-anchor"></div>

### 1. 消去固定的 gcd

原条件：

```text
gcd(x,y) = d
```

令：

```text
x = d * u
y = d * v
```

则：

```text
gcd(x,y) = d * gcd(u,v)
```

所以原条件等价于：

```text
gcd(u,v) = 1
```

范围变为：

```text
1 <= u <= a/d
1 <= v <= b/d
```

记：

```cpp
int X=a/d;
int Y=b/d;
```

---

<div id="section-13" class="note-anchor"></div>

### 2. 统计共同含有因子 k 的数对

在 `1~X` 中，`k` 的倍数有：

```text
floor(X/k)
```

个。

在 `1~Y` 中，`k` 的倍数有：

```text
floor(Y/k)
```

个。

因此同时被 `k` 整除的数对有：

```text
floor(X/k) * floor(Y/k)
```

个。

---

<div id="section-14" class="note-anchor"></div>

### 3. 使用莫比乌斯函数容斥

互质数对公式：

```text
answer = Σ mu[k] * floor(X/k) * floor(Y/k)
```

枚举范围只需到：

```text
k <= min(X,Y)
```

因为超过较小值后，至少有一个商为 0。

---

<div id="section-15" class="note-anchor"></div>

### 4. 使用前缀和合并一整块

定义：

```text
pre[i] = mu[1] + mu[2] + ... + mu[i]
```

则：

```text
mu[l] + ... + mu[r] = pre[r] - pre[l-1]
```

如果 `[l,r]` 内：

```text
X/k = qx
Y/k = qy
```

那么整块贡献为：

```text
(pre[r]-pre[l-1]) * qx * qy
```

<div id="section-16" class="note-anchor"></div>

## 莫比乌斯函数线性筛

线性筛枚举当前数 `i` 和质数 `p`。

<div id="section-17" class="note-anchor"></div>

### 情况一：`p` 已经整除 i

```cpp
if(i%p==0){
    mu[i*p]=0;
    break;
}
```

因为 `i` 中已经含有质因子 `p`，再乘一次 `p` 后，`i*p` 含有 `p^2`，所以莫比乌斯函数为 0。

<div id="section-18" class="note-anchor"></div>

### 情况二：`p` 不整除 i

```cpp
mu[i*p]=-mu[i];
```

此时乘上了一个新的不同质因子，质因子数量的奇偶性改变，所以莫比乌斯函数符号反转。

<div id="section-19" class="note-anchor"></div>

### 质数的处理

如果 `i` 没有被筛过，它是质数：

```cpp
mu[i]=-1;
```

因为质数只含有一个不同质因子。

---

<div id="section-20" class="note-anchor"></div>

## 为什么正确

<div id="section-21" class="note-anchor"></div>

### gcd 转化正确

每个满足 `gcd(x,y)=d` 的数对都可以唯一写成：

```text
x=d*u
y=d*v
gcd(u,v)=1
```

反过来，每个范围内的互质数对 `(u,v)` 也唯一对应原数对 `(d*u,d*v)`，因此是一一对应。

<div id="section-22" class="note-anchor"></div>

### 莫比乌斯容斥正确

考虑一个固定数对，其最大公约数为 `g`。

它在总和中的贡献为：

```text
Σ mu[k]，其中 k | g
```

莫比乌斯函数满足：

```text
g=1 时，约数 mu 之和为 1
g>1 时，约数 mu 之和为 0
```

因此：

- 互质数对最终贡献 1；
    
- 不互质数对最终贡献 0。
    

所以求和结果恰好是互质数对数量。

<div id="section-23" class="note-anchor"></div>

### 整除分块正确

右端点：

```cpp
r=min(X/(X/l),Y/(Y/l));
```

保证对所有 `k∈[l,r]`：

```text
X/k = X/l
Y/k = Y/l
```

因此可以把固定的两个商提出，只计算区间内的 `mu` 之和，不会遗漏或重复任何 `k`。

---

<div id="section-24" class="note-anchor"></div>

## 复杂度

设最大值为 `V=50000`，询问数量为 `T`。

线性筛预处理：

```text
时间：O(V)
空间：O(V)
```

每组询问的整除分块数量约为：

```text
O(sqrt(X) + sqrt(Y))
```

因此总时间复杂度约为：

```text
O(V + T * sqrt(V))
```

空间复杂度为：

```text
O(V)
```

相比每组枚举所有 `k` 的 `O(V)`，整除分块消掉了大量商相同位置的重复计算。相关标准推导也是通过莫比乌斯前缀和配合整除分块实现。

<div id="section-25" class="note-anchor"></div>

## 本题暴露的问题

1. **没有先明确 `X/k * Y/k` 的统计对象。**  
    一开始知道它们分别是倍数数量，但没有立刻连接到乘法原理：一个合法 `x` 可以搭配每个合法 `y`，所以乘积统计的是共同含有因子 `k` 的有序数对。
    
2. **把单个 k 内的统计和不同 k 之间的重复混在一起。**  
    固定一个 `k` 时没有重复；重复来自同一个数对拥有多个公共因子，从而出现在多个 `k` 的集合中。
    
3. **已经理解 `answer=total-bad`，但没有意识到莫比乌斯公式已经展开了这个减法。**  
    `mu[1]=1` 对应全部数对，后面的正负项已经完成容斥，因此求和结果直接是答案。
    
4. **代码中只对 `lim/k` 分块。**  
    真正需要不变的是 `X/k` 和 `Y/k` 两个商，必须分别计算右端点后取较小值。
    
5. **分块贡献中把商 q 当成了枚举变量 k。**  
    一块内固定的贡献应是 `(X/l)*(Y/l)`，而不是 `(X/q)*(Y/q)`。
    
6. **写出了 `init()`，但主函数没有调用。**  
    这会导致 `mu` 和 `pre` 全为 0，属于初始化顺序错误。
    

---

<div id="section-26" class="note-anchor"></div>

## 实现时最容易错的地方

- 原范围应先变成 `X=a/d`、`Y=b/d`。
    
- 输出的是莫比乌斯求和结果，不要再用 `X*Y-ans`。
    
- 必须在处理询问前调用 `init()`。
    
- 右端点必须写成：
    

```cpp
r=min(X/(X/l),Y/(Y/l));
```

- 块贡献必须写成：
    

```cpp
(pre[r]-pre[l-1])*(X/l)*(Y/l)
```

- `ans` 最大可能接近 `X*Y`，需要使用 `long long`。
    
- 枚举范围为 `1~min(X,Y)`，因此分块中的商不会为 0。
    
- `mu[1]` 必须初始化为 1。

<div id="section-27" class="note-anchor"></div>

## 识别信号

当出现以下结构时，可以考虑这套方法：

- 要统计大量满足 `gcd(x,y)=d` 或 `gcd(x,y)=1` 的数对；
    
- “gcd 恰好等于某值”难统计，但“某个 k 同时整除两个数”容易计算；
    
- 直接对质因子集合容斥，但质数数量太多，无法真的枚举子集；
    
- 求和中出现大量 `floor(n/i)`，并且询问数量很多；
    
- 某个函数在连续整数区间内保持相同值，可以用前缀和一次处理整块。
    

---

<div id="section-28" class="note-anchor"></div>

## 适用边界

- 当前方法依赖统计范围是从 1 开始的矩形：`1~X` 与 `1~Y`。
    
- 如果范围改为 `[L1,R1]` 和 `[L2,R2]`，需要使用二维容斥，将其拆成四个前缀矩形。
    
- 如果要求的是三个或更多整数共同互质，公式中的倍数数量要增加维度。
    
- 如果只询问一次且范围很小，直接线性枚举 `k` 可能更简单，不必整除分块。
    
- 整除分块依赖 `floor(X/k)` 在连续区间内不变；若贡献还依赖每个具体 `k` 的其他不可前缀求和信息，就不能直接合并。

## 复习时反问

1. 为什么 `(X/k)*(Y/k)` 统计的是 `k | gcd(x,y)`，而不是 `gcd(x,y)=k`？
    
2. 为什么 `mu[1]` 的一项正好代表全部数对，因此求和结果不需要再用 `X*Y` 相减？
    
3. 为什么只对 `min(X,Y)/k` 分块不够，必须同时保证 `X/k` 和 `Y/k` 不变？
    
4. 线性筛中，当 `i%p==0` 时，为什么必须令 `mu[i*p]=0` 并立即 `break`？

## 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

#define int long long
#define rep(i,l,r) for(int i=(l);i<=(r);i++)
#define all() a.begin()+1,a.begin()+n+1
#define pii pair<int,int>
#define V vector
#define F first
#define S second
#define pb push_back
#define is insert

const int inf=1e18;
const int N=1e5+10;
const double pi=acos(-1);

// --------------- AC ---------------

int T,n,a,b,d;
int mu[N];
int pre[N];
int prime[N],cnt;
bool vis[N];

void init(){
    mu[1]=1;

    for(int i=2;i<N;i++){
        if(!vis[i]){
            prime[++cnt]=i;
            mu[i]=-1;
        }

        for(int j=1;j<=cnt&&i*prime[j]<N;j++){
            int p=prime[j];

            vis[i*p]=true;

            if(i%p==0){
                mu[i*p]=0;
                break;
            }else{
                mu[i*p]=-mu[i];
            }
        }
    }

    for(int i=1;i<N;i++){
        pre[i]=pre[i-1]+mu[i];
    }
}

void O_o(){
    cin >> a >> b >> d;

    int X=a/d;
    int Y=b/d;
    int lim=min(X,Y);

    int ans=0;

    for(int l=1;l<=lim;){
        int qx=X/l;
        int qy=Y/l;

        int rx=X/qx;
        int ry=Y/qy;

        int r=min({lim,rx,ry});

        ans+=(pre[r]-pre[l-1])*qx*qy;

        l=r+1;
    }

    cout << ans << '\n';
}

signed main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init();

    cin >> T;
    while(T--)O_o();

    return 0;
}
```
