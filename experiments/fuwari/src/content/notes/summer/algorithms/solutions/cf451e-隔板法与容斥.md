> **存放建议  **
> **等级：** A 类·高难突破题  
> **Codeforces 官方评分：** 2300  
> **理由：** 需要先把选花方案建模为有上限非负整数解，再通过变量平移统计每组超限方案，最后用状态压缩容斥；同时还要处理上标达到 $10^{14}$ 的模组合数。

<div id="section-1" class="note-anchor"></div>

## 抽象题目

给定 $N$ 个非负整数上限 $A_1,A_2,\dots,A_N$，求满足：


$$
x_1+x_2+\cdots+x_N=M
$$


且：


$$
0\le x_i\le A_i
$$


的非负整数解数量，答案对 $10^9+7$ 取模。

---

<div id="section-2" class="note-anchor"></div>

## 一句话本质

先用隔板法统计没有上限时的全部非负整数解，再枚举哪些变量超过上限，通过变量平移计算这些超限集合的方案数，最后使用容斥原理加减。

---

<div id="section-3" class="note-anchor"></div>

## 本题学到的具体东西

<div id="section-4" class="note-anchor"></div>

### 1. 用变量平移去掉下限限制

当要统计第 $i$ 个变量超限的方案时，条件是：


$$
x_i\ge A_i+1
$$


把超限所必需的部分提前取出：


$$
x_i=(A_i+1)+y_i
$$


其中 $y_i\ge0$。

于是：


$$
x_1+\cdots+y_i+\cdots+x_N=M-(A_i+1)
$$


两边方案数量相等，因为存在一一对应：


$$
y_i=x_i-(A_i+1),\qquad x_i=y_i+(A_i+1)
$$


这个转换可逆、无遗漏、无重复。

**识别信号：** 当某个变量满足 $x_i\ge L$ 时，可以令 $y_i=x_i-L$，把带下限变量转化为普通非负变量。

---

<div id="section-5" class="note-anchor"></div>

### 2. 用“超限变量集合”进行容斥

单独减去每个变量超限的方案会重复删除“多个变量同时超限”的方案，因此需要枚举集合 $S$：

> $S$ 中的变量被要求全部超限。

这些变量至少已经贡献：


$$
sum_S=\sum_{i\in S}(A_i+1)
$$


剩余需要自由分配的总量为：


$$
left=M-sum_S
$$


方程中仍然有 $N$ 个非负变量，因此方案数是：


$$
C(left+N-1,N-1)
$$


不是 $C(left+|S|-1,|S|-1)$。

根据容斥：

- $|S|$ 为奇数：减；
    
- $|S|$ 为偶数：加；
    
- 空集大小为 $0$，对应没有任何超限限制的全部方案，应当加。
    

---

<div id="section-6" class="note-anchor"></div>

### 3. 组合数上标很大、下标很小时，只乘下标项数

本题组合数形如：


$$
C(X,N-1)
$$


其中 $X$ 可能达到 $10^{14}$，不能预处理到 `fac[X]`。

但：


$$
N-1\le19
$$


所以直接使用：


$$
C(X,k)=\frac{X(X-1)\cdots(X-k+1)}{k!}
$$


只需进行 $k\le19$ 次乘法。

模意义下：

```cpp
res = res * ((X - i) % mod) % mod;
res = res * ifac[k] % mod;
```

因为 $k<10^9+7$，所以 $k!$ 不含模数因子，可以使用费马小定理求逆元。

---

<div id="section-7" class="note-anchor"></div>

## 从朴素思路到关键转折

<div id="section-8" class="note-anchor"></div>

### 1. 直接 DP 为什么不行

最自然的做法是：

```text
dp[i][j] = 使用前 i 种颜色，选择 j 枝花的方案数
```

但：


$$
M\le10^{14}
$$


无法开出大小为 $M$ 的数组，也无法枚举所有花数。

<div id="section-9" class="note-anchor"></div>

### 2. 忽略上限后可以直接计数

暂时不考虑 $x_i\le A_i$，只要求：


$$
x_1+x_2+\cdots+x_N=M,\qquad x_i\ge0
$$


使用 $M$ 个星号和 $N-1$ 个隔板：

- 总符号数为 $M+N-1$；
    
- 选择 $N-1$ 个位置放隔板。
    

因此方案数为：


$$
C(M+N-1,N-1)
$$


<div id="section-10" class="note-anchor"></div>

### 3. 真正的转折

上限不好直接加入隔板法，但“超过上限”的方案可以通过变量平移重新变成普通非负整数解。

因此改为：

> 先统计全部方案，再用容斥删除至少一个变量超限的方案。

---

<div id="section-11" class="note-anchor"></div>

## 核心推导

<div id="section-12" class="note-anchor"></div>

### 1. 不考虑上限


$$
x_1+x_2+\cdots+x_N=M
$$


的非负整数解数量为：


$$
C(M+N-1,N-1)
$$


<div id="section-13" class="note-anchor"></div>

### 2. 固定一个超限集合

选择盒子集合 $S$，要求所有 $i\in S$ 都满足：


$$
x_i\ge A_i+1
$$


对每个 $i\in S$，令：


$$
y_i=x_i-(A_i+1)
$$


得到：


$$
\sum_{i\notin S}x_i+\sum_{i\in S}y_i=M-\sum_{i\in S}(A_i+1)
$$


所有变量仍然非负，变量总数仍然是 $N$。

设：


$$
left=M-\sum_{i\in S}(A_i+1)
$$


则方案数为：


$$
C(left+N-1,N-1)
$$


若 $left<0$，方案数为 $0$。

<div id="section-14" class="note-anchor"></div>

### 3. 按集合大小容斥

最终答案为：


$$
\sum_{S\subseteq{1,\dots,N}}(-1)^{|S|}  
C\left(M-\sum_{i\in S}(A_i+1)+N-1,N-1\right)
$$


空集贡献：


$$
C(M+N-1,N-1)
$$


---

<div id="section-15" class="note-anchor"></div>

## 为什么正确

考虑任意一组无上限方程的解，假设它恰好违反了 $t$ 个变量的上限。

<div id="section-16" class="note-anchor"></div>

### 如果它是合法方案

此时 $t=0$，它只会出现在空集对应的计数中，最终贡献为 $1$。

<div id="section-17" class="note-anchor"></div>

### 如果它是非法方案

它会被所有由这 $t$ 个超限变量组成的子集统计。

最终贡献为：


$$
C(t,0)-C(t,1)+C(t,2)-\cdots+(-1)^tC(t,t)
$$


根据二项式定理：


$$
(1-1)^t=0
$$


因此任何至少违反一个上限的方案最终贡献都为 $0$。

所以：

- 每个合法方案恰好保留一次；
    
- 每个非法方案最终全部抵消。
    

答案正确。

---

<div id="section-18" class="note-anchor"></div>

## 样例推演

设：


$$
N=3,\qquad M=5,\qquad A=[1,3,2]
$$


不考虑上限：


$$
C(5+3-1,3-1)=C(7,2)=21
$$


单个变量超限：

- $x_1\ge2$：剩余 $5-2=3$，有 $C(5,2)=10$ 种；
    
- $x_2\ge4$：剩余 $5-4=1$，有 $C(3,2)=3$ 种；
    
- $x_3\ge3$：剩余 $5-3=2$，有 $C(4,2)=6$ 种。
    

两个变量同时超限：

- $x_1\ge2$ 且 $x_3\ge3$：剩余 $5-2-3=0$，有 $C(2,2)=1$ 种；
    
- 其他二元交集剩余数量为负，贡献为 $0$。
    

因此：


$$
21-10-3-6+1=3
$$

<div id="section-19" class="note-anchor"></div>

## 复杂度

一共有 $2^N$ 个超限集合。

通过：

```cpp
lowbit = st & -st;
pre = st ^ lowbit;
```

可以由前驱集合在 $O(1)$ 时间计算当前集合的限制总和。

每个状态计算一次组合数，需要乘 $N-1$ 项，因此时间复杂度为：


$$
O(2^N\cdot N)
$$


空间复杂度为：


$$
O(2^N)
$$


当 $N\le20$ 时，可以通过。

---

<div id="section-20" class="note-anchor"></div>

## 识别信号

当题目出现以下结构时，可以考虑这种方法：

- 要统计 $N$ 个非负整数之和等于一个很大的数；
    
- 每个变量都有独立上限；
    
- 总和太大，无法使用背包 DP；
    
- 变量数量较少，可以枚举哪些限制被违反；
    
- 去掉上限后可以使用隔板法直接计算；
    
- 某个变量违反限制后，可以通过减去固定下限转化为普通非负变量。
    

---

<div id="section-21" class="note-anchor"></div>

## 适用边界

1. 状压容斥依赖 $N$ 较小。若 $N$ 达到几十甚至上百，$2^N$ 无法接受。
    
2. 隔板法要求变量是非负整数，不能直接用于实数解或带其他耦合限制的情况。
    
3. 当前组合数算法依赖下标 $N-1$ 很小。若组合数上下标都很大，需要考虑 Lucas 定理或其他组合数算法。
    
4. 使用费马逆元要求模数为质数，且分母在模意义下不为 $0$。
    
5. 若各变量之间还有相互影响，例如 $x_i+x_j\le B$，只对单变量上限做容斥已经不足。
    

---

<div id="section-22" class="note-anchor"></div>

## 本题暴露的问题

<div id="section-23" class="note-anchor"></div>

### 1. 没有区分“原方程”和“超限子集”

原方程只要求：


$$
x_1+\cdots+x_N=M,\qquad x_i\ge0
$$


而 $x_i\ge A_i+1$ 是为了统计某一类非法方案额外加入的条件，不是原方程本身的约束。

<div id="section-24" class="note-anchor"></div>

### 2. 一度没有理解变量平移为什么数量相等

关键不是两个方程形式相似，而是：

```text
原超限解  <->  减去 Ai+1 后的新方程解
```

转换可以唯一正向执行，也可以唯一反向还原，因此是双射。

<div id="section-25" class="note-anchor"></div>

### 3. 把选中集合大小当成了变量数量

即使集合 $S$ 中有 `cnt` 个盒子超限，平移后的方程仍然有 $N$ 个变量。

所以组合数下标始终是：

```cpp
n - 1
```

而不是：

```cpp
cnt - 1
```

<div id="section-26" class="note-anchor"></div>

### 4. 没有区分真实数量和模意义结果

以下变量表示真实花数，不能提前取模：

```cpp
m
a[i]
sum
left
```

以下量表示方案数，可以取模：

```cpp
fac
ifac
C(...)
ans
```

如果对 `sum` 取模，会破坏 `left = m - sum` 的真实大小关系。

<div id="section-27" class="note-anchor"></div>

### 5. 组合数实现中的边界与溢出

计算 $C(a,b)$ 时分子应恰好乘 $b$ 项：

```cpp
a,a-1,...,a-b+1
```

并且 `a` 可能达到 $10^{14}$，必须先取模再与 `res` 相乘：

```cpp
res = res * ((a - i) % mod) % mod;
```

否则中间乘积可能超过 `long long`。

---

<div id="section-28" class="note-anchor"></div>

## 实现时最容易错的地方

- 状压枚举的是 $N$ 个盒子的子集，应使用 `1LL << n`，不是 `1LL << m`；
    
- 空集对应无限制方案，符号为正；
    
- 每选中一个盒子，应累加 `a[pos] + 1`，不是 `a[pos]`；
    
- 一个子集只计算一次组合数，不能在枚举集合元素的 `while` 中重复计算；
    
- `left = m - sum` 可能为负，此时组合数为 $0$；
    
- 变量数量始终是 $N$，组合数下标始终是 `n - 1`；
    
- `sum` 保存真实数量，不能对 `mod` 取模；
    
- `C(a,b)` 的上标可能很大，不能访问 `fac[a]`；
    
- `__builtin_ctzll` 的参数必须非零；
    
- 位运算使用 `1LL << n`，避免整数类型问题。

## 复习时反问

1. 为什么统计 $x_i\ge A_i+1$ 的方案时，可以把右边改成 $M-A_i-1$？请用一一对应解释，而不是只说“移项”。
    
2. 当三个变量同时超限时，为什么这个方案最终会在容斥中被完全抵消？
    
3. 为什么选择了 `cnt` 个超限变量后，组合数的下标仍然是 `n - 1`？
    
4. 为什么 `sum` 不能取模，而组合数计算过程必须取模？

## 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long

const int mod = 1e9 + 7;

int n,m;
int fac[25],ifac[25];

int qp(int a,int b){
    int res = 1;
    while(b){
        if(b & 1)res = res * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}

void init(){
    fac[0] = 1;
    for(int i=1;i<=24;i++){
        fac[i] = fac[i - 1] * i % mod;
    }

    ifac[24] = qp(fac[24],mod - 2);
    for(int i=24;i>=1;i--){
        ifac[i - 1] = ifac[i] * i % mod;
    }
}

// 计算 C(a,b)，其中 a 可能达到 1e14，b <= 19
int C(int a,int b){
    if(a < 0 || a < b)return 0;

    int res = 1;
    for(int i=0;i<b;i++){
        res = res * ((a - i) % mod) % mod;
    }

    return res * ifac[b] % mod;
}

void O_o(){
    cin >> n >> m;

    vector<int> a(n);
    for(int &x : a){
        cin >> x;
    }

    int lim = 1LL << n;
    vector<int> sum(lim,0);

    int ans = 0;

    // st = 0 是空集，对应没有任何盒子被强制超限
    for(int st=0;st<lim;st++){
        if(st){
            int lowbit = st & -st;
            int pos = __builtin_ctzll(lowbit);
            int pre = st ^ lowbit;

            sum[st] = sum[pre] + a[pos] + 1;
        }

        int left = m - sum[st];
        int num = C(left + n - 1,n - 1);
        int cnt = __builtin_popcountll(st);

        if(cnt & 1){
            ans = (ans - num + mod) % mod;
        }else{
            ans = (ans + num) % mod;
        }
    }

    cout << ans << '\n';
}

signed main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    init();
    O_o();

    return 0;
}
```
