> **存放建议  **
> **等级：** C 类·基础巩固题  
> **CF 等效评分：** 约 1300～1400  
> **理由：** 核心是基础容斥原理，但需要把质数集合转化为二进制子集，并正确处理空集、奇偶贡献与乘积剪枝。

<div id="section-1" class="note-anchor"></div>

## 抽象题目

给定整数 $n$ 和 $m$ 个互不相同的质数，求 $1\sim n$ 中至少能被其中一个质数整除的整数数量。

每个整数可能同时被多个质数整除，因此直接把各质数倍数的数量相加会发生重复统计。

<div id="section-2" class="note-anchor"></div>

## 一句话本质

枚举所有非空质数子集，根据子集大小的奇偶性，对“同时被这些质数整除的整数数量”进行加减。

<div id="section-3" class="note-anchor"></div>

## 本题学到的具体东西

<div id="section-4" class="note-anchor"></div>

### 1. 用二进制状态枚举容斥中的所有集合

用 `st` 的第 $i$ 位表示是否选择质数 `p[i]`：

```cpp
st & (1 << i)
```

- 第 $i$ 位为 `1`：选择 `p[i]`；
    
- 第 $i$ 位为 `0`：不选择 `p[i]`。
    

一共有：


$$
2^m
$$


个子集。

容斥只需要枚举非空子集，因此范围是：

```cpp
1 ~ (1 << m) - 1
```

不能从 `0` 开始，因为空集的乘积为 `1`，会错误地把全部 $n$ 个数减去。

---

<div id="section-5" class="note-anchor"></div>

### 2. 用 lowbit 只枚举状态中为 1 的位置

```cpp
int tmp = st;

while(tmp){
    int lowbit = tmp & -tmp;
    int pos = __builtin_ctz(lowbit);

    mul *= p[pos];

    tmp ^= lowbit;
}
```

其中：

- `tmp & -tmp` 取出最低位的一个 `1`；
    
- `__builtin_ctz(lowbit)` 得到这一位的位置；
    
- `tmp ^= lowbit` 删除这一位。
    

例如：

```text
tmp = 10110
```

依次枚举的位置是：

```text
1、2、4
```

适用信号：

> 当前状态表示一个集合，并且只需要遍历集合中实际存在的元素。

需要区分：

- `lowbit`：枚举集合中的每个元素；
    
- `(sub - 1) & mask`：枚举一个集合的所有子集。
    

---

<div id="section-6" class="note-anchor"></div>

### 3. 容斥的正负号可以由子集大小决定

设当前子集中选择了 $k$ 个质数。

- $k$ 为奇数：加；
    
- $k$ 为偶数：减。
    

因此：

```cpp
int cnt = __builtin_popcount(st);

if(cnt & 1){
    ans += n / mul;
}else{
    ans -= n / mul;
}
```

原因是：

- 单个集合先加入；
    
- 两两交集被重复计算，需要减去；
    
- 三个集合的交集又被减多了，需要加回来；
    
- 此后不断交替。
    

---

<div id="section-7" class="note-anchor"></div>

### 4. 本题中“先乘再判断”不会溢出

代码使用：

```cpp
mul *= p[pos];

if(mul > n){
    ok = 0;
    break;
}
```

一般情况下，先乘再判断可能已经发生乘法溢出。

但本题满足：


$$
n\le 10^9,\qquad p_i\le 10^9
$$


并且乘积一旦超过 $n$ 就立即退出。

分情况讨论：

<div id="section-8" class="note-anchor"></div>

#### 第一次乘完就超过 $n$

此时：


$$
mul=p_i\le 10^9
$$


不会溢出。

<div id="section-9" class="note-anchor"></div>

#### 第一次乘完没有超过 $n$

此时：


$$
mul\le n\le 10^9
$$


第二次乘法最大为：


$$
10^9\times10^9=10^{18}
$$


而 `long long` 最大值约为：


$$
9.22\times10^{18}
$$


所以第二次乘法仍然安全。

如果第二次乘完超过 $n$，程序立即退出，不会继续乘第三次。

因此，本题中最多在安全范围内完成两次乘法，不会溢出 `long long`。

更通用的防溢出写法是：

```cpp
if(mul > n / p[pos]){
    ok = 0;
    break;
}

mul *= p[pos];
```

但在当前数据范围和剪枝条件下，两种写法都正确。

<div id="section-10" class="note-anchor"></div>

## 从朴素思路到关键转折

最直接的想法是分别统计：


$$
\left\lfloor\frac n{p_1}\right\rfloor,  
\left\lfloor\frac n{p_2}\right\rfloor,\dots
$$


然后把它们相加。

问题是，一个整数可能同时被多个质数整除，因此会被重复计算。

例如 $n=10$，质数为 $2,3$：

- 2 的倍数有 5 个；
    
- 3 的倍数有 3 个；
    
- 6 同时属于两个集合，被统计了两次。
    

所以需要：


$$
\left\lfloor\frac{10}{2}\right\rfloor+  
\left\lfloor\frac{10}{3}\right\rfloor-  
\left\lfloor\frac{10}{2\times3}\right\rfloor  
=5+3-1=7
$$


当质数数量增加时，必须枚举所有质数子集，按照容斥规律加减。

由于 $m\le16$，可以枚举全部 $2^m$ 个子集。

<div id="section-11" class="note-anchor"></div>

## 核心推导

<div id="section-12" class="note-anchor"></div>

### 1. 一个子集代表哪些整数

假设当前选择的质数为：


$$
p_{i_1},p_{i_2},\dots,p_{i_k}
$$


因为它们是互不相同的质数，所以最小公倍数就是它们的乘积：


$$
mul=p_{i_1}p_{i_2}\cdots p_{i_k}
$$


同时被这些质数整除的整数，就是 $mul$ 的倍数，数量为：


$$
\left\lfloor\frac n{mul}\right\rfloor
$$


<div id="section-13" class="note-anchor"></div>

### 2. 根据子集大小决定贡献

如果子集大小为奇数：


$$
ans\mathrel{+}=\left\lfloor\frac n{mul}\right\rfloor
$$


如果子集大小为偶数：


$$
ans\mathrel{-}=\left\lfloor\frac n{mul}\right\rfloor
$$


<div id="section-14" class="note-anchor"></div>

### 3. 乘积超过 n 后可以停止

如果：


$$
mul>n
$$


那么：


$$
\left\lfloor\frac n{mul}\right\rfloor=0
$$


而继续乘其他质数，只会让乘积更大。

因此当前子集贡献一定为 $0$，可以直接跳过。

<div id="section-15" class="note-anchor"></div>

## 为什么正确

考虑任意一个整数 $x\in[1,n]$，假设它恰好能被给出的 $k$ 个质数整除。

在容斥过程中，它会出现在这 $k$ 个质数组成的所有非空子集中。

它最终被统计的次数为：


$$
\binom{k}{1}-\binom{k}{2}+\binom{k}{3}-\cdots+(-1)^{k+1}\binom{k}{k}
$$


由二项式展开：


$$
(1-1)^k=\binom{k}{0}-\binom{k}{1}+\binom{k}{2}-\cdots+(-1)^k\binom{k}{k}=0
$$


移项可得：


$$
\binom{k}{1}-\binom{k}{2}+\cdots+(-1)^{k+1}\binom{k}{k}=1
$$


所以：

- 只要 $x$ 能被至少一个质数整除，最终恰好被统计一次；
    
- 如果 $x$ 不能被任何质数整除，它不会出现在任何子集中，贡献为 0。
    

因此答案正好是满足条件的整数数量。

<div id="section-16" class="note-anchor"></div>

## 复杂度

一共枚举：


$$
2^m-1
$$


个非空子集。

每个子集最多枚举 $m$ 个二进制位，因此时间复杂度为：


$$
O(2^m\cdot m)
$$


当 $m=16$ 时，运算次数大约为：


$$
65536\times16
$$


可以轻松通过。

空间复杂度为：


$$
O(m)
$$


只保存 $m$ 个质数。

<div id="section-17" class="note-anchor"></div>

## 识别信号

当题目出现以下结构时，可以考虑容斥原理：

- 求满足“至少一个条件”的对象数量；
    
- 每个条件单独统计很容易；
    
- 一个对象可能同时满足多个条件；
    
- 条件数量较少，可以枚举所有条件子集；
    
- 交集数量可以通过乘积、最小公倍数或其他简单方式计算。
    

当题目出现：

> $m\le 20$ 左右，并且需要枚举若干条件的组合

应考虑使用二进制状态枚举子集。

<div id="section-18" class="note-anchor"></div>

## 适用边界

<div id="section-19" class="note-anchor"></div>

### 1. 质数不同时，交集才直接使用乘积

本题给出的是互不相同的质数，所以：


$$
\operatorname{lcm}(p_{i_1},\dots,p_{i_k})  
=p_{i_1}\cdots p_{i_k}
$$


如果给出的是任意整数，不能直接相乘，需要使用最小公倍数：


$$
\operatorname{lcm}(a,b)=\frac{a}{\gcd(a,b)}\times b
$$


<div id="section-20" class="note-anchor"></div>

### 2. m 必须较小

当前方法需要枚举 $2^m$ 个子集。

如果 $m$ 达到几十或上百，无法直接使用状态压缩枚举。

<div id="section-21" class="note-anchor"></div>

### 3. 更大数据范围下需要乘前判断

本题中先乘再判断是安全的。

但如果：

- $n$ 或 $p_i$ 大于 $10^9$；
    
- 乘积超过 $n$ 后没有立即退出；
    
- 使用的整数类型范围更小；
    

则需要在乘法前判断：

```cpp
if(mul > n / p[pos])
```

<div id="section-22" class="note-anchor"></div>

## 本题暴露的问题

<div id="section-23" class="note-anchor"></div>

### 1. 最开始把质数数组开成了 n

曾写成：

```cpp
vector<int> p(n);
```

但输入只有 $m$ 个质数，正确大小应为：

```cpp
vector<int> p(m);
```

而且 $n$ 最大为 $10^9$，按 `n` 开数组会直接导致内存超限。

<div id="section-24" class="note-anchor"></div>

### 2. 最开始枚举了空集

如果从：

```cpp
st = 0
```

开始，空集时：

```cpp
mul = 1;
cnt = 0;
```

会执行：

```cpp
ans -= n;
```

这是错误的。

容斥只枚举非空子集，因此必须从：

```cpp
st = 1
```

开始。

<div id="section-25" class="note-anchor"></div>

### 3. 原题没有测试组数

题目输入第一行直接是：

```text
n m
```

不能使用：

```cpp
cin >> T;
while(T--)O_o();
```

应设置：

```cpp
T = 1;
while(T--)O_o();
```

<div id="section-26" class="note-anchor"></div>

### 4. 对溢出判断需要结合具体数据范围

不能只看到“先乘再判断”就直接认定一定溢出。

本题需要结合：

- `n,p[i] <= 1e9`；
    
- 乘积超过 `n` 后立即退出；
    

推导出最多只会安全地乘到 $10^{18}$。

说明判断溢出时，要分析变量可能达到的真实上界，而不是只套通用结论。

<div id="section-27" class="note-anchor"></div>

## 实现时最容易错的地方

- 质数数组大小应为 `m`，不是 `n`；
    
- 子集必须从 `1` 开始，不能包括空集；
    
- 原题只有一组数据；
    
- 奇数大小子集加，偶数大小子集减；
    
- `lowbit` 枚举的是选中的元素，不是所有子集；
    
- `__builtin_ctz` 不能传入 `0`；
    
- 质数不同，因此交集对应乘积；
    
- 乘积超过 `n` 后，该子集贡献为 `0`；
    
- 如果修改数据范围，需要重新判断乘法是否可能溢出。
    

<div id="section-28" class="note-anchor"></div>

## 复习时反问

1. 为什么容斥只需要根据子集大小的奇偶性决定加减？
    
2. 为什么本题中同时被若干质数整除的数量是 `n / mul`？
    
3. 为什么本题先执行 `mul *= p[pos]` 再判断 `mul > n` 仍然不会溢出？
    
4. 如果输入的是不同的合数而不是质数，当前乘积写法需要怎样修改？

## 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long
#define rep(i,l,r) for(int i=(l);i<=(r);i++)
#define all() a.begin() + 1,a.begin() + n + 1
#define pii pair<int,int>
#define V vector
#define F first
#define S second
#define pb push_back
#define is insert
const int inf = 1e18,N = 2e5 + 10;
const double pi = acos(-1);

// --------------- AC ---------------
int T,n,m;

void O_o(){
    cin >> n >> m;

    V<int> p(m);
    for(int &x : p)cin >> x;

    int ans = 0;

    rep(st,1,(1 << m) - 1){
        int tmp = st;
        int mul = 1;
        bool ok = 1;

        while(tmp){
            int lowbit = tmp & -tmp;
            int pos = __builtin_ctz(lowbit);

            mul *= p[pos];

            // 本题中乘积最大安全到 1e18，超过 n 后立即停止
            if(mul > n){
                ok = 0;
                break;
            }

            tmp ^= lowbit;
        }

        if(!ok)continue;

        int cnt = __builtin_popcount(st);

        if(cnt & 1){
            ans += n / mul;
        }else{
            ans -= n / mul;
        }
    }

    cout << ans << '\n';
}

signed main(){
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    T = 1;
    while(T--)O_o();

    return 0;
}
```
