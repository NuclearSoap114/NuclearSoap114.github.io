## 概率公式

| 名称 | 公式 |
|------|------|
| 加法 | $P(A \cup B) = P(A) + P(B) - P(AB)$ |
| 三事件 | $P(A \cup B \cup C) = \sum P - \sum P(\text{对}) + P(ABC)$ |
| 减法 | $P(A-B) = P(A) - P(AB)$ |
| 对立 | $P(\overline{A}) = 1 - P(A)$ |
| 条件 | $P(A \mid B) = \frac{P(AB)}{P(B)}$ |
| 乘法 | $P(AB) = P(B) \cdot P(A \mid B)$ |
| 全概率 | $P(A) = \sum_i P(B_i) P(A \mid B_i)$ |
| 贝叶斯 | $P(B_i \mid A) = \frac{P(B_i) P(A \mid B_i)}{\sum_j P(B_j) P(A \mid B_j)}$ |
| 伯努利 | $P_n(k) = C_n^k p^k (1-p)^{n-k}$ |

## 密度与分布

| 名称 | 公式 |
|------|------|
| 分布函数 | $F(x) = P(X \leq x) = \int_{-\infty}^x f(t)dt$ |
| 密度 | $f(x) = F'(x)$ |
| 区间概率 | $P(a<X<b) = F(b)-F(a) = \int_a^b f$ |
| 规范性 | $\int_{-\infty}^{+\infty} f = 1$ |
| 离散跳跃 | $p_i = F(x_i) - F(x_i^-)$ |

## 常见分布

| 分布 | 密度/分布律 | $E$ | $D$ |
|------|-----------|-----|-----|
| $B(1,p)$ | $P(0)=1-p, P(1)=p$ | $p$ | $p(1-p)$ |
| $B(n,p)$ | $C_n^k p^k(1-p)^{n-k}$ | $np$ | $np(1-p)$ |
| $P(\lambda)$ | $\frac{\lambda^k}{k!}e^{-\lambda}$ | $\lambda$ | $\lambda$ |
| $U(a,b)$ | $f=\frac{1}{b-a}$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| $N(\mu,\sigma^2)$ | $f=\frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu$ | $\sigma^2$ |

## 正态分布

| 名称 | 公式 |
|------|------|
| 标准化 | $Z = \frac{X-\mu}{\sigma} \sim N(0,1)$ |
| 对称性 | $\Phi(-x) = 1 - \Phi(x)$ |
| $\Phi(0)$ | $\frac{1}{2}$ |
| 概率 | $\Phi(\frac{b-\mu}{\sigma}) - \Phi(\frac{a-\mu}{\sigma})$ |
| $1\sigma/2\sigma/3\sigma$ | 68.3% / 95.5% / 99.7% |

## 多维随机变量

| 概念 | 离散型 | 连续型 |
|------|--------|--------|
| 规范性 | $\sum\sum p_{ij}=1$ | $\iint f = 1$ |
| 边缘 $X$ | 行相加 | $f_X = \int f dy$ |
| 边缘 $Y$ | 列相加 | $f_Y = \int f dx$ |
| 条件 | $\frac{p_{ij}}{p_{\cdot j}}$ | $f/f_Y$ |
| 独立 | $p_{ij} = p_{i\cdot}p_{\cdot j}$ | $f = f_X f_Y$ |

## 数字特征

| 名称 | 公式 |
|------|------|
| 期望 | $E(X) = \sum x_i p_i$ 或 $\int x f dx$ |
| 方差 | $D(X) = E(X^2) - E^2(X)$ |
| $D(cX)$ | $c^2 D(X)$ |
| 独立 $D(X \pm Y)$ | $D(X) + D(Y)$ |
| 一般 $D(X \pm Y)$ | $D(X) + D(Y) \pm 2\text{Cov}$ |
| 协方差 | $\text{Cov} = E(XY) - E(X)E(Y)$ |
| 相关系数 | $\rho = \text{Cov} / (\sqrt{D(X)}\sqrt{D(Y)})$ |
| 切比雪夫 | $P(\vert X-E\vert  \geq \varepsilon) \leq D/\varepsilon^2$ |
