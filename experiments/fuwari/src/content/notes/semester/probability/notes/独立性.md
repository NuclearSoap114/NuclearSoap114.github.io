## 一、离散型

来源：PDF第8页 — "每行成比例 = 独立，otherwise 不独立"

对所有 $i,j$：


$$
p_{ij} = p_{i\cdot} \cdot p_{\cdot j}
$$


联合概率 = 行和 × 列和。找到一个反例即可断定不独立。

<div id="section-2" class="note-anchor"></div>

## 二、连续型

来源：PDF第9页 — "独立 $\iff f(x,y) = f_X(x) f_Y(y)$"


$$
f(x,y) = f_X(x) \cdot f_Y(y)
$$


---

<div id="section-3" class="note-anchor"></div>

## 三、重要推论

- $X,Y$ 独立 $\Rightarrow E(XY) = E(X)E(Y)$
- $X,Y$ 独立 $\Rightarrow \text{Cov}(X,Y) = 0$
- $X,Y$ 独立 $\Rightarrow D(X \pm Y) = D(X) + D(Y)$

> **不相关不等于独立**
> $\text{Cov} = 0$ 不能反推独立。唯一例外是二维正态分布。

## 经典例题

**1. 判断 $X$ 与 $Y$ 是否独立：**

| $X \setminus Y$ | 0 | 1 |
|---|---|---|
| 0 | 0.15 | 0.35 |
| 1 | 0.15 | 0.35 |

$P(X=0)=0.5$，$P(X=1)=0.5$；$P(Y=0)=0.3$，$P(Y=1)=0.7$

$p_{00}=0.15 = 0.5 \times 0.3$，四个格子全满足，独立。

**2. $f(x,y) = \begin{cases} 4xy & 0 < x < 1,\, 0 < y < 1 \\ 0 & \text{其他} \end{cases}$。$X,Y$ 是否独立？**

$f_X(x) = 2x$，$f_Y(y) = 2y$。$f_X f_Y = 4xy = f(x,y)$，独立。

**3. $f(x,y) = \begin{cases} x+y & 0 < x < 1,\, 0 < y < 1 \\ 0 & \text{其他} \end{cases}$。$X,Y$ 是否独立？**

$f_X(x) = x + 1/2$，$f_Y(y) = y + 1/2$。$f_X f_Y \neq x+y$，不独立。

## 易错点

| 易错点 | 正确理解 |
|--------|----------|
| 不相关推独立 | 不相关 ≠ 独立 |
| $D(X+Y) = D(X)+D(Y)$ 恒成立 | 仅当独立 |
| $E(XY) = E(X)E(Y)$ 恒成立 | 仅当独立 |

## 考试重点

1. 离散：$p_{ij} = p_{i\cdot} p_{\cdot j}$ 逐格验证
2. 连续：$f = f_X f_Y$
3. 独立 → 不相关，但反向不成立
4. 独立 → $D(X \pm Y) = D(X) + D(Y)$
