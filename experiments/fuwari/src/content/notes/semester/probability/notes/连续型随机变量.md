## 一、概率密度

若存在 $f(x) \geq 0$，使 $P(a < X \leq b) = \int_a^b f(x)dx$，则 $f(x)$ 为概率密度。

注意：$f(x)$ 本身不是概率，$\int f dx$ 才是。$f(x)$ 可以大于 1。

**性质**：$f(x) \geq 0$、$\int_{-\infty}^{+\infty} f = 1$、$P(X=a) = 0$。

单点概率为 0，所以连续型变量区间概率与开闭无关。

## 二、$f(x)$ 与 $F(x)$ 的关系


$$
F(x) = \int_{-\infty}^x f(t)dt, \qquad f(x) = F'(x) \; (\text{在连续点})
$$



$$
P(a < X \leq b) = F(b) - F(a) = \int_a^b f(x)dx
$$

## 三、三类核心题型

<div id="section-4" class="note-anchor"></div>

### 题型1：已知 $f(x)$ 求参数

用 $\int_{-\infty}^{+\infty} f(x)dx = 1$ 解出参数。

<div id="section-5" class="note-anchor"></div>

### 题型2：已知 $f(x)$ 求 $F(x)$

$F(x) = \int_{-\infty}^x f(t)dt$，按 $f(x)$ 的分段积分。

关键：分段点处 $F(x)$ 必须连续（$P(X=a)=0$ 的必然要求）。验证 $F(-\infty)=0$，$F(+\infty)=1$。

<div id="section-6" class="note-anchor"></div>

### 题型3：已知 $F(x)$ 求 $f(x)$

$f(x) = F'(x)$，在可导点求导。

## 经典例题

**1. 设 $f(x) = \begin{cases} kx & 0 \leq x \leq 2 \\ 0 & \text{其他} \end{cases}$。求 $k$、$F(x)$、$P(0.5 < X < 1.5)$。**

(1) $\int_0^2 kx dx = 2k = 1 \Rightarrow k = \frac{1}{2}$

(2) $F(x) = \frac{x^2}{4}$（$0 \leq x < 2$）


$$
F(x) = \begin{cases} 0 & x < 0 \\ x^2/4 & 0 \leq x < 2 \\ 1 & x \geq 2 \end{cases}
$$


(3) $P(0.5 < X < 1.5) = F(1.5) - F(0.5) = \frac{2.25}{4} - \frac{0.25}{4} = 0.5$

**2. 设 $f(x) = \begin{cases} 2x & 0 < x < 1 \\ 0 & \text{其他} \end{cases}$。求 $E(X)$ 和 $D(X)$。**

$E(X) = \int_0^1 x \cdot 2x dx = \frac{2}{3}$

$E(X^2) = \int_0^1 x^2 \cdot 2x dx = \frac{1}{2}$

$D(X) = \frac{1}{2} - \frac{4}{9} = \frac{1}{18}$

## 易错点

| 易错点 | 正确理解 |
|--------|----------|
| $f(x)$ 是概率 | $f(x)dx$ 才是微元概率 |
| $F(x)$ 在分段点中断 | $F(x)$ 处处连续 |
| 积分忘分段 | $f(x)$ 分段定义，积分也必须分段 |

## 考试重点

1. 已知 $f$ 求参数 → $\int f = 1$
2. 已知 $f$ 求 $F$ → 分段积分 + 分段点连续
3. 已知 $F$ 求 $f$ → 求导
4. 区间概率：$F(b)-F(a)$ 或直接积分
