## 一、事件关系与概率公式

| 题型 | 方法 |
|------|------|
| 判断互斥/对立/独立 | 从定义逐条验证 |
| 求 $P(A \cup B)$、$P(A-B)$ | 套加法/减法公式 |
| 验证独立性 | $P(AB) \stackrel{?}{=} P(A)P(B)$ |
| De Morgan | $\overline{A \cup B} = \overline{A} \cap \overline{B}$ |

<div id="section-2" class="note-anchor"></div>

## 二、全概率与贝叶斯

全概率：找完备事件组 → 验证 $\sum P(B_i)=1$ → $P(A) = \sum P(B_i)P(A \mid B_i)$

贝叶斯：$P(B_i \mid A) = \frac{P(B_i)P(A \mid B_i)}{\sum P(B_j)P(A \mid B_j)}$

## 三、伯努利概型

1. 确认三个条件：独立 + 两种结果 + $p$ 不变
2. $P_n(k) = C_n^k p^k (1-p)^{n-k}$
3. "至少 $k$ 次" → 拆成多个"恰好"

## 四、随机变量与分布

| 题型 | 方法 |
|------|------|
| 求分布律 | 先求取值，再求概率 |
| 已知 $f$ 求参数 | $\int f = 1$ |
| 已知 $f$ 求 $F$ | 分段积分，分段点连续 |
| 已知 $F$ 求 $f$ | $F'(x)$ |
| 区间概率 | $F(b)-F(a)$ 或 $\int_a^b f$ |
| $F$ 求分布律（离散） | $p_i = F(x_i) - F(x_i^-)$ |

## 五、正态分布

标准流程：标准化 $Z = \frac{X-\mu}{\sigma}$ → 查表 → $P = \Phi(z_b) - \Phi(z_a)$

核心公式：$\Phi(0) = 0.5$，$\Phi(-x) = 1 - \Phi(x)$

---

## 六、变量函数分布

$F_Y(y) = P(g(X) \leq y)$ → 解出 $X$ 范围 → 积分 → 按 $y$ 分段 → $f_Y = F_Y'$

## 七、多维随机变量

| 题型 | 离散型 | 连续型 |
|------|--------|--------|
| 求参数 | $\sum\sum p_{ij}=1$ | $\iint f = 1$ |
| 边缘 | 行/列相加 | $\int f\,dy$ |
| 条件 | $\frac{p_{ij}}{p_{\cdot j}}$ | $\frac{f}{f_Y}$ |
| 独立性 | $p_{ij} = p_{i\cdot}p_{\cdot j}$ | $f = f_X f_Y$ |

## 八、数字特征

| 题型 | 方法 |
|------|------|
| $E(X)$ | $\sum x_i p_i$ 或 $\int x f dx$ |
| $D(X)$ | $E(X^2) - E^2(X)$ |
| $\text{Cov}$ | $E(XY) - E(X)E(Y)$ |
| $\rho$ | $\text{Cov} / (\sqrt{D(X)}\sqrt{D(Y)})$ |
| 切比雪夫 | $P(\vert X-E\vert  \geq \varepsilon) \leq D/\varepsilon^2$ |

## 高频易错点

<div id="section-10" class="note-anchor"></div>

### 方差与系数

| 错误 | 正确 |
|------|------|
| $D(cX) = cD(X)$ | $D(cX) = c^2 D(X)$ |
| $D(2X) = 2D(X)$ | $D(2X) = 4D(X)$ |

<div id="section-11" class="note-anchor"></div>

### 独立性

| 错误 | 正确 |
|------|------|
| $D(X \pm Y) = D(X)+D(Y)$ 总成立 | 仅当 $X,Y$ 独立 |
| $E(XY) = E(X)E(Y)$ 总成立 | 仅当 $X,Y$ 独立 |
| 不相关 = 独立 | 不相关 ≠ 独立 |
| 互不相容 → 独立 | 互斥且 $P>0$ → 不独立 |

<div id="section-12" class="note-anchor"></div>

### 连续型

| 错误 | 正确 |
|------|------|
| $P(X=a) > 0$ | 连续型单点概率为 0 |
| 区间开闭影响概率 | 连续型中完全相同 |
| $f(x)$ 是概率 | $f(x)dx$ 才是概率微元 |

<div id="section-13" class="note-anchor"></div>

### 正态分布

| 错误 | 正确 |
|------|------|
| $\Phi(-x) = -\Phi(x)$ | $\Phi(-x) = 1 - \Phi(x)$ |
| 标准化除以 $\sigma^2$ | 除以 $\sigma$（标准差） |

### 其他

| $P(A-B) = P(A) - P(B)$ | $P(A-B) = P(A) - P(AB)$ |
