## 分布函数法

来源：PDF第7页 — "已知 $f_X$，求 $Y = g(X)$ 的分布函数 $F_Y(y)$"

1. $F_Y(y) = P(Y \leq y) = P(g(X) \leq y)$
2. 解出 $X$ 的范围，用 $f_X$ 积分
3. **按 $y$ 的不同区间分段讨论**
4. $f_Y(y) = F_Y'(y)$

---

<div id="section-2" class="note-anchor"></div>

## 经典例题

**1. $X \sim U(0, 1)$，$Y = 2X + 1$。求 $f_Y(y)$。**

$g$ 单调递增，$h(y)=\frac{y-1}{2}$。

$f_Y(y) = f_X(\frac{y-1}{2}) \cdot \frac{1}{2} = \frac{1}{2}$，$y \in (1, 3)$。即 $Y \sim U(1,3)$。

**2. $X \sim N(0, 1)$，$Y = X^2$。求 $f_Y(y)$。**

分布函数法。$y \leq 0$ 时 $F_Y(y)=0$。

$y > 0$ 时 $F_Y(y) = \Phi(\sqrt{y}) - \Phi(-\sqrt{y}) = 2\Phi(\sqrt{y}) - 1$

求导得 $f_Y(y) = \frac{1}{\sqrt{2\pi y}}e^{-y/2}$，$y > 0$。

**3. $X \sim U(0, 2)$，$Y = \begin{cases} 1 & X < 1 \\ 2 & X \geq 1 \end{cases}$。求 $Y$ 的分布律。**

$P(Y=1) = P(X < 1) = 1/2$，$P(Y=2) = 1/2$。

## 易错点

| 易错点       | 正确理解                    |         |     |
| --------- | ----------------------- | ------- | --- |
| 不按 $y$ 分段 | 不同 $y$ 对应不同的 $X$ 范围     |         |     |
| 忘绝对值      | $f_Y = f_X(h(y)) \cdot$ | $h'(y)$ |     |
|           |                         |         |     |

## 考试重点

1. 分布函数法是通法：$F_Y(y) = P(g(X) \leq y)$ → 积分 → 求导
2. 必须按 $y$ 分段讨论
3. $Y = X^2$ 是最常考的非单调变换
