## 一、数学期望 $E(X)$

| 类型 | 公式 |
|------|------|
| 离散 | $E(X) = \sum x_i p_i$ |
| 连续 | $E(X) = \int_{-\infty}^{+\infty} x f(x)\,dx$ |

以概率为权重的加权平均，反映"中心位置"。

**性质**

- $E(c) = c$
- $E(cX) = cE(X)$
- $E(X \pm Y) = E(X) \pm E(Y)$（不需要独立）
- $E(XY) = E(X)E(Y)$（需要独立）

## 二、方差 $D(X)$


$$
D(X) = E[(X - E(X))^2]
$$


实际计算必用：

$$
D(X) = E(X^2) - [E(X)]^2
$$


标准差 $\sigma(X) = \sqrt{D(X)}$。

$E(X^2) = \sum x_i^2 p_i$（离散）或 $\int x^2 f(x)dx$（连续）。

**性质**

- $D(c) = 0$
- $D(cX) = c^2 D(X)$
- $X,Y$ 独立：$D(X \pm Y) = D(X) + D(Y)$
- 不独立：$D(X \pm Y) = D(X) + D(Y) \pm 2\text{Cov}(X,Y)$

> **$D(2X) = 4D(X)$，不是 $2D(X)$。系数必须平方。**

## 三、常见分布速查

来源：PDF第10页

| 分布 | $E(X)$ | $D(X)$ |
|------|--------|--------|
| $B(1,p)$ | $p$ | $p(1-p)$ |
| $B(n,p)$ | $np$ | $np(1-p)$ |
| $P(\lambda)$ | $\lambda$ | $\lambda$ |
| $U(a,b)$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| $N(\mu,\sigma^2)$ | $\mu$ | $\sigma^2$ |

## 经典例题

**1. 设 $X$ 分布律 $P(X=-1)=0.2$，$P(X=0)=0.5$，$P(X=2)=0.3$。求 $E(X)$ 和 $D(X)$。**

$E(X) = -0.2 + 0 + 0.6 = 0.4$

$E(X^2) = 0.2 + 0 + 1.2 = 1.4$

$D(X) = 1.4 - 0.16 = 1.24$

**2. $f(x) = \begin{cases} 3x^2 & 0 < x < 1 \\ 0 & \text{其他} \end{cases}$。求 $E(X)$ 和 $D(X)$。**

$E(X) = \int_0^1 3x^3 dx = \frac{3}{4}$

$E(X^2) = \int_0^1 3x^4 dx = \frac{3}{5}$

$D(X) = \frac{3}{5} - \frac{9}{16} = \frac{3}{80}$

**3. $X \sim B(10, 0.3)$。求 $E(X), D(X)$。若 $Y = 2X + 1$，求 $E(Y), D(Y)$。**

$E(X)=3$，$D(X)=2.1$

$E(Y)=7$，$D(Y)=4 \times 2.1=8.4$

**4. $X,Y$ 独立，$D(X)=2$，$D(Y)=3$。求 $D(2X-3Y)$。**


$$
D(2X-3Y) = 4D(X) + 9D(Y) = 8 + 27 = 35
$$

## 易错点

| 易错点 | 正确 |
|--------|------|
| $D(cX) = cD(X)$ | $D(cX) = c^2 D(X)$ |
| $D(X \pm Y) = D(X)+D(Y)$ 恒成立 | 仅当独立 |
| $E(XY) = E(X)E(Y)$ 恒成立 | 仅当独立 |
| $E(X^2) = [E(X)]^2$ | 完全不同，按定义分别算 |

---

<div id="section-6" class="note-anchor"></div>

## 考试重点

1. $D = E(X^2) - E^2(X)$：万能公式
2. $D(cX) = c^2 D(X)$：最高频易错点
3. $E(X \pm Y) = E(X) \pm E(Y)$ 不需要独立
4. 独立时 $D(X \pm Y) = D(X) + D(Y)$
