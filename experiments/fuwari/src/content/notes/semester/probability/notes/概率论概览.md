## 核心公式速查

<div id="section-8" class="note-anchor"></div>

### 概率公式

| 名称 | 公式 |
|------|------|
| 加法 | $P(A \cup B) = P(A) + P(B) - P(AB)$ |
| 减法 | $P(A-B) = P(A) - P(AB)$ |
| 条件概率 | $P(A \mid B) = \frac{P(AB)}{P(B)}$ |
| 全概率 | $P(A) = \sum_i P(B_i) P(A \mid B_i)$ |
| 贝叶斯 | $P(B_i \mid A) = \frac{P(B_i)P(A \mid B_i)}{\sum_j P(B_j)P(A \mid B_j)}$ |
| 伯努利 | $P_n(k) = C_n^k p^k (1-p)^{n-k}$ |

<div id="section-9" class="note-anchor"></div>

### 常用分布

| 分布 | $E$ | $D$ |
|------|-----|-----|
| $B(n,p)$ | $np$ | $np(1-p)$ |
| $P(\lambda)$ | $\lambda$ | $\lambda$ |
| $U(a,b)$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| $N(\mu,\sigma^2)$ | $\mu$ | $\sigma^2$ |

<div id="section-10" class="note-anchor"></div>

### 数字特征

| 名称 | 公式 |
|------|------|
| 方差 | $D(X) = E(X^2) - E^2(X)$ |
| 协方差 | $\text{Cov} = E(XY) - E(X)E(Y)$ |
| 相关系数 | $\rho = \frac{\text{Cov}}{\sqrt{D(X)}\sqrt{D(Y)}}$ |
| 切比雪夫 | $P(\vert X-E\vert  \geq \varepsilon) \leq D/\varepsilon^2$ |

## 易错点速记

1. $D(cX) = c^2 D(X)$ — 系数平方
2. $D(X \pm Y) = D(X)+D(Y)$ — 仅当独立
3. $\text{Cov}=0$ 不等于独立
4. $P(X=a)=0$ — 连续型单点概率永远是 0
5. $\Phi(-x) = 1-\Phi(x)$ — 不是 $-\Phi(x)$
6. 标准化除以 $\sigma$ — 不是 $\sigma^2$
7. 互斥且 $P>0$ → 一定不独立
