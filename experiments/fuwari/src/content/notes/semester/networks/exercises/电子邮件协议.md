## 一、核心协议对比

| 协议 | 全称 | 作用 | 端口 | 方向 |
|------|------|------|:----:|------|
| **SMTP** | Simple Mail Transfer Protocol | 发送邮件 / 控制邮件传输路径 | 25 | 客户端→服务器 / 服务器→服务器 |
| **POP3** | Post Office Protocol v3 | 收取邮件到本地 | 110 | 服务器→客户端 |
| **IMAP** | Internet Message Access Protocol | 在线管理邮件（服务器端操作） | 143 | 双向 |

<div id="section-2" class="note-anchor"></div>

## 二、老师原题考点

> **题目来源**：上课讲的第二题——电子邮件

1. **SMTP（简单邮件传输协议）**：控制邮件发送路径
   - "S" = Send（发送）
   - 用于**发送**邮件，以及邮件服务器之间的**中继转发**

2. **POP3（邮局协议第三版）**：收取电子邮件
   - "P" = Post Office（邮局）
   - 用于从邮件服务器**收取**邮件到本地客户端
   - 默认下载后从服务器删除（POP3典型行为）

<div id="section-3" class="note-anchor"></div>

### 记忆方法

```
SMTP → Send Mail → 发邮件
POP3 → Post Office → 取邮件（像去邮局取信）
IMAP → I Manage All online → 在线管理（在服务器上操作）
```

## 三、邮件收发流程

```
发送方                      接收方
  │                           │
  │── SMTP ──→ 发送方邮件服务器 ── SMTP ──→ 接收方邮件服务器
  │                                           │
  │                                    ┌──────┴──────┐
  │                                    │   POP3/IMAP │
  │                                    └──────┬──────┘
  │                                           │
  │                                    接收方客户端
```

> **关键**：SMTP负责"推"（push），POP3/IMAP负责"拉"（pull）

## 四、同类练习题

> **题目**：简述 SMTP 和 POP3 的区别，并说明在发送一封电子邮件的过程中，这两个协议分别在什么阶段使用。

**解析**：

| | SMTP | POP3 |
|------|------|------|
| 用途 | 发送和中继邮件 | 收取邮件 |
| 阶段 | 用户发送邮件 + 服务器间传输 | 收件人从服务器下载 |
| 端口 | 25 | 110 |

**完整流程**：
1. 发件人用 **SMTP** 将邮件推送到自己的邮件服务器
2. 发件人的邮件服务器用 **SMTP** 将邮件中继到收件人的邮件服务器
3. 收件人用 **POP3**（或 IMAP）从自己的邮件服务器拉取邮件到本地

> **常见考点**
> - "SMTP 既能发也能收" → **错**！SMTP只能发（推送），收邮件要用POP3/IMAP
> - "用浏览器看网页版邮箱用的是POP3协议" → **错**！网页邮箱用的是HTTP/HTTPS
