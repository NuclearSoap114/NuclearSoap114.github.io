└── 无线介质
```

## 二、双绞线

<div id="section-3" class="note-anchor"></div>

### 基本参数

| 项目 | 内容 |
|------|------|
| 5 类双绞线对数 | **4 对**线 |
| 分类 | UTP（非屏蔽双绞线）、STP（屏蔽双绞线） |

<div id="section-4" class="note-anchor"></div>

### 传输特性（重要！）

| 特性 | 说明 |
|------|------|
| 传输速率 | 10Mbps ~ 100Mbps，甚至更高 |
| 传输距离 | **通常只用作局域网通信介质**（距离有限） |
| 传输信号 | **既可以传输模拟信号，也可以传输数字信号** |
| 缺点 | 易受外部电磁波干扰，线路本身也产生噪声，误码率较高 |
| ❌ 错误说法 | 传输距离可达几十公里甚至更远 ← **这是错的！** |

## 三、光纤

| 类型 | 特点 |
|------|------|
| **单模光纤** | 纤芯细，单一传输路径，传输性能**优于**多模，适合远距离 |
| **多模光纤** | 纤芯粗，多条传输路径，存在模间色散，适合短距离 |

> **必背**
> **单模光纤的传输性能优于多模光纤。**

## 四、568B 标准线序（必须背！）

```
1 — 橙白
2 — 橙
3 — 白绿
4 — 蓝
5 — 蓝白
6 — 绿

> **记忆口诀**
> 橙白橙，白绿蓝，蓝白绿，棕白棕

> 关键：**绿色对**在中间（3号、6号），**蓝色对**被拆开（4号、5号）

## 五、连接两台交换机的线缆

> 两台交换机互联 → 使用**交叉线**

- 同种设备互联（交换机-交换机、PC-PC）→ 交叉线
- 不同设备互联（PC-交换机）→ 直通线

## 六、通信方式

| 方式 | 说明 |
|------|------|
| **单工** | 一方只能发，一方只能收 |
| **半双工** | 双方可收发，但同一时刻只能一方发 |
| **全双工** | 同一时刻双方可**同时发送和接收** |

> 交换机端口可以为半双工或全双工。**全双工 100Mbps 端口** → 带宽 = **200Mbps**（收发各 100Mbps）

<div id="section-9" class="note-anchor"></div>

## 七、多路复用技术

> 使多路信号共同使用一条线路进行传输，充分利用信道的容量。

| 复用技术 | 中文 | 原理 |
|----------|------|------|
| **FDM** | 频分多路复用 | 不同频段 |
| **WDM** | 波分多路复用 | 不同波长（光的 FDM） |
| **TDM** | 时分多路复用 | 不同时隙 |
| **CDM** | 码分多路复用 | 不同码片序列 |
