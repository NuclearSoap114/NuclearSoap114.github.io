## 一、特殊IP地址全家福

```
                    全1 (255.255.255.255)
                    ┌──── 受限广播地址 ────┐
                    │  (请求IP地址分配时用)  │
                    └──────────────────────┘

192.168.1.0/24 网段中:

  192.168.1.0      网络地址        (主机位全0)
  192.168.1.1      第一个可用IP    (通常也是默认网关)
  192.168.1.2 ~ 254  可用主机范围
  192.168.1.254    最后一个可用IP  (广播地址-1)
  192.168.1.255    直接广播地址    (主机位全1)
```

<div id="section-2" class="note-anchor"></div>

### 速查表

| 地址/概念 | 定义 | 示例（192.168.1.0/24） |
|-----------|------|------------------------|
| **网络地址** | 主机位全为 0 | 192.168.1.0 |
| **直接广播地址** | 网络位不变，主机位全为 1 | 192.168.1.255 |
| **受限广播地址** | 32位全为 1 | 255.255.255.255 |
| **第一个可用IP** | 网络地址 + 1 | 192.168.1.1 |
| **最后一个可用IP** | 直接广播地址 - 1 | 192.168.1.254 |
| **默认网关** | 本网络通向其他网络的出口 | 通常是第一个可用IP |
| **回环地址** | 本机测试用 | 127.0.0.1 |

## 二、各种地址详细说明

<div id="section-4" class="note-anchor"></div>

### 网络地址（网络本身）

- **规则**：主机号**全为 0**
- **示例**：192.168.1.0/24 → 代表 "192.168.1.0 这个网络"，不能分配给主机
- **用途**：路由表中标识一个网络

<div id="section-5" class="note-anchor"></div>

### 直接广播地址

- **规则**：网络位不变，**主机位全为 1**
- **示例**：192.168.1.255/24 → 向 192.168.1.0 网络中的所有主机广播
- **注意**：路由器默认会**阻挡**直接广播（防广播风暴），考试不考虑此细节

<div id="section-6" class="note-anchor"></div>

### 受限广播地址

- **规则**：**32位全为 1** → 255.255.255.255
- **用途**：主机在不知道自己的网络号时（如 DHCP 请求IP），向本网络所有主机广播
- **范围**：仅限**本网络内**，不会被路由器转发

> **直接广播 vs 受限广播**
> | | 直接广播 | 受限广播 |
> |------|----------|----------|
> | 地址 | 网络位 + 主机位全1 | 255.255.255.255 |
> | 范围 | 可以跨网络（由路由器转发） | 仅本网络内 |
> | 知道网络号？ | 知道 | 不知道（如刚开机请求IP） |

<div id="section-7" class="note-anchor"></div>

### 最后一个可用IP地址

- **规则**：直接广播地址 - 1
- **示例**：192.168.1.254/24

<div id="section-8" class="note-anchor"></div>

### 网关 (Gateway)

- **概念**：一个网络通向**其他网络**的出口 IP 地址
- **默认网关**：主机如果找不到可用的特定网关，就默认使用这个地址
- **常见设定**：子网中第一个或最后一个可用 IP（如 192.168.1.1 或 192.168.1.254）

## 三、ADSL 与宽带

<div id="section-10" class="note-anchor"></div>

### ADSL（Asymmetric Digital Subscriber Line）非对称数字用户线路

- **中文**：非对称数字用户线路
- **非对称**：**下行速率 > 上行速率**（下载比上传快）
- **技术**：利用现有电话线传输数据，数据和语音可同时传输（频分复用）
- **成为宽带的条件**：非对称 + 满足一定速率标准 → 才叫"宽带"
- 课本位置：P176

<div id="section-11" class="note-anchor"></div>

### 宽带判断

```
ADSL = 非对称 + 速率 ≥ 标准值 → 宽带
```

> 考点：ADSL的中文名称、非对称的含义、是否算宽带

## 四、ARP 地址解析协议

<div id="section-13" class="note-anchor"></div>

### 基本概念

- **全称**：Address Resolution Protocol
- **功能**：将 **IP 地址** 解析为 **MAC 地址**
- **工作层次**：网络层（但服务于数据链路层）

<div id="section-14" class="note-anchor"></div>

### 工作过程

```
主机A (知道B的IP，不知道B的MAC)
  │
  ├─ ① ARP请求（广播）："谁是 192.168.1.2？请告诉我你的MAC"
  │   目标MAC: FF-FF-FF-FF-FF-FF（广播地址）
  │
  ├─ ② ARP响应（单播）："我是 192.168.1.2，我的MAC是 AA-BB-CC-DD-EE-FF"
  │   仅B回复，其他主机忽略
  │
  └─ ③ 主机A将映射关系存入 ARP缓存
```

> **ARP缓存**
> 主机本地会维护一个 ARP 缓存表，存储 IP→MAC 的映射，避免重复查询。可用 `arp -a` 命令查看。

## 五、超网 (Supernet / Route Aggregation)

<div id="section-16" class="note-anchor"></div>

### 概念
- **与子网相反**：将多个小网络**合并**为一个更大的网络
- **方法**：子网掩码**变短**（网络位减少，主机位增加）
- **目的**：**路由聚合**，减少路由表中的条目数

<div id="section-17" class="note-anchor"></div>

### 示例

```
合并前（两条路由）:        合并后（一条路由 = 超网）:
192.168.0.0/24           192.168.0.0/23
192.168.1.0/24           (掩码从 24 缩短到 23)
                         
分析：192.168.0.0 = 11000000.10101000.0000000|0.00000000
      192.168.1.0 = 11000000.10101000.0000000|1.00000000
      共同前缀 = 前23位相同 → 超网 = 192.168.0.0/23
```

<div id="section-18" class="note-anchor"></div>

### 关键公式

- 超网掩码 = 原掩码 - $\log_2$(合并的网络数)
- 例如合并2个/24网络 → 新掩码 = 24 - $\log_2(2)$ = 24 - 1 = **/23**

## 六、同类练习题

> **题目**：某网络地址为 172.16.8.0/22，求：
> 1. 该网络的子网掩码
> 2. 第一个可用IP和最后一个可用IP
> 3. 直接广播地址

**解析**：

**1. 子网掩码**：
- /22 → 前22位为1 → 255.255.252.0
- 计算：第三段 11111100 = 252

**2. 可用IP范围**：
- 主机位 = 32 - 22 = 10位
- 网络地址：172.16.8.0/22
  - 172.16.8.0 = 172.16.00001000.00000000
  - 掩码 /22 意味着第三段后6位+第四段8位=10位主机位
- 第一个可用：172.16.8.1
- 最后一个可用：172.16.11.254

**3. 直接广播地址**：
- 主机位全1 → 172.16.11.255

> **验证**：步长 = 256 - 252 = 4，子网为 172.16.0.0, 172.16.4.0, 172.16.8.0, 172.16.12.0...
> 172.16.8.0/22 的下一个子网是 172.16.12.0，所以广播地址 = 172.16.12.0 - 1 = **172.16.11.255** ✓

> **快速答题技巧**
> - **已知掩码求可用IP数**：$2^{\text{主机位数}} - 2$
> - **已知网络地址和掩码，求广播地址**：网络地址 + ($2^{\text{主机位数}} - 1$)
> - **判断两个IP是否在同一网段**：分别和掩码做AND运算，结果相同则同网段
