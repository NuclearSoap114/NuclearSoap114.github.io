## 题型分类

考试常考 **画图题**：给一串二进制数字，画出对应波形。分两大类：
1. **基带编码**（数字信号传输数字数据）：NRZ、曼彻斯特、差分曼彻斯特
2. **频带调制**（模拟信号传输数字数据）：ASK、FSK、PSK

<div id="section-2" class="note-anchor"></div>

## 一、基带编码（数字→数字信号）

<div id="section-3" class="note-anchor"></div>

### 三种编码对比表

| 编码 | 规则 | 特点 | 有无自同步 |
|------|------|------|:----------:|
| **NRZ**（非归零） | 1=高电平，0=低电平 | 最简单，但不自带时钟 | ❌ |
| **曼彻斯特** | 中间必跳变：1=↑（低→高），0=↓（高→低） | 自带时钟信号 | ✅ |
| **差分曼彻斯特** | 中间必跳变：1=起始不跳变，0=起始跳变 | 抗干扰强，自带时钟 | ✅ |

<div id="section-4" class="note-anchor"></div>

### 记忆口诀

```
NRZ：   1高 0低 最简单，无法自己认时间
曼码：   中间跳，1上 0下 好分辨
差分曼： 中间跳，1头不变 0头变
```

<div id="section-5" class="note-anchor"></div>

### 波形示意（以 `100110` 为例）

```
时钟:   ┐┌┐┌┐┌┐┌┐┌┐┌
        0 1 0 0 1 1 0  (示例数据)

NRZ:    ────┐   ┌───
        1   0   1

曼码:     ┐ ┌─┐ ┐ ┌─┐ ┌─
         1   0   0   1

差分曼:   ┐ ┌──┐ ┐ ┌──┐ ┌
         1   0    0    1
```

> 实际考试时在答题纸上画波形图，要画整齐，标注每个比特对应的区间。

<div id="section-6" class="note-anchor"></div>

### 详细规则

**NRZ（非归零制）**：
- 1 → 整个比特周期保持**高电平**
- 0 → 整个比特周期保持**低电平**
- ⚠️ 连续多个1或0时无法区分边界 → 必须标注**时钟频率**

**曼彻斯特编码**：
- 每个比特**正中间**一定发生跳变（这是自同步的关键）
- 1 → 中间从**低跳到高**（上升沿）
- 0 → 中间从**高跳到低**（下降沿）
- 开头电平取决于前一位结束时的电平

**差分曼彻斯特编码**：
- 每个比特**正中间**一定发生跳变
- 1 → 比特**起始位置不跳变**（保持前一位结束的电平）
- 0 → 比特**起始位置发生跳变**
- 注意：是看比特边界的跳变，不是中间的跳变

## 二、频带调制（数字→模拟信号）

<div id="section-8" class="note-anchor"></div>

### 三个参数

模拟信号 = $A \sin(\omega t + \phi)$
- **幅度** $A$（Amplitude）
- **频率** $\omega$（角频率，Omega）
- **相位** $\phi$（初相，Phi）

<div id="section-9" class="note-anchor"></div>

### 三种调制对比表

| 调制 | 中文名 | 改变什么 | 1 的表现 | 0 的表现 | 标记要点 |
|------|--------|----------|----------|----------|----------|
| **ASK** | 幅移键控 | 幅度 | 有正弦波 | 无波形（直线） | 标频率 $\omega$ |
| **FSK** | 频移键控 | 频率 | 较稀疏（频率低 $\omega_1$） | 较密集（频率高 $\omega_2$） | 标 $\omega_1, \omega_2$ |
| **PSK** | 相移键控 | 相位 | 正弦从 0° 开始 | 正弦从 180°（π）开始 | 标相位翻转点 |

> **关键区分**
> - **ASK**：看有没有波形（幅度变化）
> - **FSK**：看波形疏密（频率变化），频率高=波形密
> - **PSK**：看相位是否翻转（相位变化），在比特边界处可能发生相位突变

<div id="section-10" class="note-anchor"></div>

### 记忆方法

```
ASK：1有波 0没波（幅度变化）
FSK：1疏波 0密波（频率变化）  ← 0更密！
PSK：1正起 0反起（相位变化）  ← 0从180度开始
```

<div id="section-11" class="note-anchor"></div>

### 波形示意（以 `100` 为例）

```
ASK:  |~~~~~~~~|________|________
      正弦波    直线(0)  直线(0)
         1        0        0

FSK:  |~~~~|~~~~~~|~~~~~~
      稀疏(ω1)  密集(ω2) 密集(ω2)
         1        0         0

PSK:  |~~~~~~~~|~~~~~~~~|~~~~~~~~
      0°起始   180°起始  180°起始
         1        0         0
```

## 三、老师原题

> **例题**：请写出 `100110` 的 ASK，PSK，FSK 波形图。

<div id="section-13" class="note-anchor"></div>

### ASK (幅移键控) - 100110

```
比特:    1       0       0       1       1       0
       ┌─┐                            ┌─┐    ┌─┐
       │ │   ________ ________  ┌─┐    │ │    │ │   ________
       │ │                        │    │ │    │ │
       └─┘                        └─┘    └─┘    └─┘
       有波    直线     直线     有波    有波    直线
       标注: ω
```

> **考点**：1有正弦波，0是直线（幅度为0）。标注载波频率 $\omega$。

<div id="section-14" class="note-anchor"></div>

### FSK (频移键控) - 100110

```
比特:    1       0       0       1       1       0
       ~  ~   ~~~~~~  ~~~~~~   ~  ~    ~  ~   ~~~~~~
       稀疏    密集     密集    稀疏    稀疏     密集
       标注: ω1        标注: ω2               标注: ω1
```

> **考点**：1和0都有波形，但0的频率更高（波形更密集）。标注 $\omega_1$（1的频率）和 $\omega_2$（0的频率）。

<div id="section-15" class="note-anchor"></div>

### PSK (相移键控) - 100110

```
比特:    1       0       0       1       1       0
       ~~~~~~~~|~~~~~~~~|~~~~~~~~|~~~~~~~~|~~~~~~~~|~~~~~~~~
       0°起始  180°起始  180°起始  0°起始   0°起始   180°起始
              ↑相位翻转  ↑        ↑相位翻转         ↑相位翻转
```

> **考点**：每个比特都有波形，但相位在比特边界变化。1从0°开始，0从180°（π）开始。**在比特边界处**可能看到波形突然反转。

## 同类练习题

> **题目**：请画出比特序列 `10110` 的 NRZ、曼彻斯特编码和差分曼彻斯特编码波形图。

**解析**：

```
数据:      1     0     1     1     0
         ───────────────────────────────

时钟:    _┐┌_┐┌_┐┌_┐┌_┐┌_

NRZ:     ────┐         ┌─────┐
         高  低  高  高  低
              └───┘     (注意连续两个1)

曼码:      ┐  ┌──┐  ┌──┐  ┌──┐  ┌──
          1    0    1    1    0
          ↑    ↑    ↑    ↑    ↑
         低高 高低 低高 低高 高低
          (中间跳变方向表示数据)

差分曼:    ┐  ┌──┐  ┌─────┐  ┌──
          1    0    1     1    0
          ↑    ↑    ↑     ↑    ↑
         (边界不跳) (跳) (不跳) (不跳) (跳)
```

> **验证要点**：
> - NRZ：连续两个1时保持高电平（这是NRZ的弱点）
> - 曼码：每个比特中间必定有跳变
> - 差分曼：每个比特中间有跳变 + 看边界是否跳变来判断数据

## 四、得分要点汇总

| 编码/调制 | 必须标注的内容 |
|-----------|---------------|
| NRZ | **时钟频率**（因为不能自同步） |
| 曼彻斯特 | 每个比特**中间跳变**的方向 |
| 差分曼彻斯特 | 每个比特**起始边界**是否跳变 |
| ASK | 载波频率 $\omega$ |
| FSK | 两个频率 $\omega_1, \omega_2$ |
| PSK | 相位翻转处（0°↔180°） |

> **画图注意事项**
> 1. 先画一条时钟参考线
> 2. 每个比特区间画虚线分隔
> 3. 在每个比特区间下方标注是 1 还是 0
> 4. 波形要画整齐，高低电平要明显
> 5. 标注关键频率参数
