## 一、五层模型对照 OSI 七层

| TCP/IP五层 | OSI七层 | 典型设备 | 识别依据 | 数据单元 |
|:----------:|:-------:|----------|----------|:--------:|
| **应用层** | 应用层/表示层/会话层 | 电脑、手机、服务器、**网关**、**WAF**、堡垒机 | HTTP/DNS/SMTP等应用协议 | 报文 |
| **传输层** | 传输层 | 防火墙（部分）、负载均衡器 | TCP/UDP **端口号** | 段 |
| **网络层** | 网络层 | **路由器**、**三层交换机**、防火墙 | **IP地址** | 包 |
| **数据链路层** | 数据链路层 | **二层交换机**、网桥 | **MAC地址** | 帧 |
| **物理层** | 物理层 | **集线器(Hub)**、中继器、网线、光纤、网卡、调制解调器 | 电/光**比特流** | 比特 |

<div id="section-2" class="note-anchor"></div>

### 速记对照表（考试常考填空）

```
层级          → 典型设备            → 识别依据
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
物理层       → 集线器Hub、中继器    → 比特流（电信号）
数据链路层   → 二层交换机、网桥     → MAC地址（帧）
网络层       → 路由器、三层交换机   → IP地址（包）
传输层       → 防火墙、负载均衡     → 端口号（段）
应用层       → 服务器、WAF、网关    → 应用协议（HTTP/DNS等）
```

> **必背**
> **交换机工作在第二层（数据链路层）**，依据**MAC地址**转发，同一局域网内转发，不跨网段。

## 二、OSI各层功能（必背）

| 层级 | 核心功能 | 关键协议/技术 |
|:----:|----------|---------------|
| **物理层** | 透明传输比特流，定义电气/机械/功能特性 | 定义了电压、接口(RS-232)、传输介质 |
| **数据链路层** | 成帧、差错检测(CRC)、流量控制、MAC寻址 | PPP, HDLC, 以太网 |
| **网络层** | IP寻址、路由选择、拥塞控制、分组转发 | IP, ICMP, ARP, OSPF, RIP |
| **传输层** | 端到端可靠传输、流量控制、差错恢复、复用分用 | TCP, UDP |
| **应用层** | 为应用程序提供网络服务接口 | HTTP, DNS, SMTP, FTP, POP3 |

> **记忆要点**
> - **物理层**：只管比特，不管内容 → "不认帧、不看MAC/IP"
> - **链路层**：相邻节点间的可靠传输，MAC寻址
> - **网络层**：跨网络寻址和路由，IP寻址
> - **传输层**：端到端（进程到进程），端口号标识
> - **应用层**：最贴近用户，各种网络应用协议

## 三、各层设备详解

<div id="section-5" class="note-anchor"></div>

### 物理层设备

| 设备 | 功能 | 特点 |
|------|------|------|
| **集线器 (Hub)** | 将信号复制到所有端口 | 共享带宽，所有端口在同一冲突域 |
| **中继器 (Repeater)** | 放大/再生衰减的信号 | 延长传输距离 |
| **调制解调器 (Modem)** | 数字信号↔模拟信号转换 | "猫"，拨号上网用 |
| 网线、光纤 | 物理传输介质 | — |
| 网卡 (NIC) | 计算机连接网络的接口 | 含MAC地址 |

<div id="section-6" class="note-anchor"></div>

### 数据链路层设备

| 设备 | 功能 | 特点 |
|------|------|------|
| **二层交换机** | 依MAC地址转发帧 | 隔离冲突域，每个端口独立带宽 |
| **网桥 (Bridge)** | 连接两个局域网段 | 依MAC地址决定是否转发 |

> **Hub vs 交换机**：
> - Hub：物理层，收到数据**广播到所有端口**，共享带宽
> - 交换机：数据链路层，收到数据**仅发到目标MAC对应端口**，独享带宽，隔离冲突域

<div id="section-7" class="note-anchor"></div>

### 网络层设备

| 设备 | 功能 | 特点 |
|------|------|------|
| **路由器 (Router)** | 依IP地址跨网段转发 | 连接不同网络 |
| **三层交换机** | 二层交换 + 三层路由 | 可跨网段转发，一次路由多次交换 |
| 防火墙（路由功能） | 包过滤 + 路由 | 安全策略 + 转发 |

> **三层交换机**
> 同时具备**二层交换**（MAC地址转发，同一网段）和**三层路由**（IP地址转发，跨网段）功能。

<div id="section-8" class="note-anchor"></div>

### 传输层

- **无独立专用硬件设备**
- 部分防火墙、负载均衡器会解析 **TCP/UDP端口号** 做过滤和分发
- 负载均衡器：根据端口将流量分发到多台服务器

<div id="section-9" class="note-anchor"></div>

### 应用层

| 设备 | 功能 |
|------|------|
| **网关 (Gateway)** | 连接两种**不同协议**的网络，协议转换 |
| **WAF** | Web应用防火墙，检测HTTP攻击（SQL注入、XSS等） |
| **代理服务器** | 代理用户请求，可缓存、过滤 |
| **堡垒机** | 运维安全审计，控制服务器访问 |

> **网关 vs 路由器**
> - **路由器**：在网络层基于IP地址转发（协议相同）
> - **网关**：在应用层做**协议转换**（连接不同协议的网络）

## 四、老师原题相关

<div id="section-11" class="note-anchor"></div>

### 来自 a.txt 的考点

1. **ADSL**：非对称数字用户线路（Asymmetric Digital Subscriber Line）
   - 非对称：上行和下行速率不同（下行 > 上行）
   - 满足一定速率标准 → 称为"宽带"
   - 课本 P176

2. **交换机工作在第二层**（数据链路层）

3. **ARP**：地址解析协议
   - 功能：**IP地址 → MAC地址** 的映射
   - 工作过程：广播ARP请求 → 目标主机单播ARP响应
   - 属于网络层协议（虽然服务于数据链路层）

4. **超网 (Supernet)**：
   - 与子网相反：将多个小网络**合并**为一个大网络
   - 方法：向网络位**借位给主机位**（掩码变短）
   - 用途：路由聚合（减少路由表条目）
   - 例如：192.168.0.0/24 + 192.168.1.0/24 → 192.168.0.0/23

## 五、同类练习题

> **题目**：以下设备分别工作在OSI的哪一层？
> 1. 集线器  2. 路由器  3. 二层交换机  4. 防火墙（具备路由功能） 5. WAF

**解析**：
1. 集线器 → **物理层**（仅复制转发比特流）
2. 路由器 → **网络层**（基于IP地址转发）
3. 二层交换机 → **数据链路层**（基于MAC地址转发）
4. 防火墙（路由功能）→ **网络层**（基于IP地址过滤转发）
5. WAF → **应用层**（解析HTTP协议检测Web攻击）

> **得分技巧**
> - "X层交换机"的X就是工作层级：二层交换机→数据链路层，三层交换机→网络层
> - 看"依据什么地址"判断层级：MAC→链路层，IP→网络层，端口→传输层，URL/HTTP→应用层
