## 一、常见协议缩写

| 缩写 | 中文名 | 英文全称 |
|:----:|--------|----------|
| **UTP** | 非屏蔽双绞线 | Unshielded Twisted Pair |
| **DNS** | 域名系统 | Domain Name System |
| **FTP** | 文件传输协议 | File Transfer Protocol |
| **SMTP** | 简单邮件传输协议 | Simple Mail Transfer Protocol |
| **ADSL** | 非对称数字用户线 | Asymmetric Digital Subscriber Line |
| **HTTP** | 超文本传输协议 | HyperText Transfer Protocol |
| **DHCP** | 动态主机配置协议 | Dynamic Host Configuration Protocol |

<div id="section-2" class="note-anchor"></div>

## 二、必背端口号

| 端口 | 协议 | 用途 |
|:----:|------|------|
| **80** | HTTP | Web 服务默认端口 |
| **21** | FTP | 文件传输（控制连接） |
| 20 | FTP | 文件传输（数据连接） |
| 25 | SMTP | 发送邮件 |
| 110 | POP3 | 收取邮件 |
| 53 | DNS | 域名解析 |
| 443 | HTTPS | 安全 Web |

> **第二套考题高频易错**
> - HTTP 端口是 **80**，**不是** 110（110 是 POP3）
> - Web 服务和 FTP 服务默认 TCP 端口分别是 **80** 和 **21**
> - FTP 使用**两条连接**：控制连接（21）+ 数据连接（20）

<div id="section-3" class="note-anchor"></div>

## 三、HTTP 会话过程

HTTP 的四个过程：
1. **建立连接**
2. **发出请求信息**
3. **发出响应信息**
4. ❌ **传输数据** ← 不是独立过程！

> HTTP 请求和响应中已经在传输数据了，所以不把"传输数据"单列。

> ATM 网络采用固定长度信元传送数据，信元长度为 **53B**

## 五、协议所在层次

| 协议 | TCP/IP 模型层次 |
|------|:--------------:|
| SMTP | **应用层** |
| HTTP | 应用层 |
| DNS | 应用层 |
| FTP | 应用层 |
| TCP | 传输层 |
| UDP | 传输层 |
| IP | 互联层 |

> **TCP/IP 共 **4 层**：网络接口层 → 互联层 → **传输层**(第3层) → **应用层**(第4层)**
