## 一、数字签名

<div id="section-2" class="note-anchor"></div>

### 功能

认证、完整性、不可否认

<div id="section-3" class="note-anchor"></div>

### 签名过程

1. 原文做 **Hash** → 消息摘要
2. 用**私钥加密**摘要 → 数字签名
3. 原文 + 签名一起发送

<div id="section-4" class="note-anchor"></div>

### 验证过程

1. 收到后对原文同样做 Hash
2. 用**公钥解密**签名得到原始摘要
3. 对比两个摘要 → 相同则验证通过

> **核心**
> 数字签名 = **私钥加密** Hash 值
> 验证 = **公钥解密** + 对比 Hash

## 二、数字证书 (PKI)

| 组件 | 功能 |
|------|------|
| **CA**（认证中心） | 签发和管理证书 |
| **RA**（注册中心） | 审核用户身份 |
| **CRL** | 证书吊销列表 |

> 数字证书 = CA 签发的包含用户身份和公钥的电子文档

## 三、防火墙分类

| 类型 | 工作层次 | 说明 |
|------|:--------:|------|
| **包过滤** | 网络/传输层 | 按 IP、端口、协议过滤 |
| **状态检测** | 网络/传输层 | 还跟踪连接状态 |
| **应用网关** | 应用层 | 代理应用请求，深度检查 |

<div id="section-8" class="note-anchor"></div>

## 经典例题

**简述数字签名的原理。**

① 发送方对原文做 Hash 得到摘要
② 用私钥加密摘要得到签名
③ 接收方用公钥解密签名得到摘要，与原文 Hash 对比
④ 相同→验证通过，不同→被篡改
