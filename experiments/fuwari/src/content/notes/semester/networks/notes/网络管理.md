## 一、FCAPS 五大功能

| 功能 | 英文 | 说明 |
|------|------|------|
| **F** 故障管理 | Fault | 检测、隔离、纠正故障 |
| **C** 配置管理 | Configuration | 管理设备配置和拓扑 |
| **A** 计费管理 | Accounting | 记录资源使用 |
| **P** 性能管理 | Performance | 监测分析性能 |
| **S** 安全管理 | Security | 控制访问 |

## 二、SNMP 协议

<div id="section-3" class="note-anchor"></div>

### 三大组件

| 组件 | 功能 |
|------|------|
| **Manager**（管理站） | 管理和监控 |
| **Agent**（代理） | 运行在被管设备上 |
| **MIB**（管理信息库） | 被管对象树形集合 |

<div id="section-4" class="note-anchor"></div>

### SNMP 操作

| 操作 | 说明 |
|------|------|
| **Get** | Manager 查询 Agent |
| **Set** | Manager 设置 Agent |
| **Trap** | Agent 主动告警 |

<div id="section-5" class="note-anchor"></div>

### 端口

- Agent 监听：UDP **161**
- Manager 收 Trap：UDP **162**
