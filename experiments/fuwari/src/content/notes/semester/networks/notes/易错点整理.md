## 物理层与数据链路层

| 易错点 | 正确理解 |
|--------|----------|
| 发送时延 = 传播时延 | 发送在机器内部（看数据量），传播在链路上（看距离） |
| 曼彻斯特编码比特率=波特率 | 波特率 = 2 × 比特率 |
| 最短帧长对所有速率都是64字节 | 仅10Mbps，高速率需缩短距离或加长帧 |
| 交换机用IP转发 | 普通交换机在数据链路层，只看MAC |
| 集线器=交换机 | 集线器物理层广播，交换机数据链路层查表 |

## 网络层

| 易错点 | 正确理解 |
|--------|----------|
| RIP 用 TCP | RIP 用 UDP 520 |
| BGP 是内部网关协议 | BGP 是 EGP，AS 之间 |
| 子网数 $2^n$ 不-2 | 子网数不需要-2（现代CIDR下） |
| 可用主机数 $2^m$ | 需要减2：去掉网络地址和广播地址 |
| 路由器转发广播 | 路由器隔离广播域，不转发广播 |

## 传输层

| 易错点 | 正确理解 |
|--------|----------|
| TCP也是四次握手 | 建立是三次握手，释放才是四次挥手 |
| TIME-WAIT在服务器 | 主动关闭方才进入 TIME-WAIT |
| 超时 → 快恢复 | 超时是严重拥塞 → 慢开始(cwnd=1) |
| 3重复ACK → 慢开始 | 3重复ACK是轻度拥塞 → 快恢复(cwnd减半) |
| UDP和TCP都有拥塞控制 | UDP没有拥塞控制 |

## 应用层与安全

| 易错点 | 正确理解 |
|--------|----------|
| DNS端口是TCP 53 | DNS查询一般用 UDP 53 |
| 数字签名用公钥加密 | 签名用**私钥**加密，验证用公钥 |
| HTTP有状态 | HTTP 是无状态协议 |
| 加密用非对称（快） | 非对称慢，一般用对称加密数据，非对称传密钥 |

## 概念辨析

1. **互连** = 物理连接，**互通** = 能通信（有协议），**互操作** = 能协同工作
2. **面向连接** ≠ 可靠（虽常相关但不是一回事）
3. **流量控制** ≠ 拥塞控制（流量是端到端，拥塞是全网）
4. **协议** ≠ **服务**（协议是水平的，服务是垂直的）
5. **吞吐量** ≠ **带宽**（吞吐量是实际值，带宽是理论最大值）
