## 三、Active Directory 核心概念

| 概念 | 说明 |
|------|------|
| **域(Domain)** | 一组计算机的安全边界 |
| **域控制器(DC)** | 运行 AD 服务的服务器 |
| **组织单位(OU)** | 域内的管理容器 |

## 四、Linux 常用网络命令

| 命令 | 功能 |
|------|------|
| `ifconfig` / `ip addr` | 查看/配置网络接口 |
| `ping` | 测试连通性 |
| `traceroute` | 路由追踪 |
| `netstat` | 查看网络连接 |
| `nslookup` / `dig` | DNS查询 |
