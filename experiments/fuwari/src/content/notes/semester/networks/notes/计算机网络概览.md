## 核心公式速查

<div id="section-12" class="note-anchor"></div>

### 物理层

| 名称 | 公式 |
|------|------|
| 奈奎斯特（无噪声） | $C = 2W \log_2 V$ |
| 香农定理（有噪声） | $C = W \log_2(1 + S/N)$ |
| 信噪比换算 | $\text{dB} = 10 \log_{10}(S/N)$ |
| 总时延 | 发送时延 + 传播时延 + 处理时延 + 排队时延 |
| 发送时延 | 数据帧长度 / 发送速率 |
| 传播时延 | 信道长度 / 传播速率 |

<div id="section-13" class="note-anchor"></div>

### 数据链路层

| 名称 | 公式 |
|------|------|
| 争用期 | $2\tau$（$\tau$ 为端到端传播时延） |
| 最短帧长 | 争用期 × 数据速率 |
| 二进制退避等待 | $T = k \times 2\tau$，$k \in \{0,1,...,2^n-1\}$ |

<div id="section-14" class="note-anchor"></div>

### 网络层

| 名称 | 公式 |
|------|------|
| 子网数 | $2^n$（$n$ = 借用的主机位数） |
| 每子网可用主机数 | $2^m - 2$（$m$ = 剩余主机位数） |
| 网络地址 | IP AND 子网掩码 |
| 广播地址 | 网络地址 + 主机位全1 |

## 易错点速记

1. 发送时延发生在机器内部，传播时延发生在链路上——两者无关
2. 曼彻斯特编码：波特率 = 2 × 比特率
3. 最短帧长 64 字节针对的是 10Mbps 以太网
4. 交换机不认识 IP——它工作在数据链路层，只看 MAC
5. 路由器不转发广播——广播被限制在局域网内
6. TCP 三次握手不是四次——释放连接才是四次挥手
7. TIME-WAIT 持续 2MSL，是主动关闭方进入的状态
8. 超时 → 慢开始（cwnd=1）；3 个重复 ACK → 快恢复（cwnd 减半）
9. 私有 IP 地址不能在 Internet 上路由
10. $D(cX) = c^2 D(X)$——系数必须平方
