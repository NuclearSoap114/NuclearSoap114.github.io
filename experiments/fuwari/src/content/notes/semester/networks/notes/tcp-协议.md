## 一、TCP 特点

| 特点 | 说明 |
|------|------|
| **面向连接** | 三次握手建立连接 |
| **可靠传输** | 确认 + 重传机制 |
| **面向字节流** | 不保留报文边界 |
| **全双工** | 双方可同时收发 |
| **流量控制** | 滑动窗口 |
| **拥塞控制** | 慢开始、拥塞避免、快重传、快恢复 |

## 二、TCP 首部（20字节固定 + 选项）

| 字段 | 位数 | 说明 |
|------|:----:|------|
| **源端口 / 目的端口** | 各16 | 进程标识 |
| **序号(Seq)** | 32 | 本段第一个字节的编号 |
| **确认号(Ack)** | 32 | 期望收到的下一个字节序号 |
| **首部长度** | 4 | 以 4 字节为单位 |
| **标志位** | 6 | URG/ACK/PSH/RST/SYN/FIN |
| **窗口** | 16 | 接收窗口大小 |
| **检验和** | 16 | 差错检测 |
| **紧急指针** | 16 | 紧急数据偏移 |

> **标志位**
> SYN=1：建立连接
> FIN=1：释放连接
> ACK=1：确认号有效
> RST=1：重置连接

## 三、TCP 可靠传输机制

| 机制 | 说明 |
|------|------|
| **序号** | 每个字节编号 |
| **确认(ACK)** | 收到后回复确认 |
| **超时重传** | 超时未确认 → 重传 |
| **校验和** | 检测传输错误 |
