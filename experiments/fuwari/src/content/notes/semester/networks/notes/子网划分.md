## 一、核心概念

子网划分 = 从主机号中**借位**给网络号，将一个大网络分成多个小网络。

---

<div id="section-2" class="note-anchor"></div>

## 二、关键公式

| 概念 | 公式 |
|------|------|
| 子网掩码 | 网络位全1，主机位全0 |
| 子网数 | $2^n$（$n$ = 借用的主机位数） |
| 每子网可用主机数 | $2^m - 2$（$m$ = 剩余主机位数） |
| 网络地址 | IP AND 子网掩码 |
| 广播地址 | 主机位全1 |

> **减 2**
> 全0 = 网络地址，全1 = 广播地址，都不能分配给主机。

---

<div id="section-3" class="note-anchor"></div>

## 三、计算步骤

1. 确定需要多少子网 → 决定借几位（$n$）
2. 新掩码 = 原掩码 + $n$ 位
3. 计算每子网地址范围、广播地址、可用 IP

---

<div id="section-4" class="note-anchor"></div>

## 经典例题

**C类地址 192.168.1.0/24，需6个子网。求子网掩码和每子网可用主机数。**

$2^n \ge 6$ → $n = 3$，新掩码 = /27 = 255.255.255.224

剩余主机位 = $8-3=5$，每子网 $2^5-2=30$ 台

**IP = 192.168.10.130/27，求网络地址和广播地址。**

掩码 /27 = 255.255.255.224 = 11100000

130 = 10000010

网络地址：10000010 AND 11100000 = 10000000 = 128 → 192.168.10.128

广播地址：100|11111 = 159 → 192.168.10.159

可用IP：129~158（30个）

**B类地址需划分50个子网，每子网至少200台主机。求子网掩码。**

$2^n \ge 50$ → $n = 6$，掩码 /22（16+6）

剩余主机位 $= 16-6 = 10$，每子网 $2^{10}-2=1022$ 台 ≥ 200 ✓

## 考试重点

1. 子网掩码计算
2. 网络地址 = IP AND 掩码
3. 广播地址 = 网络地址 + 主机位全1
4. 可用主机数 = $2^{主机位} - 2$
