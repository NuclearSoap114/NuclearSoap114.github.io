### 1. 下面 ( ) 不是网络的拓扑结构。 (5.0分)
- [ ] A. 星型
- [ ] B. 总线型
- [ ] C. 立方形
- [ ] D. 环型

> ****答案与解析****
> **【正确答案】** C
> **【详细解析】** 常见的计算机网络拓扑结构主要包括：星型（Star）、总线型（Bus）、环型（Ring）、树型（Tree）和网状型（Mesh）。在标准的计算机网络领域中，不存在“立方形”这种网络拓扑结构。

### 2. 以下说法哪一个是不正确的 ( )。 (5.0分)
- [ ] A. 计算机网络分为资源子网和通讯子网
- [ ] B. 在局域网中，如每台计算机在逻辑上都是平等的，不存在主从关系，称为对等网络
- [ ] C. 在非对等网络中，存在着主从关系，即某些计算机扮演主角的服务器，其余计算机则充当配角的客户机
- [ ] D. 如果服务器的处理能力强而客户机的处理能力弱，就称为胖客户机/瘦服务器

> ****答案与解析****
> **【正确答案】** D
> **【详细解析】** 选项 D 的表述正好说反了。如果服务器的处理能力强而客户机的处理能力弱（主要负责显示和简单交互），这被称为**“瘦客户机/胖服务器”**（Thin Client / Fat Server）架构。胖客户机（Fat Client）是指客户机本身具备较强的处理能力和本地应用运行能力，对服务器的依赖相对较少。

### 3. 组建计算机网络的目的是为了能够相互共享资源，这里的计算机资源主要是指硬件、软件与 ( )。 (5.0分)
- [ ] A. 大型机
- [ ] B. 通信系统
- [ ] C. 服务器
- [ ] D. 数据

> ****答案与解析****
> **【正确答案】** D
> **【详细解析】** 计算机网络建立的核心初衷就是为了实现“资源共享”。网络中的共享资源通常被划分为三大类：**硬件资源**（如共享打印机、大容量硬盘）、**软件资源**（如网络版应用软件）和**数据资源**（如数据库、文档资料）。

### 4. 计算机网络的目标是 ( )。 (5.0分)
- [ ] A. 提高计算机安全性
- [ ] B. 分布处理
- [ ] C. 将多台计算机连接起来
- [ ] D. 共享软件、硬件和数据资源

> ****答案与解析****
> **【正确答案】** D
> **【详细解析】** 计算机网络最根本的目标和核心价值就是实现软、硬件及数据资源的共享。连接多台计算机和分布处理是实现这一目标的手段或网络具备的特征，而不是网络发展的终极目标。

### 5. 一座办公楼内各个办公室中的微机进行联网，这个网络属于 ( )。 (5.0分)
- [ ] A. WAN
- [ ] B. LAN
- [ ] C. MAN
- [ ] D. GAN

> ****答案与解析****
> **【正确答案】** B
> **【详细解析】** 按照网络覆盖的地理范围分类：
> * **LAN**（Local Area Network）：局域网，范围通常在几公里以内（如一座办公楼、一个校园、一个家庭）。
> * **MAN**（Metropolitan Area Network）：城域网，范围通常是一个城市。
> * **WAN**（Wide Area Network）：广域网，范围跨越国家、地区甚至全球。
> * 因此，办公楼内的网络属于 LAN。

### 6. 下列哪一项是计算机网络技术发展的一个里程碑，它的研究成果对促进网络技术的发展起到重用的作用，并为 Internet 的形成奠定了基础 ( )。 (5.0分)
- [ ] A. ARPANET
- [ ] B. NSFNET
- [ ] C. Internet
- [ ] D. ATM

> ****答案与解析****
> **【正确答案】** A
> **【详细解析】** **ARPANET**（阿帕网）由美国国防部高级研究计划局于1969年投入运行，它是世界上第一个真正意义上的分组交换网。ARPANET 的成功验证了分组交换技术的可行性，其后续演进直接孕育了 TCP/IP 协议栈，是 Internet（互联网）的前身和雏形，被公认为计算机网络技术发展史上的里程碑。

### 7. 信息高速公路是指 ( )。 (5.0分)
- [ ] A. Internet
- [ ] B. 国家信息基础设施
- [ ] C. 智能化高速公路建设
- [ ] D. 高速公路的信息化建设

> ****答案与解析****
> **【正确答案】** B
> **【详细解析】** “信息高速公路”（Information Superhighway）是一个形象的比喻，通俗地指代高度发达的现代化信息传输网络。其官方和学术上的标准术语是**国家信息基础设施**（NII，National Information Infrastructure）。它不单指公路的信息化，而是指全国范围的高速多媒体传输网络。

### 8. 计算机网络的基本分类方法主要有两种：一种是根据覆盖范围与规模；另一种是根据 ( )。 (5.0分)
- [ ] A. 网络协议
- [ ] B. 网络使用的主机类型
- [ ] C. 网络所使用的传输技术
- [ ] D. 网络服务器类型与规模

> ****答案与解析****
> **【正确答案】** C
> **【详细解析】** 计算机网络最普遍、最基本的两种分类标准是：
> 1. 按**覆盖的地理范围与规模**（分为局域网、城域网、广域网）。
> 2. 按**所使用的传输技术**（分为广播式网络和点对点网络）。

### 9. 以下关于计算机网络特征的描述中，错误的是 ( )。 (5.0分)
- [ ] A. 计算机网络建立的主要目的是实现资源的共享
- [ ] B. 网络用户可以调用网中多台计算机共同完成某项任务
- [ ] C. 联网计算机既可以联网工作也可以脱网工作
- [ ] D. 联网计算机必须使用统一的操作系统

> ****答案与解析****
> **【正确答案】** D
> **【详细解析】** 计算机网络的一大重要特征是其**异构性**。网络中的计算机并不需要使用统一的操作系统，Windows、Linux、macOS、Unix 等不同系统只要共同遵守相同的网络协议（如 TCP/IP 协议栈），就可以顺畅地进行通信和资源共享。

### 10. 计算机网络中通过网络中结点与通信线路之间的几何关系来表示的结构为 ( )。 (5.0分)
- [ ] A. 网络层次
- [ ] B. 协议关系
- [ ] C. 体系结构
- [ ] D. 网络拓扑结构

> ****答案与解析****
> **【正确答案】** D
> **【详细解析】** 在网络工程中，通常把网络中的设备（如计算机、交换机、路由器）抽象为“结点”，把传输介质（如双绞线、光纤）抽象为“链路”。这种由网络结点与通信线路之间的几何关系所构成的图，就称为**网络拓扑结构**（Topology）。

### 12. 下列说法错误的是 ( )。 (5.0分)
- [ ] A. 网络互联是基础
- [ ] B. 网络互通是手段
- [ ] C. 网络协议要完全一致
- [ ] D. 资源共享是目的

> ****答案与解析****
> **【正确答案】** C
> **【详细解析】** 在全球大互联网的环境下，不同的子网可以运行不同的底层协议（如早期的 IPX/SPX、AppleTalk 与 TCP/IP），通过路由器、网关等互连设备进行协议转换，依然可以实现互联互通。因此，并不要求整个网络生态中所有局域网内部的网络协议“完全一致”。

### 13. 计算机的硬件组成可以分为 4 个层次，第一层是 ( )。 (5.0分)
- [ ] A. 芯片
- [ ] B. 板卡
- [ ] C. 设备
- [ ] D. 网络

> ****答案与解析****
> **【正确答案】** A
> **【详细解析】** 从底层到高层，计算机硬件系统的构建层次通常可以划分为：
> * **第一层：芯片**（最基础的集成电路，如CPU芯片、桥片、存储颗粒）。
> * **第二层：板卡**（由芯片和电子元件组装成的电路板，如主板、显卡、网卡）。
> * **第三层：设备**（板卡和外设组合成的完整硬件实体，如主机箱、打印机）。
> * **第四层：网络**（将多台设备连接在一起的整体系统）。

### 14. 在现实中，我们一般将计算机分类为 ( )。 (5.0分)
- [ ] A. 服务器、工作站、台式机、便携机、手持设备
- [ ] B. 大型机、小型机、个人计算机、工作站、巨型计算机
- [ ] C. 服务器、工作站、台式机、笔记本
- [ ] D. 服务器/工作站、台式机、笔记本、掌上电脑，大型机、小型机

> ****答案与解析****
> **【正确答案】** B
> **【详细解析】** 在经典的计算机科学分类体系中，根据计算机的规模、运算速度、处理能力和价格等综合指标，通常将计算机划分为：**巨型机**（Supercomputer）、**大型机**（Mainframe）、**小型机**（Minicomputer）、**工作站**（Workstation）和**个人计算机/微型机**（PC/Microcomputer）。

### 15. 下列网中不是按距离划分的是 ( )。 (5.0分)
- [ ] A. 广域网
- [ ] B. 局域网
- [ ] C. 城域网
- [ ] D. 公用网

> ****答案与解析****
> **【正确答案】** D
> **【详细解析】** 广域网、局域网、城域网都是严格根据地理覆盖距离划分的网络类型。而**公用网**（以及与之对应的**专用网**）则是根据网络的所有权、管理性质以及服务对象来划分的（例如中国电信建设的宽带网络属于公用网，而军队、铁路内部使用的网络属于专用网）。

### 16. 计算机网络拓扑结构主要取决于它的 ( )。 (5.0分)
- [ ] A. 资源子网
- [ ] B. FDDI 网
- [ ] C. 通信子网
- [ ] D. 城域网

> ****答案与解析****
> **【正确答案】** C
> **【详细解析】** 从逻辑功能上看，计算机网络分为**资源子网**（负责处理数据、提供资源，由主机和终端组成）和**通信子网**（负责网络内的数据通信，由通信控制处理机和传输介质组成）。我们日常讨论的星型、总线型等网络拓扑结构，主要是指通信子网中节点的物理或逻辑连接排列方式。

### 17. 一个功能完备的计算机网络需要制定一套复杂的协议集。对于复杂的计算机网络协议来说，最好的组织方式是 ( )。 (5.0分)
- [ ] A. 连续地址编码模型
- [ ] B. 层次结构模型
- [ ] C. 分布式进程通信模型
- [ ] D. 混合结构模型

> ****答案与解析****
> **【正确答案】** B
> **【详细解析】** 为了降低网络设计和维护的复杂度，计算机网络体系结构无一例外地采用了**分层结构模型**（如 OSI 七层参考模型、TCP/IP 四层参考模型）。分层能够将一个庞大复杂的通信问题分解为多个边界清晰、功能单一的子层，使得层与层之间相互独立，便于软硬件的实现与标准化。

### 18. 计算机网络最突出的优点是 ( )。 (5.0分)
- [ ] A. 计算精度高
- [ ] B. 内存容量大
- [ ] C. 运算速度快
- [ ] D. 联网的计算机能够相互共享资源

> ****答案与解析****
> **【正确答案】** D
> **【详细解析】** 计算精度高、内存大、运算速度快这些都是单台计算机本身就具备的计算特性。而把计算机连接成“网络”后，所能带来的核心也是最突出的优点，就是打破地域限制，让联网的计算机之间能够**相互共享资源**。

### 19. 计算机网络能够不受地理上的束缚实现资源共享，下列不属于共享的资源是 ( )。 (5.0分)
- [ ] A. 数据
- [ ] B. 办公人员
- [ ] C. 软件
- [ ] D. 硬件

> ****答案与解析****
> **【正确答案】** B
> **【详细解析】** 计算机网络能够共享的系统资源包括：硬件、软件、数据（信息）。**办公人员**是网络系统的使用者（主体），而不是系统内可以被分配、调用和共享的 IT 资源。

### 20. 下列 ( ) 不是计算机网络的系统结构。 (5.0分)
- [ ] A. 星形结构
- [ ] B. 单线结构
- [ ] C. 总线结构
- [ ] D. 环形结构

> ****答案与解析****
> **【正确答案】** B
> **【详细解析】** 常见的标准网络拓扑结构包括星形、总线形、环形、树形、网状形。在网络系统结构术语中，并没有“单线结构”这一分类。
