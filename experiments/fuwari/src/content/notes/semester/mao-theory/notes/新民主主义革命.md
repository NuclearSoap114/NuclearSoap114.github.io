## 一、新民主主义革命的总路线和基本纲领（大纲第 4 点）

<div id="section-2" class="note-anchor"></div>

### 总路线

> 无产阶级领导的，人民大众的，反对帝国主义、封建主义和官僚资本主义的革命。

**四要素分析**：

| 要素 | 内容 | 关键表述 |
|------|------|------|
| **领导者** | 无产阶级（通过中国共产党） | 区别新旧民主革命的**根本标志** |
| **动力** | 人民大众 | 工人（最基本动力）、农民（主力军）、小资产阶级、民族资产阶级 |
| **对象** | 三座大山 | 帝国主义（首要对象）、封建主义、官僚资本主义 |
| **性质** | 资产阶级民主主义革命 | 但由无产阶级领导→"新"民主主义；属于世界无产阶级社会主义革命的一部分 |
| **前途** | 社会主义 | 分两步走 |

<div id="section-3" class="note-anchor"></div>

### 基本纲领

| 纲领 | 内容 |
|------|------|
| **政治纲领** | 建立无产阶级领导的、工农联盟为基础的、各革命阶级联合专政的民主共和国（**国体：人民民主专政**） |
| **经济纲领** | ①没收封建地主阶级土地归农民所有（**中心内容**）；②没收官僚资本归新民主主义国家所有（双重性质）；③保护民族工商业 |
| **文化纲领** | 无产阶级领导的、人民大众的、反帝反封建的文化，即**民族的、科学的、大众的**文化 |

## 二、新民主主义革命和社会主义革命的辩证关系（大纲第 5 点）

**"两步走"战略**：

```
第一步：新民主主义革命 → 改变半殖民地半封建的社会形态 → 建立新民主主义社会
第二步：社会主义革命 → 建立社会主义社会
```

**辩证关系**：

| 关系 | 表述 |
|------|------|
| **区别** | 性质不同——前者是资产阶级民主主义革命，后者是无产阶级社会主义革命 |
| **联系** | 前者是后者的**必要准备**，后者是前者的**必然趋势** |
| **衔接** | 两个革命阶段必须衔接，中间不容横插一个资产阶级专政的阶段 |

> **核心论述句**
> 新民主主义革命是社会主义革命的必要准备，社会主义革命是新民主主义革命的必然趋势。只有完成前一个革命，才有可能去完成后一个革命。两个革命阶段互相衔接，不容横插资产阶级专政。

## 三、新民主主义革命的道路和基本经验（大纲第 6 点）

<div id="section-6" class="note-anchor"></div>

### 1. 革命道路

> **农村包围城市、武装夺取政权**

- 提出背景：大革命失败后，党的工作重心由城市转向农村
- 毛泽东的贡献：《中国的红色政权为什么能够存在》《井冈山的斗争》《星星之火，可以燎原》
- 土地革命、武装斗争、农村革命根据地建设三者结合（工农武装割据）

<div id="section-7" class="note-anchor"></div>

### 2. 三大法宝

> 毛泽东在《〈共产党人〉发刊词》中提出：**统一战线、武装斗争、党的建设**

| 法宝 | 地位 | 核心内容 |
|------|:---:|------|
| **统一战线** | 战胜敌人的**重要武器** | 团结一切可以团结的力量；两个联盟（工农联盟 + 与非劳动者的联盟） |
| **武装斗争** | 中国革命的主要形式 | 枪杆子里出政权；党指挥枪 |
| **党的建设** | **核心**，伟大工程 | 思想建设（首位）、组织建设、作风建设 |

**三者关系**：统一战线和武装斗争是战胜敌人的两个基本武器，党的组织是掌握这两个武器的英勇战士。

<div id="section-8" class="note-anchor"></div>

### 3. 党的建设

| 方面 | 内容 |
|------|------|
| **三大作风** | 理论联系实际、密切联系群众、批评与自我批评 |
| **思想建设** | 放在**首位**——用马克思主义武装全党 |
| **组织建设** | 民主集中制 |
| **作风建设** | 与人民群众保持血肉联系 |
