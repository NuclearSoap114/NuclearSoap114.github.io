## 通用答题框架（材料分析题 20 分）

```
① 理论定位：这个热点对应课本哪一章、哪个理论 → 2 分
② 概念解释：该理论的核心概念和内涵 → 4 分
③ 材料回扣：结合材料中的具体信息点出关联 → 4 分
④ 展开论述：用理论的多个维度分析材料 → 6 分
⑤ 总结升华：联系新时代意义/个人认识 → 4 分
```

## 热点一：中国式现代化

<div id="section-3" class="note-anchor"></div>

### 理论定位

对应**习近平新时代中国特色社会主义思想**。党的二十大报告提出："以中国式现代化全面推进中华民族伟大复兴。"

<div id="section-4" class="note-anchor"></div>

### 中国式现代化的五个特征（必背）

| 特征 | 内涵 |
|------|------|
| **人口规模巨大** | 14 亿多人口整体迈进现代化，规模超过现有发达国家人口总和 |
| **全体人民共同富裕** | 不是少数人富裕、贫富两极分化——区别于西方现代化 |
| **物质文明和精神文明相协调** | 既要物质富足，也要精神富有——区别于物质主义膨胀的西方现代化 |
| **人与自然和谐共生** | 绿水青山就是金山银山——区别于先污染后治理的老路 |
| **走和平发展道路** | 不搞殖民掠夺、不搞霸权——区别于西方依靠战争和掠夺的现代化 |

<div id="section-5" class="note-anchor"></div>

### 本质要求

> 坚持中国共产党领导，坚持中国特色社会主义，实现高质量发展，发展全过程人民民主，丰富人民精神世界，实现全体人民共同富裕，促进人与自然和谐共生，推动构建人类命运共同体，创造人类文明新形态。

<div id="section-6" class="note-anchor"></div>

### 论述角度

- 与**西方现代化的对比**：中国式现代化打破了"现代化=西方化"的迷思
- 与**马克思主义**的关系：马克思主义中国化时代化的最新成果
- 与**"两个结合"** 的关系：中国式现代化是"两个结合"的产物
- 与**共同富裕**的联系：共同富裕是中国式现代化的本质特征

## 热点二：台湾问题

<div id="section-8" class="note-anchor"></div>

### 理论定位

对应**"一国两制"**——邓小平理论的重要组成部分。也对应**新时代党解决台湾问题的总体方略**。

<div id="section-9" class="note-anchor"></div>

### 核心原则

| 要点 | 内容 |
|------|------|
| **一个中国原则** | 世界上只有一个中国，台湾是中国领土不可分割的一部分。**是两岸关系的政治基础** |
| **"和平统一、一国两制"** | 解决台湾问题的**基本方针** |
| **反对"台独"** | "台独"分裂是祖国统一的最大障碍，是民族复兴的严重隐患 |
| **不承诺放弃使用武力** | 针对的是外部势力干涉和极少数"台独"分裂分子，绝非针对台湾同胞 |

<div id="section-10" class="note-anchor"></div>

### 论述角度

- **法理依据**：《开罗宣言》《波茨坦公告》均明确规定台湾归还中国；联合国第 2758 号决议承认中华人民共和国政府是代表全中国的唯一合法政府
- **历史依据**：台湾自古属于中国——三国时期吴国派卫温到达夷洲（台湾）
- **与党的领导**的关系：解决台湾问题、实现祖国完全统一，是党矢志不渝的历史任务
- **民族复兴**：国家统一是民族复兴的必然要求

## 热点三：科技创新

<div id="section-12" class="note-anchor"></div>

### 理论定位

对应**"三个代表"重要思想**中"代表先进生产力发展要求"、**科学发展观**中"发展是第一要义"以及**习近平新时代中国特色社会主义思想**中"科技自立自强"。

<div id="section-13" class="note-anchor"></div>

### 核心论点

| 论点 | 内容 |
|------|------|
| **科技是第一生产力** | 邓小平提出；科技创新是提高社会生产力和综合国力的战略支撑 |
| **创新是第一动力** | 发展动力决定发展速度、效能、可持续性 |
| **科技自立自强** | 关键核心技术是要不来、买不来、讨不来的 |
| **新型举国体制** | 集中力量办大事的制度优势 |

<div id="section-14" class="note-anchor"></div>

### 论述角度

- 与**马克思主义**的联系：马克思认为科学技术是生产力——邓小平发展了这一观点
- 与**先进生产力**的联系：谁掌握了先进科技，谁就代表了先进生产力的发展方向
- 与**中国式现代化**的联系：科技现代化是中国式现代化的**关键**
- 与**党的领导**的联系：党对科技事业的全面领导

## 热点四：共同富裕

<div id="section-16" class="note-anchor"></div>

### 理论定位

对应**社会主义本质论**（邓小平理论）、**科学发展观**（以人为本）、**习近平新时代中国特色社会主义思想**（中国式现代化的本质特征）。

<div id="section-17" class="note-anchor"></div>

### 核心原则

| 要点 | 内容 |
|------|------|
| **本质要求** | 共同富裕是中国特色社会主义的**本质要求**——邓小平社会主义本质论的落脚点 |
| **不是同时富裕** | 允许一部分人、一部分地区**先富起来**，先富带后富 |
| **不是平均主义** | 共同富裕不是"均贫富"，而是在普遍富裕基础上的有差别的富裕 |
| **物质+精神** | 共同富裕是人民群众**物质生活和精神生活**都富裕 |
| **循序渐进** | 分阶段推进，不能一蹴而就——等不得，也急不得 |

<div id="section-18" class="note-anchor"></div>

### 论述角度

- 与**邓小平理论**的关系：邓小平提出"让一部分人先富起来，先富带动后富，最终达到共同富裕"
- 与**以人民为中心**的关系：共同富裕是以人民为中心的发展思想的根本体现
- 与**乡村振兴**的联系：乡村振兴是实现共同富裕的重要途径——最艰巨最繁重的任务在农村
- 与**中国式现代化**的关系：共同富裕是中国式现代化区别于西方现代化的重要特征

## 热点五：乡村振兴

<div id="section-20" class="note-anchor"></div>

### 理论定位

对应**科学发展观**（统筹兼顾——统筹城乡发展）、**习近平新时代中国特色社会主义思想**（乡村振兴战略）。

<div id="section-21" class="note-anchor"></div>

### 核心内容

| 要点 | 内容 |
|------|------|
| **总目标** | 农业农村现代化 |
| **总方针** | 坚持农业农村优先发展 |
| **总要求** | 产业兴旺、生态宜居、乡风文明、治理有效、生活富裕 |
| **五个振兴** | 产业振兴、人才振兴、文化振兴、生态振兴、组织振兴 |

<div id="section-22" class="note-anchor"></div>

### 论述角度

- 与**共同富裕**的联系：最艰巨最繁重的任务在农村
- 与**党的领导**的联系：五级书记抓乡村振兴
- 与**中国式现代化**的联系：没有农业农村现代化，就没有整个国家的现代化
- 与**毛泽东思想**的联系：毛泽东强调农民问题是革命的首要问题——当下农民富裕是实现共同富裕的关键

## 拓展应用题答题模板（15 分）

> 拓展应用题是开放式高阶题。答题需要**理论 + 实际 + 个人观点**三者结合。

**一般结构**：
```
第一段（3 分）：用课本理论定位——这是哪一章的哪个理论问题
第二段（5 分）：展开分析——两个以上论述角度，结合材料和实际
第三段（4 分）：提出对策/建议/展望——结合国家方针政策
第四段（3 分）：个人认识升华——联系时代、青年责任、"两个确立"等
```

**举例**：如何理解中国式现代化？
> ① 理论定位：党的二十大首次系统阐述，是马克思主义中国化时代化的最新成果
> ② 展开分析：五大特征中选 2-3 个展开，对比西方现代化
> ③ 对策/展望：坚持党的领导，贯彻新发展理念，推进共同富裕
> ④ 个人认识：青年一代应增强"四个自信"，为民族复兴贡献力量
