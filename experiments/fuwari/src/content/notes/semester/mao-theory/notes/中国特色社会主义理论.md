## 一、邓小平理论（大纲第 9-12 点）

<div id="section-2" class="note-anchor"></div>

### 1. 首要的基本理论问题（大纲第 9 点）

> **什么是社会主义、怎样建设社会主义**

邓小平指出：贫穷不是社会主义，发展太慢也不是社会主义。社会主义的本质是解放生产力，发展生产力，消灭剥削，消除两极分化，最终达到共同富裕。

**社会主义本质论**（五句话）：解放生产力，发展生产力，消灭剥削，消除两极分化，最终达到共同富裕。

<div id="section-3" class="note-anchor"></div>

### 2. 精髓（大纲第 10 点）

> **解放思想，实事求是**

- 1978 年《解放思想，实事求是，团结一致向前看》——开辟新时期新道路的宣言书
- 实事求是是马克思主义的精髓，是毛泽东思想的精髓，也是邓小平理论的精髓
- 解放思想是实事求是的**前提**，实事求是是解放思想的**目的**

<div id="section-4" class="note-anchor"></div>

### 3. 主要内容（大纲第 11 点）

| 方面 | 核心内容 |
|------|------|
| **社会主义初级阶段理论** | 我国将长期处于社会主义初级阶段（至少一百年）。党的基本路线："一个中心、两个基本点" |
| **改革开放理论** | 改革是中国的第二次革命，是社会主义制度的自我完善。对外开放是基本国策 |
| **社会主义市场经济理论** | 计划多点还是市场多点，不是社会主义与资本主义的本质区别。计划和市场都是经济手段 |
| **"一国两制"** ⭐ | 在一个中国的前提下，国家主体实行社会主义，港澳台实行资本主义。**香港、澳门已成功实践**。解决台湾问题的基本方针 |
| **党的建设** | 坚持党的领导，加强党的建设 |

<div id="section-5" class="note-anchor"></div>

#### 党在社会主义初级阶段的基本路线

> 领导和团结全国各族人民，以**经济建设为中心**，坚持**四项基本原则**，坚持**改革开放**，自力更生，艰苦创业，为把我国建设成为富强民主文明和谐美丽的社会主义现代化强国而奋斗。

**"一个中心、两个基本点"**：
- 一个中心：**经济建设**
- 两个基本点：**四项基本原则**（立国之本）、**改革开放**（强国之路）

<div id="section-6" class="note-anchor"></div>

#### "一国两制"

| 要点 | 内容 |
|------|------|
| 核心 | **一个中国**——世界上只有一个中国，台湾是中国的一部分 |
| 两制并存 | 国家主体实行社会主义，港澳台实行资本主义 |
| 高度自治 | 港澳享有高度自治权（不是完全自治） |
| 台湾问题 | "和平统一、一国两制"是解决台湾问题的**基本方针** |

<div id="section-7" class="note-anchor"></div>

### 4. 历史地位（大纲第 12 点）

- 邓小平理论是**中国特色社会主义理论体系的开篇之作**
- 是对马克思列宁主义、毛泽东思想的继承和发展
- 是指导党和人民实现中华民族伟大复兴的正确理论

## 二、"三个代表"重要思想（大纲第 13 点）

<div id="section-9" class="note-anchor"></div>

### 核心观点

> 中国共产党必须始终代表**中国先进生产力的发展要求**，代表**中国先进文化的前进方向**，代表**中国最广大人民的根本利益**。

| 核心观点 | 地位 |
|------|------|
| 代表中国先进生产力的发展要求 | 基础和前提 |
| 代表中国先进文化的前进方向 | 灵魂和旗帜 |
| 代表中国最广大人民的根本利益 | **核心**——出发点和归宿 |

**党的建设**方面："三个代表"提出从严治党，增强党的**执政能力**。贯彻"三个代表"要求，关键在坚持**与时俱进**，核心在坚持**党的先进性**，本质在坚持**执政为民**。

## 三、科学发展观（大纲第 14 点）

<div id="section-11" class="note-anchor"></div>

### 科学内涵

| 要点 | 内容 |
|------|------|
| **第一要义** | **发展**——发展是硬道理，是党执政兴国的第一要务 |
| **核心立场** | **以人为本**——发展为了人民、依靠人民、成果由人民共享 |
| **基本要求** | **全面协调可持续**——经济、政治、文化、社会、生态文明五位一体 |
| **根本方法** | **统筹兼顾**——统筹城乡、区域、经济社会、人与自然和谐、国内发展和对外开放 |
