## 二、题型1：数制大小比较

<div id="section-3" class="note-anchor"></div>

### 题型识别

看到：

```text
下列数中最大的是？
下列数中最小的是？
(101001)2、(52)8、(2B)16、(44)10
```

就是进制转换比较题。

<div id="section-4" class="note-anchor"></div>

### 解题步骤

```text
全部转成十进制
再比较大小
```

<div id="section-5" class="note-anchor"></div>

### 原题类型

题目：

```text
下列数中最小的数为（ ）。
A. (101001)2
B. (52)8
C. (2B)16
D. (44)10
```

答案：

```text
A
```

解析：

```text
(101001)2 = 41
(52)8 = 42
(2B)16 = 43
(44)10 = 44

最小是41，所以选A。
```

## 三、题型2：补码与机器数

<div id="section-7" class="note-anchor"></div>

### 题型识别

看到：

```text
8位补码
机器字长
-39
[X]补
[-X]补
补码表示范围
```

就是补码题。

<div id="section-8" class="note-anchor"></div>

### 解题步骤

负数求补码：

```text
先写正数二进制
取反
加1
```

n位补码范围：

```text
-2^(n-1) ~ 2^(n-1)-1
```

<div id="section-9" class="note-anchor"></div>

### 原题类型

题目：

```text
十进制数-39，用8位字长的补码表示，该补码用十六进制表示为（ ）。
A. D8
B. D9
C. 56
D. 38
```

答案：

```text
B
```

解析：

```text
+39 = 0010 0111
取反 = 1101 1000
加1 = 1101 1001
1101 1001 = D9H
```

## 四、题型3：存储容量与地址线

<div id="section-11" class="note-anchor"></div>

### 题型识别

看到：

```text
某计算机字长32位
存储容量256KB
按字编址
寻址范围
```

就是容量/编址题。

<div id="section-12" class="note-anchor"></div>

### 解题步骤

```text
1. 先把总容量换成字节
2. 看按字节编址还是按字编址
3. 按字编址：字数 = 总字节数 / 每字字节数
4. 寻址范围 = 字数
```

<div id="section-13" class="note-anchor"></div>

### 原题类型

题目：

```text
某计算机字长是32位，它的存储容量是256KB，按字编址，它的寻址范围是（ ）。
A. 64K
B. 64KB
C. 128K
D. 128KB
```

答案：

```text
A
```

解析：

```text
32位 = 4B
256KB / 4B = 64K个字
按字编址，所以寻址范围是64K。
```

## 五、题型4：Cache计算

<div id="section-15" class="note-anchor"></div>

### 题型识别

看到：

```text
cache命中率
cache访问时间
主存访问时间
平均访问时间
cache效率
```

就是Cache计算题。

<div id="section-16" class="note-anchor"></div>

### 解题步骤

```text
1. H = 命中次数 / 总访问次数
2. T平均 = H×Tcache + (1-H)×T主存
3. 效率 = Tcache / T平均
```

<div id="section-17" class="note-anchor"></div>

### 原题类型

题目：

```text
CPU执行一段程序时，cache完成存取3800次，主存完成存取200次。
已知cache存取周期为50ns，主存为250ns，求cache/主存系统效率和平均访问时间。
```

答案：

```text
H = 3800 / (3800+200) = 0.95

T平均 = 0.95×50 + 0.05×250
      = 47.5 + 12.5
      = 60ns

效率 = 50 / 60 = 83.3%
```

解析：

先算命中率，再算平均访问时间，最后算效率。

## 六、题型5：存储系统设计与地址译码

<div id="section-19" class="note-anchor"></div>

### 题型识别

看到：

```text
ROM区
RAM区
0000H~1FFFH
2000H~7FFFH
74LS138
A15 A14 A13
片选
```

就是存储系统设计大题。

<div id="section-20" class="note-anchor"></div>

### 解题步骤

```text
1. 地址范围求容量
2. 根据容量选ROM/RAM芯片
3. 低位地址线接芯片内部地址
4. 高位地址线接74LS138译码器
5. 译码输出接片选
6. 说明总容量和是否用满地址空间
```

<div id="section-21" class="note-anchor"></div>

### 老师原题类型

题目：

```text
CPU有16根地址线A15~A0，8根数据线D7~D0。
系统程序区0000H~1FFFH使用ROM。
用户程序区2000H~7FFFH使用RAM。
要求选择芯片并使用74LS138完成片选。
```

答案要点：

```text
系统区：
1FFFH - 0000H + 1 = 2000H = 8KB
选1片8K×8 ROM

用户区：
7FFFH - 2000H + 1 = 6000H = 24KB
选3片8K×8 RAM

A0~A12接所有芯片地址端
D0~D7接所有芯片数据端
A15、A14、A13接74LS138输入C、B、A

Y0选ROM
Y1、Y2、Y3分别选三片RAM

总容量：
8KB + 24KB = 32KB

CPU最大寻址：
2^16 = 64KB

没有完全利用，高32KB空闲。
```

## 七、题型6：指令格式设计

<div id="section-23" class="note-anchor"></div>

### 题型识别

看到：

```text
主存容量4M×16
指令字长16位
108种操作
6种寻址方式
画一地址指令格式
```

就是指令格式设计题。

<div id="section-24" class="note-anchor"></div>

### 解题步骤

```text
1. 操作码位数 = ceil(log2(操作种类))
2. 寻址特征位数 = ceil(log2(寻址方式数))
3. 形式地址位数 = 指令字长 - 操作码位数 - 寻址特征位数
```

<div id="section-25" class="note-anchor"></div>

### 老师原题类型

题目：

```text
某机主存容量为4M×16位，存储字长等于指令字长。
指令系统可完成108种操作，支持6种寻址方式。
设计一地址指令格式。
```

答案：

```text
操作码：
2^7 = 128 ≥ 108，所以OP为7位

寻址特征：
2^3 = 8 ≥ 6，所以MOD为3位

形式地址：
16 - 7 - 3 = 6位

格式：
OP(7位) | MOD(3位) | A(6位)
```

## 八、题型7：寻址方式与寻址范围

<div id="section-27" class="note-anchor"></div>

### 题型识别

看到：

```text
立即寻址
直接寻址
间接寻址
相对寻址
访存次数
寻址范围
```

就是寻址题。

<div id="section-28" class="note-anchor"></div>

### 解题步骤

```text
立即寻址：操作数=A，访存0次
直接寻址：EA=A，访存1次
间接寻址：EA=M[A]，访存2次
寄存器寻址：操作数在寄存器，访存0次
相对寻址：EA=PC+A，访存1次
```

<div id="section-29" class="note-anchor"></div>

### 原题类型

题目：

```text
形式地址A为6位，求直接寻址最大范围、立即数范围、相对位移范围。
```

答案：

```text
直接寻址：
2^6 = 64个单元，地址0~63

立即数：
6位补码 = -32~+31

相对位移：
6位补码 = -32~+31
```

解析：

直接寻址按无符号地址看；立即数和相对位移通常按有符号补码看。

## 十、题型9：指令执行微操作

<div id="section-35" class="note-anchor"></div>

### 题型识别

看到：

```text
ADD ACC,M
ADD addr
SUB addr
取指周期
单总线CPU
写出微操作
```

就是微操作题。

<div id="section-36" class="note-anchor"></div>

### 解题步骤

先写取指：

```text
PC → MAR
M[MAR] → MDR
MDR → IR
PC + 指令长度 → PC
```

再写执行。

<div id="section-37" class="note-anchor"></div>

### 原题类型

题目：

```text
执行ADD X，写出主要微操作。
```

答案：

```text
X → MAR
M[MAR] → MDR
ACC + MDR → ACC
```

解析：

ADD X的含义是：

```text
ACC ← ACC + M[X]
```

所以先取X地址中的操作数，再和ACC相加。

## 十一、题型10：微程序控制

<div id="section-39" class="note-anchor"></div>

### 题型识别

看到：

```text
微操作
微命令
微指令
微程序
控制存储器
字段编码
```

就是微程序控制题。

<div id="section-40" class="note-anchor"></div>

### 解题步骤

概念题直接背：

```text
微命令控制微操作
微指令是一组微命令
微程序是一组微指令
控制存储器存放微程序
```

字段位数题：

```text
位数 = ceil(log2(k+1))
```

其中k是互斥微命令个数，+1表示空操作。

<div id="section-41" class="note-anchor"></div>

### 仿题

题目：

```text
某字段有7个互斥微命令，需要几位编码？
```

答案：

```text
ceil(log2(7+1)) = 3位
```

解析：

7个命令加1个“不发命令”状态，共8种。

## 十二、题型11：总线性能计算

<div id="section-43" class="note-anchor"></div>

### 题型识别

看到：

```text
总线频率100MHz
总线周期4个时钟周期
数据总线宽16位
读取200个32位数据
平均传输率
```

就是总线性能计算题。

<div id="section-44" class="note-anchor"></div>

### 解题步骤

```text
1. 时钟周期 = 1 / 频率
2. 总线周期 = 时钟周期 × 每周期时钟数
3. 传输次数 = 总数据量 / 每次传输位数
4. 总时间 = 传输次数 × 总线周期
5. 平均传输率 = 总数据量 / 总时间
```

<div id="section-45" class="note-anchor"></div>

### 老师原题类型

题目：

```text
总线时钟频率100MHz，每个总线周期占4个时钟周期，数据总线宽16位。
CPU连续读取200个32位数据，每个数据分两次16位传输。
求总时间和平均传输率。
```

答案：

```text
时钟周期 = 1/100MHz = 10ns

总线周期 = 4×10ns = 40ns

每个32位数据需要2次传输
总传输次数 = 200×2 = 400次

总时间 = 400×40ns = 16000ns = 16μs

总数据量 = 200×32bit = 6400bit

平均传输率 = 6400bit / 16μs = 400Mbps
```

## 十三、题型12：I/O、中断、DMA

<div id="section-47" class="note-anchor"></div>

### 题型识别

看到：

```text
程序查询
中断
DMA
CPU参与程度
数据传输效率
直接存储器访问
```

就是I/O控制方式题。

<div id="section-48" class="note-anchor"></div>

### 解题步骤

先比较：

| 方式 | CPU参与 | 效率 |
|---|---|---|
| 程序查询 | 最高 | 低 |
| 中断 | 较低 | 较高 |
| DMA | 最低 | 高 |

DMA流程：

```text
CPU初始化DMA控制器
外设发出DMA请求
DMA请求总线
CPU让出总线
DMA控制外设与主存直接传输
传输完成后中断通知CPU
```

<div id="section-49" class="note-anchor"></div>

### 老师原题类型

题目：

```text
说明DMA方式工作原理及对CPU执行效率的影响。
```

答案：

```text
DMA由DMA控制器接管总线，使外设和主存直接交换数据。
CPU只在传输开始时设置地址、长度、方向等参数，在传输结束时处理中断。
优点是减少CPU搬运数据的负担，提高I/O效率和CPU利用率。
局限是需要DMA控制器，硬件成本增加；DMA占用总线时可能影响CPU访存。
```
