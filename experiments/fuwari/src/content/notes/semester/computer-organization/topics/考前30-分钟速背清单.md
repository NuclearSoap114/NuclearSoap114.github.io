## 一、最重要公式

<div id="section-2" class="note-anchor"></div>

### 1. 补码范围

```text
n位补码范围：
-2^(n-1) ~ 2^(n-1)-1
```

例：

```text
8位补码：-128 ~ 127
```

---

<div id="section-3" class="note-anchor"></div>

### 2. 负数补码

```text
负数补码 = 原码符号位不变，其余位取反，再加1
```

口诀：

```text
负数补码：取反加一
```

---

<div id="section-4" class="note-anchor"></div>

### 3. 补码减法

```text
[X-Y]补 = [X]补 + [-Y]补
```

口诀：

```text
减法变加法
```

---

<div id="section-5" class="note-anchor"></div>

### 4. 溢出判断

```text
同号相加，结果异号，发生溢出
```

---

<div id="section-6" class="note-anchor"></div>

### 5. 存储容量

```text
存储容量 = 存储单元数 × 每单元位数
```

---

<div id="section-7" class="note-anchor"></div>

### 6. 地址线数量

```text
2^n = 存储单元个数
n = 地址线根数
```

例：

```text
8K = 2^13，所以需要13根地址线
```

---

<div id="section-8" class="note-anchor"></div>

### 7. Cache命中率

```text
H = 命中次数 / 总访问次数
```

---

<div id="section-9" class="note-anchor"></div>

### 8. Cache平均访问时间

常用：

```text
T平均 = H × Tcache + (1-H) × T主存
```

如果题目强调“先访问Cache，未命中再访问主存”：

```text
T平均 = Tcache + (1-H) × T主存
```

---

<div id="section-10" class="note-anchor"></div>

### 9. Cache效率

```text
效率 = Tcache / T平均
```

---

<div id="section-11" class="note-anchor"></div>

### 10. 操作码位数

```text
操作码位数 = ceil(log2(指令种类数))
```

---

<div id="section-12" class="note-anchor"></div>

### 11. 寻址特征位数

```text
寻址特征位数 = ceil(log2(寻址方式数))
```

---

<div id="section-13" class="note-anchor"></div>

### 12. 形式地址位数

```text
形式地址位数 = 指令字长 - 操作码位数 - 寻址特征位数
```

---

<div id="section-14" class="note-anchor"></div>

### 13. 微命令字段编码位数

有空操作时：

```text
位数 = ceil(log2(k+1))
```

k表示互斥微命令个数。

---

<div id="section-15" class="note-anchor"></div>

### 14. 总线带宽

```text
总线带宽 = 每次传送数据量 × 总线频率
```

注意：

```text
32位 = 4Byte
64位 = 8Byte
```

---

<div id="section-16" class="note-anchor"></div>

### 15. 总线周期

```text
时钟周期 = 1 / 时钟频率
总线周期 = 时钟周期 × 每个总线周期所需时钟数
```

---

<div id="section-17" class="note-anchor"></div>

### 16. 平均传输率

```text
平均传输率 = 总数据量 / 总时间
```

## 二、必背寄存器

| 寄存器 | 作用 |
|---|---|
| PC | 存放下一条指令地址 |
| IR | 存放当前正在执行的指令 |
| MAR | 存放访存地址 |
| MDR | 存放访存数据 |
| ACC | 存放运算结果 |
| MQ | 乘除法相关 |
| PSW | 存放状态标志 |
| SP | 堆栈指针 |

口诀：

```text
PC下一条
IR当前令
MAR存地址
MDR存数据
ACC存结果
PSW存状态
```

## 三、必背指令执行模板

<div id="section-20" class="note-anchor"></div>

### 1. 取指周期

```text
PC → MAR
M[MAR] → MDR
MDR → IR
PC + 1 → PC
```

如果题目说指令长度不是1个字，要写：

```text
PC + 指令长度 → PC
```

---

<div id="section-21" class="note-anchor"></div>

### 2. ADD X

含义：

```text
ACC ← ACC + M[X]
```

微操作：

```text
X → MAR
M[MAR] → MDR
ACC + MDR → ACC
```

---

<div id="section-22" class="note-anchor"></div>

### 3. SUB X

含义：

```text
ACC ← ACC - M[X]
```

微操作：

```text
X → MAR
M[MAR] → MDR
ACC - MDR → ACC
```

---

<div id="section-23" class="note-anchor"></div>

### 4. MOV R1, R2

常见含义：

```text
R2 → R1
```

微操作：

```text
R2 → 总线 → R1
```

## 四、寻址方式速背

| 寻址方式 | 地址码含义 | 有效地址 |
|---|---|---|
| 立即寻址 | 操作数本身 | 无需EA |
| 直接寻址 | 操作数地址 | EA = A |
| 间接寻址 | 操作数地址的地址 | EA = M[A] |
| 寄存器寻址 | 寄存器编号 | 操作数在R |
| 寄存器间接寻址 | 寄存器中存地址 | EA = (R) |
| 相对寻址 | 位移量 | EA = PC + A |
| 基址寻址 | 位移量 | EA = 基址寄存器 + A |
| 变址寻址 | 位移量 | EA = 变址寄存器 + A |

口诀：

```text
立即：数在指令
直接：地址在指令
间接：地址的地址
寄存器：数在寄存器
寄存器间接：地址在寄存器
相对：PC加位移
```

## 七、总线计算模板

<div id="section-34" class="note-anchor"></div>

### 看到题目

关键词：

```text

总线宽度
总线周期
传输率
```

---

<div id="section-35" class="note-anchor"></div>

### 固定步骤

```text
1. 位宽换成字节
2. 时钟周期 = 1 / 频率
3. 总线周期 = 时钟周期 × 周期数
4. 传输次数 = 总数据量 / 每次传输量
5. 总时间 = 传输次数 × 总线周期
6. 平均传输率 = 总数据量 / 总时间
```

## 八、DMA大题模板

<div id="section-37" class="note-anchor"></div>

### DMA定义

```text
DMA是直接存储器访问，允许外设和主存直接交换数据，不需要CPU逐字节搬运。
```

---

<div id="section-38" class="note-anchor"></div>

### DMA工作流程

```text
1. CPU初始化DMA控制器，设置主存地址、传输长度、传输方向
2. 外设提出DMA请求
3. DMA控制器向CPU请求总线
4. CPU响应并让出总线
5. DMA控制器接管总线
6. 外设与主存直接传输数据
7. 传输结束后，DMA控制器用中断通知CPU
```

---

<div id="section-39" class="note-anchor"></div>

### DMA优点

```text
减少CPU搬运数据负担
提高I/O效率
适合高速、大批量数据传输
```

---

<div id="section-40" class="note-anchor"></div>

### DMA缺点

```text
需要额外DMA控制器
硬件复杂
DMA占用总线时可能影响CPU访存
```

## 九、I/O方式对比

| 方式 | CPU参与 | 效率 | 特点 |
|---|---|---|---|
| 程序查询 | 最高 | 低 | CPU一直等待设备 |
| 中断 | 较低 | 较高 | 设备准备好后通知CPU |
| DMA | 最低 | 高 | 外设和主存直接传输 |
| 通道 | 更低 | 更高 | 专门I/O处理机管理 |

口诀：

```text
查询一直等
中断来通知
DMA直接搬
通道更高级
```

## 十一、微程序控制速背

```text
微操作：最基本操作，如PC→MAR
微命令：控制微操作的命令
微指令：一组微命令
微程序：一组微指令
```

硬布线控制器：

```text
速度快，修改难
```

微程序控制器：

```text
设计灵活，修改容易，速度较慢
```

## 十三、浮点数速背

浮点数一般表示：

```text
N = M × 2^E
```

其中：

```text
M：尾数
E：阶码
```

结论：

```text
阶码决定范围
尾数决定精度
```

```text
MAR存地址

```

---

<div id="section-60" class="note-anchor"></div>

### 2. PC和IR

```text
PC存下一条指令地址

```

<div id="section-61" class="note-anchor"></div>

```text
32bit = 4Byte

```


```text

```

## 十六、考前最后10分钟只背这些

```text
1. 取指周期：
PC→MAR
M[MAR]→MDR
MDR→IR
PC+1→PC

2. Cache：
H=命中/总访问
T=H×Tc+(1-H)×Tm
效率=Tc/T

3. 存储设计：
低位进片内，高位做片选

4. 指令格式：
OP=ceil(log2操作数))
MOD=ceil(log2寻址方式数)
A=指令长-OP-MOD

5. 总线：
带宽=每次传输数据量×频率

6. DMA：
请求→响应→接管→传输→结束

7. 寻址：
立即数在指令
直接地址在指令
间接地址的地址
相对PC+偏移

8. 补码：
负数取反加一
减法变加法
同号相加异号溢出
```
