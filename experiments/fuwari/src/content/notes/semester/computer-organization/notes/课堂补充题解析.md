## 题 1：多体低位交叉存储器

**题目**：

某机器采用**四体低位交叉存储器**，存取时间为存取周期的 **1/4**。现分别执行下述操作：

① 读取 **6 个**连续地址单元中存放的存储字，重复 **80 次**；

② 读取 **8 个**连续地址单元中存放的存储字，重复 **60 次**。

则①、②所花费的时间之比为（ ）

A. 1:1　　B. 2:1　　C. 4:3　　D. 3:4

**这类题怎么做**：

> 多体低位交叉存储器中，存取周期 T = 体数 m × 存取时间 τ。相邻体的启动间隔 = τ（即 T/m）。连续读 n 个字的总时间 = 第一个字的 τ + (n−1)τ = **nτ**。因为 m 个体轮流启动，间隔刚好 τ，第 n 个字在时刻 nτ 读出。重复次数直接乘。

**解答**：

设存取时间 τ，存取周期 T = 4τ。四体交叉，相邻体启动间隔 = τ。地址 mod 4 轮流进入体 0,1,2,3,0,1,…

- 操作①：单次读 6 个字需 6τ，重复 80 次 = 80 × 6τ = 480τ
- 操作②：单次读 8 个字需 8τ，重复 60 次 = 60 × 8τ = 480τ

时间比 = 480τ : 480τ = **1 : 1**

**答案：A**

## 题 2：2018 统考真题 — IO 方式综合

**题目**：

假定计算机的主频为 **500 MHz**，CPI 为 **4**。现有设备 A 和 B，其数据传输速率分别为 **2 MB/s** 和 **40 MB/s**，对应 I/O 接口中各有一个 **32 位**数据缓冲寄存器。回答下列问题，要求给出计算过程。

（1）设备 A 采用**定时查询 I/O** 方式，每次输入/输出都至少执行 **10 条指令**。设备 A 最多间隔多长时间查询一次才能不丢失数据？CPU 用于设备 A 输入/输出的时间占 CPU 总时间的百分比至少是多少？

（2）在**中断 I/O** 方式下，若每次中断响应和中断处理的总时钟周期数至少为 **400**，则设备 B 能否采用中断 I/O 方式？为什么？

（3）若设备 B 采用 **DMA** 方式，每次 DMA 传送的数据块大小为 **1000 B**，CPU 用于 DMA 预处理和后处理的总时钟周期数为 **500**，则 CPU 用于设备 B 输入/输出的时间占 CPU 总时间的百分比最多是多少？

**这类题怎么做**：

> **通用步骤**：
> ① 时钟周期 T = 1/f
> ② 缓冲区填满时间 = 缓冲大小 ÷ 数据传输速率
> ③ 查询间隔 ≤ 填满时间（否则数据被覆盖）
> ④ CPU 占比 = (每秒操作次数 × 每次时钟周期开销) ÷ CPU 主频
>
> **中断可行性判断**：比较 中断处理时间 与 数据到达间隔。前者 > 后者 → 不能用中断。
>
> **DMA**：每秒 DMA 次数 = 数据速率 ÷ 块大小。CPU 占比公式同上，开销只看预处理+后处理。

**解答**：

**已知**：主频 500MHz → T_clk = 2ns。CPI = 4。缓冲 = 32 位 = 4B。A = 2MB/s，B = 40MB/s。

**（1）设备 A 定时查询**

填满缓冲区时间 = 4B ÷ 2MB/s = 2 × 10⁻⁶ s = **2 μs** → 查询间隔 ≤ **2 μs**。

每秒查询次数 = 1 / 2μs = 5 × 10⁵ 次。每次 10 条指令 × 4 CPI = 40 时钟周期。

每秒用于查询的时钟周期 = 5×10⁵ × 40 = 2×10⁷ 个。

CPU 每秒总时钟周期 = 500 × 10⁶ = 5×10⁸ 个。

占比 = 2×10⁷ / 5×10⁸ = **4%**。

**（2）设备 B 中断方式是否可行**

数据到达间隔 = 4B ÷ 40MB/s = 10⁻⁷ s = **0.1 μs**。

中断处理时间 = 400 × 2ns = 800ns = **0.8 μs**。

0.8 μs > 0.1 μs → 中断处理时间远大于数据到达间隔，CPU 来不及处理。

→ **不能采用中断 I/O 方式**。

**（3）设备 B 采用 DMA 方式**

每秒 DMA 传送次数 = 40MB ÷ 1000B = 4 × 10⁴ 次。

每次 DMA 的 CPU 开销 = 500 个时钟周期。

每秒 CPU 用于 DMA 的时钟周期 = 4×10⁴ × 500 = 2×10⁷ 个。

占比 = 2×10⁷ / 5×10⁸ = **4%**。

## 题 3：2009 统考真题 — 中断 vs DMA CPU 占比

**题目**：

某计算机的 CPU 主频为 **500 MHz**，CPI 为 **5**（执行每条指令平均需 5 个时钟周期）。假定某外设的数据传输速率为 **0.5 MB/s**，采用**中断**方式与主机进行数据传送，以 **32 位**为传输单位，对应的中断服务程序包含 **18 条指令**，中断服务的其他开销相当于 **2 条指令**的执行时间。回答下列问题，要求给出计算过程。

（1）在中断方式下，CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少？

（2）当该外设的数据传输速率达到 **5 MB/s** 时，改用 **DMA** 方式传送数据。假定每次 DMA 传送块大小为 **5000 B**，且 DMA 预处理和后处理的总开销为 **500 个时钟周期**，则 CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少（假设 DMA 与 CPU 之间没有访存冲突）？

**这类题怎么做**：

> 同题 2 的方法。额外注意：**中断每次开销 = (服务程序指令数 + 额外指令数) × CPI**。

**解答**：

**已知**：主频 500MHz → T = 2ns。CPI = 5。传输单位 = 32 位 = 4B。

**（1）中断方式，0.5 MB/s**

每秒中断次数 = 0.5×10⁶ B/s ÷ 4B = 1.25 × 10⁵ 次/秒。

每次中断消耗 = (18 条服务 + 2 条额外) = 20 条指令。每次耗时 = 20 × 5 CPI = 100 时钟周期。

每秒用于中断 = 1.25×10⁵ × 100 = 1.25×10⁷ 时钟周期。

总时钟周期/秒 = 5×10⁸。

占比 = 1.25×10⁷ / 5×10⁸ = 0.025 = **2.5%**。

**（2）DMA 方式，5 MB/s**

每秒 DMA 传送次数 = 5×10⁶ B/s ÷ 5000B = 1000 次/秒。

每次 DMA 开销 = 500 时钟周期。

每秒用于 DMA = 1000 × 500 = 5×10⁵ 时钟周期。

占比 = 5×10⁵ / 5×10⁸ = 0.001 = **0.1%**。

> 数据速率从 0.5MB/s 提高到 5MB/s（10 倍），CPU 占比反而从 2.5% 降到 0.1%。这就是 DMA 的效率优势——CPU 只在传输开始和结束时介入。

## 题 4：2016 统考真题 — 异步串行通信

**题目**：

假定 CPU 主频为 **50 MHz**，CPI 为 **4**。设备 D 采用**异步串行通信**方式向主机传送 **7 位 ASCII 码**字符，通信规程中有 **1 位奇校验位**和 **1 位停止位**，从 D 接收启动命令到字符送入 I/O 端口需要 **0.5 ms**。回答下列问题，要求说明理由。

（1）每传送一个字符，在异步串行通信线路上共需传输多少位？在设备 D 持续工作过程中，每秒最多可向 I/O 端口送入多少个字符？

（2）设备 D 采用**中断 I/O** 方式。一个字符传送时间包括：设备 D 将字符送 I/O 端口的时间、中断响应时间和中断服务程序前 **15 条指令**的执行时间。计算 CPU 用于该任务的时间占整个 CPU 时间的百分比。在中断响应阶段，CPU 主要进行哪些操作？

**这类题怎么做**：

> **异步串行通信帧** = 1 起始位 + 数据位 + 校验位（有则 1 位）+ 停止位（1/1.5/2 位）。直接相加。
>
> **每秒字符数** = 1000ms ÷ 单字符处理时间(ms)。
>
> **中断 I/O 的 CPU 占比**：设备传字符到 I/O 端口的时间是**设备的工作**，CPU 在这期间可以等待中断、做其他事。CPU 实际开销只有"中断响应 + 服务指令"。中断响应阶段 CPU 做：**关中断、保护断点和程序状态、识别中断源**。

**解答**：

**（1）每字符传输位数 & 每秒最多字符数**

异步串行通信帧：1 起始位 + 7 位 ASCII 数据 + 1 位奇校验 + 1 位停止位 = **10 位**。

每个字符处理时间 = 0.5 ms。

每秒最多字符数 = 1000ms / 0.5ms = **2000 个/秒**。

**（2）CPU 时间占比**

时钟周期 = 1/50MHz = 20ns。

中断响应时间（关中断、保护断点和程序状态、识别中断源）≈ 10 条指令的量级。

中断服务程序 = 15 条指令。

CPU 每字符开销 = (10 + 15) × 4 CPI = 100 个时钟周期。

每秒处理 2000 个字符，总开销 = 2000 × 100 = 2×10⁵ 个时钟周期。

CPU 每秒总时钟 = 50×10⁶ = 5×10⁷。

占比 = 2×10⁵ / 5×10⁷ = **0.4%**。

## 题 5：2024 统考真题 — int → short 截断

**题目**：

C 语言代码段如下，执行该代码段后，j 的值是（ ）

```c
int i = 32777;
short si = i;
int j = si;
```

A. −32777　　B. −32759　　C. 32759　　D. 32777

**这类题怎么做**：

> **大类型 → 小类型（int → short）**：截断低 N 位，按目标类型解读。short 是 16 位有符号补码，范围 [−32768, 32767]。
>
> **快速算法**：值超出目标范围？加减 2^(目标位数) 直到落入。16 位 → 加减 65536。
>
> **小类型 → 大类型（short → int）**：有符号数**符号扩展**（高位补符号位），值不变。

**解答**：

int i = 32777。short 是 16 位有符号，范围 [−32768, 32767]。

32777 > 32767 → 溢出。快速法：32777 − 65536 = **−32759**。

验证：32777₁₀ = 1000 0000 0000 1001₂（16 位）。最高位=1 → 补码解读 → 取反加 1 得 32759 → 真值 −32759。

short si = −32759。int j = si → 符号扩展，值不变，仍为 −32759。

**答案：B**

## 题 6：2017 统考真题 — 指令格式扩展编码

**题目**：

某计算机按字节编址，指令字长固定且只有两种指令格式，其中**三地址指令 29 条**、**二地址指令 107 条**，每个地址字段为 **6 位**，则指令字长至少应该是（ ）

A. 24　　B. 26　　C. 28　　D. 32

**这类题怎么做**：

> **扩展操作码设计步骤**：
> 1. 短格式（多地址）的 OP 位数 = ⌈log₂(指令数)⌉
> 2. 剩余空间 = 2^OP − 已用指令数
> 3. 长格式需要：剩余空间 × 2^(长格式额外 OP 位数) ≥ 长格式指令数
> 4. 指令字长 = max(两种格式各自的 OP 位数 + 地址位数)，取字节倍数

**解答**：

三地址：地址 = 3×6 = 18 位。OP = ⌈log₂29⌉ = 5 位。剩余 = 2⁵ − 29 = 3 个编码。

二地址：地址 = 2×6 = 12 位。需 3 × 2^(k'−5) ≥ 107 → 2^(k'−5) ≥ 35.67 → k'−5 ≥ 6 → k' ≥ 11 位。

字长 = max(5+18=23, 11+12=23) = 23 → 取字节倍数 → **24 位**。

**答案：A**

## 题 7：2022 统考真题 — 扩展操作码最大条数

**题目**：

设计某指令系统时，假设采用 **16 位定长指令字**格式，操作码使用**扩展编码**方式，地址码为 **6 位**，包含**零地址、一地址和二地址** 3 种格式的指令。若二地址指令有 **12 条**，一地址指令有 **254 条**，则零地址指令的条数最多为（ ）

**这类题怎么做**：

> 同题 6，逐层往下算。每层释放 6 位地址字段，即乘 2⁶ = 64。公式：
> - 第 N 层可用编码 = 上层剩余编码 × 2^(本层释放的地址位数)
> - 第 N 层剩余 = 可用 − 本层已用

**解答**：

指令字长 16 位，地址码 6 位。

| 层 | OP 位数 | 地址占用 | 编码空间 | 已用 | 剩余 |
|:---|:---:|:---:|:---:|:---:|:---:|
| 二地址 | 4 | 12 | 16 | 12 | **4** |
| 一地址 | 10 | 6 | 4×64=256 | 254 | **2** |
| 零地址 | 16 | 0 | 2×64=**128** | ? | — |

零地址指令最多 **128 条**。

## 题 8：2010 统考真题 — 指令格式 + 寻址方式综合

**题目**：

某计算机字长为 **16 位**，主存地址空间大小为 **128 KB**，**按字编址**，采用**单字长指令格式**，指令各字段定义如下：

```
15      12  11      6   5       0
┌─────────┬───────────┬──────────┐
│   OP    │ 源操作数    │ 目的操作数 │
└─────────┴───────────┴──────────┘
          Ms(3)+Rs(3)  Md(3)+Rd(3)
```

转移指令采用相对寻址方式，相对偏移量用补码表示，寻址方式定义见下表。

| Ms/Md | 寻址方式 | 助记符 | 含义 |
|:---:|------|------|------|
| 000B | 寄存器直接 | Rn | 操作数 = (Rn) |
| 001B | 寄存器间接 | (Rn) | 操作数 = ((Rn)) |
| 010B | 寄存器间接自增 | (Rn)+ | 操作数 = ((Rn))，(Rn) + 1 → Rn |
| 011B | 相对 | D(Rn) | 转移目标地址 = (PC) + (Rn) |

注：(X) 表示存储器地址 X 或寄存器 X 的内容。

回答下列问题：

**（1）** 该指令系统最多可有多少条指令？该计算机最多有多少个通用寄存器？存储器地址寄存器（MAR）和存储器数据寄存器（MDR）至少各需要多少位？

**（2）** 转移指令的目标地址范围是多少？

**（3）** 若操作码 0010B 表示加法操作（助记符为 add），寄存器 R4 和 R5 的编号分别为 100B 和 101B，R4 的内容为 1234H，R5 的内容为 5678H，地址 1234H 中的内容为 5678H，5678H 中的内容为 1234H，则汇编语句 `add (R4), (R5)+`（逗号前为源操作数，逗号后为目的操作数）对应的机器码是什么（用十六进制表示）？该指令执行后，哪些寄存器和存储单元的内容会改变？改变后的内容是什么？

**这类题怎么做**：

> **（1）字段分析法**：OP n 位 → 指令数 = 2ⁿ。寄存器号 m 位 → 寄存器数 = 2^m。MAR = ⌈log₂(地址空间/编址单位)⌉。MDR = 字长。
>
> **（2）转移范围**：看 PC 和基址寄存器的位数，都是 16 位 → 全地址空间。
>
> **（3）机器码组装**：OP + Ms + Rs + Md + Rd（十六进制）。**(Rn)+ 自增寻址执行顺序**：先取操作数 → 参与运算 → Rn+1（类似 C 的 *ptr++）。

**解答**：

**（1）**
- OP 4 位 → 最多 2⁴ = **16 条指令**
- Rs/Rd 各 3 位 → 最多 2³ = **8 个通用寄存器**
- 128KB 按字编址（字长 16 位 = 2B）→ 地址空间 = 128KB/2B = 64K 字 → MAR = log₂(64K) = **16 位**
- MDR = 字长 = **16 位**

**（2）**

转移目标地址 = (PC) + (Rn)，PC 和 Rn 均为 16 位，目标地址范围 = **0000H ~ FFFFH**。

**（3）**

组装机器码：

```
OP = 0010B (add)
源操作数：Ms = 001B（寄存器间接）, Rs = 100B（R4）
目的操作数：Md = 010B（寄存器间接自增）, Rd = 101B（R5）

机器码 = 0010 001 100 010 101
       = 0010 0011 0001 0101
       = 2315H
```

指令 `add (R4), (R5)+` 含义：((R4)) + ((R5)) → (R5)，然后 R5 + 1 → R5。

执行过程：
- 源操作数 = ((R4)) = (1234H) = **5678H**
- 目的地址 = (R5) = **5678H**
- 目的原值 = ((R5)) = (5678H) = **1234H**
- 加法：5678H + 1234H = **68ACH**
- 追结果：(5678H) = **68ACH**
- 自增：R5 = 5678H + 1 = **5679H**

| 变化对象 | 原值 | 新值 |
|------|------|------|
| R5 | 5678H | 5679H |
| 存储单元 5678H | 1234H | 68ACH |
