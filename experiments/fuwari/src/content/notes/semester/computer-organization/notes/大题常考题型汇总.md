## 题型一：Cache 效率/平均访问时间计算

**出现**：22-23 Q1, 21-22 Q3｜**分值**：11 分

<div id="section-3" class="note-anchor"></div>

### 解题模板

```
已知：Cache 存取周期 t_c，主存存取周期 t_m
      Cache 命中次数 N_c，主存访问次数 N_m

① 命中率：    h = N_c / (N_c + N_m)
② 平均访问时间：t_a = h·t_c + (1-h)·t_m
③ 系统效率：  e = t_c / t_a × 100%
```

<div id="section-4" class="note-anchor"></div>

### 变体
- 给命中率 + 倍数关系（"主存比 Cache 慢 N 倍"）→ 先求 t_c 和 t_m
- 给主存周期，反推 Cache 周期

> 📄 详见：[补充大题（Cache+微指令+进位链）](/notes/semester/computer-organization/notes/%E8%A1%A5%E5%85%85%E5%A4%A7%E9%A2%98-cache%E4%B8%8E%E5%BE%AE%E6%8C%87%E4%BB%A4%E4%B8%8E%E8%BF%9B%E4%BD%8D%E9%93%BE/#section-1)

## 题型二：存储器地址译码电路

**出现**：22-23 Q3｜**分值**：11 分

<div id="section-6" class="note-anchor"></div>

### 解题模板

```
① 算片内地址线数：n = log₂(芯片容量/字节数)
② 芯片容量→低位 n 根地址线接芯片地址端
③ 高位地址线→接译码器输入（74LS138 的 C,B,A）
④ 译码器输出→芯片片选端 CS
⑤ 使能端接法：MREQ（低有效）or 固定电平
```

<div id="section-7" class="note-anchor"></div>

### 必背
- 74LS138：3 输入→8 输出（低有效）
- 2:4 译码器（74LS139）：2 输入→4 输出
- 地址范围 = 译码器输入值对应的高位固定 + 片内低位从全 0 到全 1

> 📄 详见：[五大综合大题](/notes/semester/computer-organization/notes/%E4%BA%94%E5%A4%A7%E7%BB%BC%E5%90%88%E5%A4%A7%E9%A2%98/#section-1) | [存储器与 3-8 译码器](/notes/semester/computer-organization/notes/%E5%AD%98%E5%82%A8%E5%99%A8%E4%B8%8E-3-8-%E8%AF%91%E7%A0%81%E5%99%A8/)

## 题型三：进位链逻辑表达式

**出现**：22-23 Q2｜**分值**：11 分

<div id="section-9" class="note-anchor"></div>

### 解题模板

```
设 G_i = A_i·B_i（进位产生），P_i = A_i⊕B_i（进位传递）

串行：C_i = G_i + P_i·C_{i-1}

并行：将 C_1~C_4 全部展开为 G_i、P_i、C_0 的表达式
      C_4 = G_4 + P_4G_3 + P_4P_3G_2 + P_4P_3P_2G_1 + P_4P_3P_2P_1C_0
```

## 题型四：微指令控制字段设计

**出现**：22-23 Q4, 21-22 Q4｜**分值**：11 分｜🔥两套都考

<div id="section-11" class="note-anchor"></div>

### 解题模板

```
① 根据微指令表，找出互斥的微命令
② 互斥微命令→放同一字段（编码方式）
   → 字段位数 = ⌈log₂(微命令数 + 1)⌉（+1 为"不操作"）
③ 相容微命令→放不同字段
④ 总位数 = 各字段位数之和
⑤ 画出控制字段格式
```

## 题型五：集中式仲裁/中断判优逻辑图

**出现**：22-23 Q5, Q6｜**分值**：各 11 分

<div id="section-13" class="note-anchor"></div>

### 集中式仲裁逻辑图

三种方式中，**独立请求**的逻辑图最常考：

- 每个设备有独立的 BR（请求线）和 BG（授予线）
- 所有 BR 和 BG 连接到仲裁器
- 仲裁器根据优先级逻辑输出对应的 BG

<div id="section-14" class="note-anchor"></div>

### 中断判优（串行排队链）逻辑图

- 各设备的中断请求线连到公共 INTR
- 各设备通过菊花链串行连接（IEI→IEO）
- 离 CPU 最近的设备优先级最高

<div id="section-15" class="note-anchor"></div>

### 绘图要点
- 画出 CPU、设备 1~n 的框
- 标注各信号线（BR、BG / INTR、INTA）
- 串行链：标注菊花链连接方向

## 题型七：补码公式证明

**出现**：21-22 Q1｜**分值**：11 分

<div id="section-19" class="note-anchor"></div>

### 原题

> 设 $[x]_{补} = x_0.x_1x_2...x_n$，求证：$x = -x_0 + \sum_{i=1}^{n} x_i 2^{-i}$

<div id="section-20" class="note-anchor"></div>

### 证明思路

对于二进制小数，补码定义：
- 当 $x_0 = 0$（正数）：$[x]_{补} = x$，且 $-0 + \sum x_i 2^{-i} = \sum x_i 2^{-i} = x$ ✓
- 当 $x_0 = 1$（负数）：$[x]_{补} = 2 + x$（模 2），故 $x = [x]_{补} - 2 = -1 + \sum x_i 2^{-i} = -x_0 + \sum x_i 2^{-i}$ ✓

<div id="section-21" class="note-anchor"></div>

### 记忆关键
- 补码的符号位有**负权**：$x_0$ 的权重是 $-1$（小数）或 $-2^{n-1}$（整数）
- 纯小数的模 = 2
- 整数的模 = $2^n$

> 📄 关联：[运算方法](/notes/semester/computer-organization/notes/%E8%BF%90%E7%AE%97%E6%96%B9%E6%B3%95/)（原码/反码/补码转换）

## 题型八：总线带宽计算

**出现**：21-22 Q5｜**分值**：11 分

<div id="section-23" class="note-anchor"></div>

### 解题模板

```
已知：总线时钟频率 f，总线周期= n 个时钟，数据线宽度 W

① T_clk = 1/f
② T_cycle = n × T_clk
③ 总线带宽 = W / T_cycle（理论最大）
④ 实际传输率 = 总数据量 / 总时间
```

<div id="section-24" class="note-anchor"></div>

### 变体
- 含访问延迟时：判断延迟是否小于时钟周期（通常包含在寻址阶段内，不额外加）
- 含多次传输时：总数 = 数据数 × (位宽/总线位宽)

> 📄 详见：[五大综合大题](/notes/semester/computer-organization/notes/%E4%BA%94%E5%A4%A7%E7%BB%BC%E5%90%88%E5%A4%A7%E9%A2%98/#section-5) | [第四次考试真题](/notes/semester/computer-organization/notes/%E7%AC%AC%E5%9B%9B%E6%AC%A1%E8%80%83%E8%AF%95%E7%9C%9F%E9%A2%98/#section-8)

## 题型九：DMA 多路时空图

**出现**：21-22 Q6｜**分值**：11 分

<div id="section-26" class="note-anchor"></div>

### 解题要点

- 多设备同时发 DMA 请求 → 多路 DMA 控制器分时响应
- 时空图 = 时间轴 + 多个设备通道
- 画出每个设备的 DMA 传输时间段，标注重叠/交替

<div id="section-27" class="note-anchor"></div>

### 画图步骤

```
① 画时间轴（以 μs 为单位）
② 每个设备一行，标注其 DMA 请求间隔
③ 标注 DMA 控制器每次传输耗时
④ 注意设备间的冲突/等待
```

> 📄 关联：[IO 方式与中断](/notes/semester/computer-organization/notes/io-%E6%96%B9%E5%BC%8F%E4%B8%8E%E4%B8%AD%E6%96%AD/)（DMA 全流程）
