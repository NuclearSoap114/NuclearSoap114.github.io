## 二、三种机器数对比

| | 原码 | 反码 | 补码 |
|------|:----:|:----:|:----:|
| **正数** | 符号位0 + 绝对值 | 同原码 | 同原码 |
| **负数** | 符号位1 + 绝对值 | 符号位1 + 数值位按位取反 | 反码 + 1 |
| **+0** | 0000...0 | 0000...0 | 0000...0 |
| **-0** | 1000...0 | 1111...1 | **无**（0000...0唯一） |
| **表示范围(8位)** | $-(2^7-1) \sim +(2^7-1)$ | 同原码 | $-2^7 \sim +(2^7-1)$ |
| **用途** | 乘除法 | 中间过渡 | **加减法运算** |

> **核心公式**
> - **补码 → 原码**：符号位不变，数值位取反+1（负数的补码再求一次补得原码）
> - **补码加法**：$[X+Y]_{补} = [X]_{补} + [Y]_{补}$（连同符号位一起加，进位丢弃）
> - **补码减法**：$[X-Y]_{补} = [X]_{补} + [-Y]_{补}$

<div id="section-3" class="note-anchor"></div>

### 转换示例（8位）

| 十进制 | 原码 | 反码 | 补码 |
|:------:|------|------|------|
| +5 | 0 0000101 | 0 0000101 | 0 0000101 |
| -5 | 1 0000101 | 1 1111010 | **1 1111011** |
| +0 | 0 0000000 | 0 0000000 | 0 0000000 |
| -128 | — | — | **1 0000000**（补码唯一能表示-128） |

> **负数的"求补"口诀**：从最低位开始，第一个1及其后的0保持不变，前面的所有有效位取反。

## 三、补码加减运算

<div id="section-5" class="note-anchor"></div>

### 步骤

```
1. 将两个操作数都用补码表示
2. 连同符号位一起计算
3. [X]补 + [Y]补 → 结果是 [X+Y]补
4. 符号位产生的进位自然丢弃
5. 若溢出则报错
```

<div id="section-6" class="note-anchor"></div>

### 溢出判断

- **单符号位法**：两个正数相加得负数，或两个负数相加得正数 → **溢出**
- **双符号位法（变形补码）**：两个符号位相异（01或10）→ **溢出**
  - 符号位 00 = 正数，11 = 负数
  - 01 = **正溢出**（结果太大），10 = **负溢出**（结果太小）

## 四、浮点数表示（重难点补充 🌟）

<div id="section-8" class="note-anchor"></div>

### IEEE 754 标准

| 精度 | 总位数 | 符号S | 阶码E | 尾数M | 偏置常数 |
|------|:------:|:-----:|:-----:|:-----:|:--------:|
| **单精度** | 32 | 1位 | 8位 | 23位 | 127 |
| **双精度** | 64 | 1位 | 11位 | 52位 | 1023 |

<div id="section-9" class="note-anchor"></div>

### 浮点数真值公式


$$
X = (-1)^S \times 1.M \times 2^{E - \text{bias}}
$$


> 注意：尾数 M 有**隐含的整数1**（1.M），这是"规格化"的核心。

<div id="section-10" class="note-anchor"></div>

### 典型例题

> **题目**：将十进制数 -12.625 表示为 IEEE 754 单精度浮点数（32位十六进制）。

**逐步解答**：

```
Step 1: 确定符号 S
  -12.625 < 0 → S = 1

Step 2: 转换为二进制
  12 = 1100B
  0.625 = 0.101B  (0.625×2=1.25→1, 0.25×2=0.5→0, 0.5×2=1.0→1)
  → 12.625 = 1100.101B

Step 3: 规格化（小数点移到第一个1之后）
  1100.101B = 1.100101 × 2³
  → M（尾数部分） = 100101 00000000000000000（23位）
  → 真指数 e = 3

Step 4: 阶码 E = e + bias = 3 + 127 = 130 = 10000010B

Step 5: 拼接
  S(1) | E(8位)     | M(23位)
   1   | 10000010   | 10010100000000000000000
   
  = 1 10000010 10010100000000000000000
  = 1100 0001 0100 1010 0000 0000 0000 0000B
  = C14A0000H
```

> **最终答案**：`C14A0000H`

<div id="section-11" class="note-anchor"></div>

### 同类浮点练习题

> **题目**：将十进制数 0.375 表示为 IEEE 754 单精度浮点数。

**解析**：
- S = 0（正数）
- 0.375 = 0.011B = $1.1 \times 2^{-2}$ → 尾数 M = 100...0，真指数 e = -2
- E = -2 + 127 = 125 = 01111101B
- 结果：`0 01111101 10000000000000000000000` = `3EC00000H`

## 五、同类练习题（机器数）

> **题目**：已知 $X = -37$，$Y = 26$，用8位补码计算 $X + Y$，并判断是否溢出。

**解析**：

**Step 1**：求补码
- $X = -37$：37 = 00100101，取反+1 → $[X]_{补} = 11011011$
- $Y = 26$：$[Y]_{补} = 00011010$

**Step 2**：补码加法

```
  11011011  (-37)
+ 00011010  (+26)
───────────
  11110101
  ↑  丢弃进位
```

**Step 3**：结果分析
- $[X+Y]_{补} = 11110101$，符号位为1 → 负数
- 求原码：取反+1 = 00001011 = 11
- $X+Y = -11$ ✓（两个异号数相加不可能溢出）

---

> **题目**：已知 $X = -90$，$Y = -70$，用8位补码计算 $X + Y$，并判断是否溢出。

**解析**：

- $[-90]_{补} = 10100110$（90=01011010，取反+1=10100110）
- $[-70]_{补} = 10111010$（70=01000110，取反+1=10111010）

```
  10100110  (-90)
+ 10111010  (-70)
───────────
 101100000
   ↑ 丢弃

结果 = 01100000 = +96
```

- 两个负数相加得正数 → **溢出**！
- 原因：$-90 + (-70) = -160$，8位补码表示范围是 $-128 \sim +127$，超出范围。

> **得分要点**
> - 熟记：**补码的定义** $[X]_{补} = 2^n + X$（模 $2^n$）
> - 负数的补码 = 反码 + 1
> - 补码运算**丢弃最高位进位**
> - 溢出判断：同号相加得异号则溢出
