## 一、考点概述

考试要求画出三种总线通信方式的**时序波形图**，并说明各自特点。重点是理解时钟信号、控制信号、数据信号之间的关系。

---

<div id="section-2" class="note-anchor"></div>

## 二、三种总线通信方式对比

| 特性 | 同步通信 | 异步通信 | 半同步通信 |
|------|:--------:|:--------:|:----------:|
| **时钟** | 统一时钟 | 无公共时钟 | 有统一时钟 |
| **握手信号** | 不需要 | **需要**（请求+应答） | 需要等待信号 |
| **速度** | 由最慢设备决定 | 自适应设备速度 | 兼顾快慢设备 |
| **可靠性** | 低（可能丢数据） | 高 | 较高 |
| **复杂度** | 简单 | 复杂 | 中等 |
| **适用场景** | 近距离、设备速度相近 | 速度差异大、远距离 | 折中方案 |

## 三、波形图绘制要点

<div id="section-4" class="note-anchor"></div>

### 1. 同步通信波形

```
时钟 CLK:  ┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌
           ↑ ↑ ↑ ↑ ↑ ↑ ↑ ↑
           时钟上升沿（或下降沿）为定时基准

地址总线:  ────┬──────┬──────
              地址1   地址2

数据总线:  ────────┬──────┬──
                  数据1   数据2

控制信号:  ────┐   ┌──┐   ┌──
          (读/写) (读/写)
```

> **特点**：
> - 所有操作在**时钟沿**触发
> - 地址和数据在固定时钟周期内传输
> - 控制信号配合时钟沿变化

<div id="section-5" class="note-anchor"></div>

### 2. 异步通信波形（全互锁/握手）

```
请求信号 REQ:
          ──────┐         ┌──────
                 ├─────────┤
                 请求开始   请求结束

应答信号 ACK:
          ──────┐         ┌──────
                 ├─────────┤
                 应答开始   应答结束

数据:     ────────┬──────────────
                 有效数据
```

> **全互锁三握手过程**：
> 1. 主设备发出 **REQ**（请求）
> 2. 从设备收到后发出 **ACK**（应答）→ 主设备开始传数据
> 3. 主设备传完撤销 **REQ** → 从设备撤销 **ACK** → 一次传输完成

<div id="section-6" class="note-anchor"></div>

### 3. 半同步通信波形

```
时钟 CLK:  ┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌

地址:      ────┬──────────────
              地址

WAIT信号:  ──────┐     ┌──────
                 ├─────┤
                 设备慢，等待

数据:      ────────────┬──────
                       有效数据
```

> **特点**：
> - 有统一时钟（和同步一样）
> - 但增加了 **WAIT/READY** 信号
> - 慢设备拉低WAIT → CPU插入等待周期 → 设备就绪后继续

## 四、老师原题考点归纳

根据大纲"波形图（同步、异步、半同步）"：

- 必须能**画出三种波形图**
- 标注**关键信号**：时钟、地址、数据、REQ/ACK（异步）、WAIT（半同步）
- 必须能**对比三种方式的优缺点**

> **得分要点**
> - 同步：必须画**时钟线**，地址数据对齐时钟沿
> - 异步：必须画**REQ和ACK两条握手线**，体现互锁关系
> - 半同步：时钟 + **WAIT信号**，体现插入等待周期

## 同类练习题

> **题目**：画出异步通信方式下一次数据传送的波形图，并说明为什么异步通信比同步通信更可靠。

**解析**：

```
主设备 REQ:  ───┐          ┌───
                └──────────┘
从设备 ACK:  ──────┐          ┌──
                   └──────────┘
数据传输:    ─────────┬─────────
                    有效数据
```

**为什么更可靠**：
- 异步通信通过**完整的握手应答机制**，主设备确认从设备已收到数据后才撤销请求
- 同步通信依赖统一时钟，若从设备来不及在时钟沿前准备好数据，就会**读错**
- 异步通信对设备速度差异**自适应**，不会因为一方慢而丢失数据
