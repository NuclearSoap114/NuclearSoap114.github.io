## 一、四种IO方式对比（必考）

| 对比项 | 程序查询 | 程序中断 | DMA | 通道 |
|--------|:--------:|:--------:|:---:|:----:|
| **数据传送单位** | 字/字节 | 字/字节 | **块** | 块/多块 |
| **CPU参与程度** | **全程参与** | 传送时参与 | 仅开始和结束 | 几乎不参与 |
| **是否中断CPU** | 否 | **是** | 仅结束时 | 仅结束时 |
| **速度** | 最慢 | 较慢 | **快** | 最快 |
| **硬件复杂度** | 最低 | 较低 | 较高 | 最高 |
| **适用场景** | 低速简单设备 | 中低速交互 | **高速批量**（磁盘） | 大型机多设备 |

<div id="section-2" class="note-anchor"></div>

### 记忆口诀

```
程序查询：CPU一直问"好了没？" → 效率极低
程序中断：设备好了"叫"CPU → CPU暂停当前，服务完再回来
DMA：     CPU说"去传这个"，DMA自己传完再"告诉你"
通道：    通道自己有程序，全权负责IO
```

## 二、DMA（直接存储器访问）🌟

<div id="section-4" class="note-anchor"></div>

### DMA传送时间计算（必考）

**核心公式**：

- **DMA周期窃取**：当DMA和CPU同时访存时，DMA**优先**
- 如果DMA周期和CPU周期冲突 → CPU等待一个存取周期

**DMA传送总时间**：


$$
T = T_{\text{初始化}} + N \times T_{\text{传送一个数据}} + T_{\text{结束处理}}
$$


其中 $N$ = 传送数据个数（块大小）

> **典型考题**：磁盘以DMA方式传送数据，每秒传送 $X$ 字节，存储器周期为 $Y$ ns，求DMA占用总线的时间比例。

**解法**：
1. 每秒 DMA 传送次数 = 数据量 ÷ 每次传送块大小
2. 每次 DMA 占用总线时间 = 1个存储周期（周期窃取）
3. DMA 占用总时间 = 传送次数 × 存储周期
4. 占用比例 = DMA占用时间 ÷ 1秒

<div id="section-5" class="note-anchor"></div>

### DMA工作流程

```
CPU 初始化 DMA 控制器
      │
      ▼
   ┌─────────────────────┐
   │ DMA 控制器接管总线   │ ← CPU 释放总线控制权
   │ 源地址 → 地址寄存器  │
   │ 字节数 → 计数寄存器  │
   │ 启动 DMA 传送        │
   └────────┬────────────┘
            │
            ▼
   ┌─────────────────────┐
   │ 每个存储周期传送一字节│
   │ 计数 -1，地址 +1     │ ← 周期窃取（CPU等待）
   │ 重复直到计数 = 0    │
   └────────┬────────────┘
            │
            ▼
   ┌─────────────────────┐
   │ 计数 = 0 → 发中断   │
   │ CPU 处理结束工作     │ ← 仅此时CPU才介入
   └─────────────────────┘
```

## 三、中断处理流程图（必考画图）🌟

<div id="section-7" class="note-anchor"></div>

### 完整中断处理流程

```
程序执行中
    │
    ▼
中断请求 INTR 到达
    │
    ▼
CPU 执行完当前指令  ← 指令执行中不响应中断
    │
    ▼
┌─── 关中断 ───┐          ← 保护现场期间禁止新中断
│              │
│   保护断点   │          ← PC → 堆栈
│   保护现场   │          ← 各寄存器 → 堆栈
│              │
└── 开中断 ───┘          ← 可响应更高级中断
    │
    ▼
┌─────────────┐
│  中断服务程序 │          ← 真正处理中断
│  (执行具体任务)│
└──────┬──────┘
       │
       ▼
┌─── 关中断 ───┐
│              │
│   恢复现场   │          ← 堆栈 → 各寄存器
│   恢复断点   │          ← 堆栈 → PC
│              │
└── 开中断 ───┘
    │
    ▼
返回原程序继续执行
```

<div id="section-8" class="note-anchor"></div>

### 流程记忆口诀

```
来了中断 → 执行完当前指令（不打断指令）
→ 关中断 → 保存现场 → 开中断（允许嵌套）
→ 执行中断服务
→ 关中断 → 恢复现场 → 开中断 → 返回
```

> **关键考点**
> 1. **中断响应时机**：CPU 执行完**当前指令**后才检查中断请求（不在指令执行中响应）
> 2. **保存/恢复现场**期间必须**关中断**，防止嵌套破坏现场
> 3. **中断向量**：指向中断服务程序入口地址
> 4. **断点 = 发生中断时的 PC 值**，存在堆栈中

## 四、同类练习题

<div id="section-10" class="note-anchor"></div>

### 练习1：DMA计算

> **题目**：某磁盘以DMA方式传送数据，传送速率为 2MB/s。CPU主频 100MHz，每个存储周期包含4个时钟周期。每次DMA传送一个字节。求DMA占用总线时间的百分比。

**解析**：
- 每秒传送 2MB = $2 \times 10^6$ 字节
- 每次DMA传1字节 → 每秒 $2 \times 10^6$ 次 DMA请求
- 时钟周期 = 1/100MHz = 10ns
- 存储周期 = 4 × 10ns = 40ns
- DMA 占用总时间 = $2 \times 10^6 \times 40\text{ns} = 80\text{ms}$
- 占用比例 = 80ms / 1s = **8%**

<div id="section-11" class="note-anchor"></div>

### 练习2：中断流程

> **题目**：简述中断处理过程中为什么要"关中断→保存现场→开中断"，而不能一直关着中断。

**解析**：
- **关中断**：保护现场（各寄存器值入栈）时，若被新中断打断，现场数据会混乱
- **开中断**：保护完毕后开中断，允许**更高级的中断嵌套**，提高实时性
- 若一直关中断：高优先级中断无法及时响应，影响系统实时性

<div id="section-12" class="note-anchor"></div>

### 练习3：四种IO对比

> **题目**：分别用程序查询方式和DMA方式从磁盘读取1KB数据到内存。假设每次传送1字节，CPU检测/启动耗时2μs，存储周期0.5μs。分别计算两种方式的CPU耗时。

**解析**：
- **程序查询**：CPU每次读1字节需检测+启动（2μs），共1024次 → $1024 \times 2\mu\text{s} = 2048\mu\text{s}$ ≈ 2ms
- **DMA**：CPU仅初始化DMA（约10μs）+ 结束处理中断（约10μs）≈ 20μs
- **效率差异**：DMA节省约 **100倍** CPU时间
