## 一、考点概述

这是计组**最核心的大题**——给一条指令格式，求各种寻址方式下的**有效地址（EA）**和**操作数**。大纲说"6-10个求EA"，意味着10种寻址方式都会考。

---

<div id="section-2" class="note-anchor"></div>

## 二、10种寻址方式速查表

| 编号 | 寻址方式 | EA 公式 | 访存次数 | 特点 |
|:----:|----------|---------|:--------:|------|
| 1 | **立即寻址** | 操作数在**指令中** | 0 | 最快，操作数=指令中的立即数 |
| 2 | **直接寻址** | EA = 指令中的地址码A | 1 | 最简单 |
| 3 | **间接寻址** | EA = (A) | ≥2 | A指向的单元内容才是EA |
| 4 | **寄存器直接** | EA = **寄存器号R** | 0 | 操作数在寄存器中 |
| 5 | **寄存器间接** | EA = (R) | 1 | 寄存器内容=操作数地址 |
| 6 | **变址寻址** | EA = (IX) + A | 1 | IX=变址寄存器, A=形式地址 |
| 7 | **基址寻址** | EA = (BR) + A | 1 | BR=基址寄存器 |
| 8 | **相对寻址** | EA = **(PC)** + A | 1 | PC=程序计数器（隐含） |
| 9 | **堆栈寻址** | EA = (SP) | 0~1 | SP=堆栈指针 |
| 10 | **隐含寻址** | 隐含在某寄存器 | 0 | 如累加器ACC |

<div id="section-3" class="note-anchor"></div>

### 记忆方法

```
立即：数在指令里 → 不访存
直接：指令给地址 → 访存1次取数
间接：指令给"存地址的地址" → 访存≥2次（先取地址，再取数）
寄存器：数在寄存器 → 不访存
寄存器间接：寄存器里是地址 → 访存1次

变址：(IX)+A → 适合数组访问（IX变化，A不变）
基址：(BR)+A → 适合程序重定位（BR是基地址）
相对：(PC)+A → 适合短跳转（偏移量A可正可负）
```

> **基址 vs 变址**
> - **基址寻址**：基址寄存器 BR 不变，形式地址 A 变 → 面向**系统**（程序整体重定位）
> - **变址寻址**：变址寄存器 IX 变化，形式地址 A 不变 → 面向**用户**（数组遍历）

## 三、典型例题——10种EA求值

> **例题**：某指令字长为16位，其中操作码6位，寻址方式X占2位，形式地址A占8位。设 (PC)=2000H, (IX)=1000H, (BR)=3000H, (R₁)=4000H。内存部分单元内容如下。求10种寻址方式下的EA和操作数。

<div id="section-5" class="note-anchor"></div>

### 解题模板

| 寻址方式 | EA 计算过程 | EA值 | 操作数 |
|----------|------------|------|:------:|
| 立即寻址 | 无需EA，操作数=A | — | A的值 |
| 直接寻址 | EA = A | A | (A) |
| 间接寻址 | EA = (A) | 内存A的内容 | ((A)) |
| 寄存器直接 | EA = R₁ | — | (R₁)=4000H |
| 寄存器间接 | EA = (R₁) | 4000H | (4000H) |
| 变址寻址 | EA = (IX) + A | 1000H + A | (EA) |
| 基址寻址 | EA = (BR) + A | 3000H + A | (EA) |
| 相对寻址 | EA = (PC) + A | 2000H + A | (EA) |
| 堆栈寻址 | EA = (SP) | SP值 | 栈顶内容 |
| 隐含寻址 | 约定为ACC | — | (ACC) |

<div id="section-6" class="note-anchor"></div>

### 具体数值代入（假设A = 20H）

```
给定条件:
  (PC)=2000H, (IX)=1000H, (BR)=3000H
  A=20H（指令中的形式地址）
  内存 (4000H)=5050H
  内存 (1020H)=6789H

各寻址方式:

1. 立即寻址      → 操作数 = 20H
2. 直接寻址      → EA = 0020H, 操作数 = (0020H)
3. 间接寻址      → EA = (0020H)（内存20H单元的内容）
4. 寄存器直接    → 操作数 = (R₁) = 4000H
5. 寄存器间接   → EA = (R₁) = 4000H, 操作数 = (4000H) = 5050H
6. 变址寻址     → EA = (IX)+A = 1000H+20H = 1020H, 操作数 = (1020H) = 6789H
7. 基址寻址     → EA = (BR)+A = 3000H+20H = 3020H, 操作数 = (3020H)
8. 相对寻址     → EA = (PC)+A = 2000H+20H = 2020H, 操作数 = (2020H)
9. 堆栈寻址     → EA = (SP), 操作数 = 栈顶((SP))
10. 隐含寻址     → 操作数 = (ACC)
```

## 四、同类练习题

> **题目**：某机字长16位，指令格式：OP(4位) + MOD(3位) + A(9位)。
> 已知 (PC)=1500H, (IX)=0200H, (R₂)=0800H, A=0050H。
> 内存 (0850H)=1234H, (1550H)=5678H。
> 求变址寻址和相对寻址的 EA 和操作数。

**解析**：

**变址寻址**：
- EA = (IX) + A = 0200H + 0050H = **0250H**
- 操作数 = (0250H)

**相对寻址**：
- EA = (PC) + A = 1500H + 0050H = **1550H**
- 操作数 = (1550H) = **5678H**

> **验证**：EA = 1550H，对应内存内容5678H ✓

---

> **10种EA题型的得分技巧**
> 1. **先列出所有给定条件**（各寄存器值、内存内容）
> 2. **逐一计算EA**，用表格对比（考试时表格很加分）
> 3. **注意**：相对寻址的A通常是**补码**表示的偏移量（可正可负）
> 4. **区别**立即寻址（不访存）和直接寻址（访存1次）
> 5. **访存次数**也是常见考点
