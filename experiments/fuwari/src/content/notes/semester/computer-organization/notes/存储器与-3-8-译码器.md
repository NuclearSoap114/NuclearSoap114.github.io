## 一、考点概述

存储器章节的必考点是**38译码器**的地址译码分析。考试形式：给电路图/芯片规格，分析每个芯片的地址范围。

<div id="section-2" class="note-anchor"></div>

## 二、38译码器（3-8 Decoder）基础

<div id="section-3" class="note-anchor"></div>

### 原理

- **3输入 → 8输出**（$2^3 = 8$）
- 输入的3根地址线组合 → 8种状态 → 选通对应输出端（低电平有效）
- 每个输出端连接一片存储器芯片的**片选端（CS/CE）**

<div id="section-4" class="note-anchor"></div>

### 真值表

| 输入 C B A | 有效输出端（低电平） | 选通芯片 |
|:---------:|:-------------------:|:--------:|
| 0 0 0 | $\overline{Y_0}$ | 芯片0 |
| 0 0 1 | $\overline{Y_1}$ | 芯片1 |
| 0 1 0 | $\overline{Y_2}$ | 芯片2 |
| 0 1 1 | $\overline{Y_3}$ | 芯片3 |
| 1 0 0 | $\overline{Y_4}$ | 芯片4 |
| 1 0 1 | $\overline{Y_5}$ | 芯片5 |
| 1 1 0 | $\overline{Y_6}$ | 芯片6 |
| 1 1 1 | $\overline{Y_7}$ | 芯片7 |

<div id="section-5" class="note-anchor"></div>

### 关键概念

- **高位地址 → 译码器输入**（CBA），决定选中哪片芯片（**片选**）
- **低位地址 → 芯片内部地址线**，决定芯片内部哪个存储单元（**片内寻址**）
- 芯片的**片选信号**通常为**低电平有效**（$\overline{CS}$ 或 $\overline{CE}$）

## 三、典型考试题型

<div id="section-7" class="note-anchor"></div>

### 题型：给定连接图，求芯片地址范围

> **例题**：CPU 有 16 根地址线（$A_{15} \sim A_0$），$A_{13}A_{12}A_{11}$ 接38译码器输入端CBA。每片存储芯片容量为 2KB（11根片内地址线）。求各芯片的地址范围。

<div id="section-8" class="note-anchor"></div>

### 解题步骤

```
Step 1: 确定片内地址线数
  2KB = 2 × 1024 = 2048 = 2¹¹ → 片内地址需 11 根线
  → 低11位 A₁₀~A₀ 为片内地址

Step 2: 确定片选地址线
  A₁₃, A₁₂, A₁₁ → 38译码器 C, B, A
  → 这三位决定选中哪片芯片
  
Step 3: 其余高位地址
  A₁₅, A₁₄ → 可能接使能端（控制译码器是否工作）或固定

Step 4: 逐片写出地址范围
```

<div id="section-9" class="note-anchor"></div>

### 具体计算（假设 $A_{15}A_{14}=00$ 使能译码器，$A_{10}\sim A_0$ 为片内地址）

对于 $\overline{Y_0}$（CBA = 000），即 $A_{13}A_{12}A_{11} = 000$：

```
A₁₅ A₁₄ A₁₃ A₁₂ A₁₁ │ A₁₀ ... A₀
 0   0   0   0   0  │  0 ... 0  → 最低地址 = 0000H
 0   0   0   0   0  │  1 ... 1  → 最高地址 = 07FFH

地址范围: 0000H ~ 07FFH（2KB）
```

对于 $\overline{Y_1}$（CBA = 001），即 $A_{13}A_{12}A_{11} = 001$：

```
A₁₅ A₁₄ A₁₃ A₁₂ A₁₁ │ A₁₀ ... A₀
 0   0   0   0   1  │  0 ... 0  → = 0800H
 0   0   0   0   1  │  1 ... 1  → = 0FFFH

地址范围: 0800H ~ 0FFFH
```

以此类推，每片跨度 = $2^{11} = 2048 = 800\text{H}$

| 芯片 | CBA | 地址范围(Hex) |
|:----:|:---:|---------------|
| Y0 | 000 | 0000H ~ 07FFH |
| Y1 | 001 | 0800H ~ 0FFFH |
| Y2 | 010 | 1000H ~ 17FFH |
| Y3 | 011 | 1800H ~ 1FFFH |
| Y4 | 100 | 2000H ~ 27FFH |
| Y5 | 101 | 2800H ~ 2FFFH |
| Y6 | 110 | 3000H ~ 37FFH |
| Y7 | 111 | 3800H ~ 3FFFH |

## 四、同类练习题

> **题目**：CPU 地址线 $A_{19}\sim A_0$（20根），$A_{14}A_{13}A_{12}$ 接38译码器 CBA，使能端接 $A_{15}$（高电平有效）。每片芯片 4KB。求 Y3 对应的芯片地址范围。

**解析**：

- 4KB = $2^{12}$，片内地址线 = 12 根 → $A_{11}\sim A_0$
- Y3 → CBA = 011，即 $A_{14}A_{13}A_{12} = 011$
- 使能 $A_{15}=1$，其余高位 $A_{19}\sim A_{16}$ 未接 → 可为任意，默认全0

```
A₁₉..A₁₆  A₁₅  A₁₄A₁₃A₁₂  │ A₁₁...A₀
 0000      1      0 1 1    │ 0...0  → 最低地址
 0000      1      0 1 1    │ 1...1  → 最高地址

= 00001 011 000000000000B = 05800H (最低)
= 00001 011 111111111111B = 05FFFH (最高)

Y3 地址范围: 05800H ~ 05FFFH
```

> **得分要点**
> - 先判断**片内地址线数**（由芯片容量决定）：$n = \log_2(\text{容量/字节})$
> - 片选地址线 = 连接译码器输入的地址线
> - 高位地址线若未接或接使能，按题目说明确定（通常是全0或使能值）
> - 地址范围跨度 = 芯片容量（用十六进制表示）
> - **十六进制换算必须熟练**
