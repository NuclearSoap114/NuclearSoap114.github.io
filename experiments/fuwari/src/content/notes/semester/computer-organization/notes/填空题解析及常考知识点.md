## 一、22-23 填空题真题解析

<div id="section-2" class="note-anchor"></div>

### Q1：Cache 相关

**原题**：Cache 是一种 A.____ 存储器，是为了解决 CPU 和主存之间 B.____ 不匹配而采用的一项重要硬件技术。现发展为多级 cache 体系，C.____ 分设体系。

**答案**：A. **高速缓冲**　B. **速度**　C. **指令和数据**

> **知识点**：Cache = 位于 CPU 和主存之间的高速小容量存储器（SRAM）。哈佛结构 = 指令 Cache + 数据 Cache 分离。解决 CPU 快、主存慢的速度不匹配问题。

<div id="section-3" class="note-anchor"></div>

### Q2：RISC 指令系统特点

**原题**：RISC 指令系统的最大特点是，A.____；B.____ 种类少。只有取数/存数指令访问存储器。

**答案**：A. **指令长度固定**（或"指令格式规整"）　B. **寻址方式**

> **知识点**：RISC（精简指令系统）= 指令等长 + 寻址方式少 + 只有 LOAD/STORE 访存 + 大量寄存器。

<div id="section-4" class="note-anchor"></div>

### Q3：并行处理技术

**原题**：并行处理技术已成为计算机技术发展的主流。概括起来，主要有三种形式 A.____ 并行，B.____ 并行，C.____ 并行。

**答案**：A. **时间**（流水线）　B. **空间**（多部件同时工作）　C. **时间+空间**

> **知识点**：时间并行 = 流水线（不同指令不同阶段同时进行）；空间并行 = 多处理器/多部件同时工作。

<div id="section-5" class="note-anchor"></div>

### Q4：总线仲裁

**原题**：为了解决多个 A.____ 同时竞争总线，B.____ 必须具有 C.____ 部件。

**答案**：A. **主设备**　B. **总线**　C. **仲裁**

> **知识点**：多个主设备同时申请总线→需要仲裁器决定谁获得总线控制权。

<div id="section-6" class="note-anchor"></div>

### Q5：磁盘

**原题**：软磁盘和硬磁盘的 A.____ 原理与 B.____ 方式基本相同，但在 C.____ 和性能上存在较大差别。

**答案**：A. **记录**　B. **读写**　C. **容量**

> **知识点**：软盘和硬盘都用磁记录方式读写数据，核心区别在容量和转速。

<div id="section-7" class="note-anchor"></div>

### Q6：DMA 控制器

**原题**：选择型 DMA 控制器在 A.____ 可连接多个设备，而在 B.____ 只允许连接一个设备，适于连接 C.____ 设备。

**答案**：A. **逻辑上**　B. **物理上**（或"某一时刻"）　C. **高速**

> **知识点**：选择型 DMA → 多个设备共享 DMA 控制器，但同一时刻只能为一个设备服务。多路型 DMA → 同时为多个设备服务。

<div id="section-8" class="note-anchor"></div>

### Q7：Cache 映射方式

**原题**：主存与 cache 的地址映射有 A.____、B.____、C.____ 三种方式。其中组相连方式适度地兼顾了前二者的优点。

**答案**：A. **直接映射**　B. **全相联映射**　C. **组相联映射**

> **知识点**：三种映射（直接/全相联/组相联）。组相联 = 直接和全相联的折中，最常用。

<div id="section-9" class="note-anchor"></div>

### Q8：流水线 CPU

**原题**：流水 CPU 是以 A.____ 为原理构造的处理器，是一种非常 B.____ 的并行技术。目前的 C.____ 微处理器几乎无一例外的使用了流水技术。

**答案**：A. **时间并行**（或"指令重叠执行"）　B. **有效/高效**　C. **高性能/超标量**

> **知识点**：流水线 = 时间并行，现代 CPU 标配。

## 二、21-22 填空题真题解析

<div id="section-11" class="note-anchor"></div>

### Q1：超级计算机

**原题**：2000 年超级计算机浮点最高运算速度达到每秒 A.____ 次。我国的 B.____ 号计算机的运算速度达到 C.____ 次，使我国成为美国、日本后第三个拥有高速计算机的国家。

**答案**：A. **万亿**（或"太拉/10¹²"）　B. **神威/曙光**　C. **千万亿/百万亿**

> **知识点**：概论中的历史里程碑。2000 年达到 TFLOP 级别，中国超级计算机发展史。

<div id="section-12" class="note-anchor"></div>

### Q2：定点数组成

**原题**：一个定点数由 A.____ 和 B.____ 两部分组成。根据小数点位置不同，定点数有 C.____ 和纯整数之分。

**答案**：A. **符号位**　B. **数值位**　C. **纯小数**

> **知识点**：定点数 = 符号位 + 数值位。两种形式：纯小数（小数点在最前面）和纯整数（小数点在最后面）。

<div id="section-13" class="note-anchor"></div>

### Q3：存储器要求

**原题**：对存储器的要求是 A.____、B.____、C.____。为了解决这三方面的矛盾计算机采用多级存储体系结构。

**答案**：A. **容量大**　B. **速度高**　C. **价格低**

> **知识点**：存储器的三个要求——容量大、速度快、价格低。三者矛盾→多级存储（Cache-主存-辅存）。

<div id="section-14" class="note-anchor"></div>

### Q4：指令系统

**原题**：指令系统是表征一台计算机性能的重要因素，它的 A.____ 和 B.____ 不仅影响到机器的硬件结构，而且也影响到 C.____。

**答案**：A. **格式**　B. **寻址方式**（或"功能"）　C. **软件/系统软件**

> **知识点**：指令系统 = 软硬件交界面，影响硬件实现和软件编译。

<div id="section-15" class="note-anchor"></div>

### Q5：CPU 芯片

**原题**：当今的 CPU 芯片除了包括定点运算器和控制器外，还包括 A.____，B.____ 运算器和 C.____ 管理等部件。

**答案**：A. **Cache**　B. **浮点**　C. **存储**

> **知识点**：现代 CPU 芯片 = 定点运算器 + 控制器 + Cache + 浮点运算器 + MMU（存储管理）。

<div id="section-16" class="note-anchor"></div>

### Q6：总线

**原题**：总线是构成计算机系统的 A.____，是多个 B.____ 部件间进行数据传送的 C.____ 通道。

**答案**：A. **骨架/互联结构**　B. **系统**　C. **公共**

> **知识点**：总线 = 系统中各部件共享的公共传输通道。

<div id="section-17" class="note-anchor"></div>

### Q7：外设控制

**原题**：每一种外设都是在它自己的 A.____ 控制下进行工作，而 A 则通过 B.____ 和 C.____ 与 CPU 相连。

**答案**：A. **控制器**（或"接口"）　B. **接口**　C. **总线**

> **知识点**：外设→设备控制器→IO 接口→总线→CPU。

<div id="section-18" class="note-anchor"></div>

### Q8：CPU 外设管理方式

**原题**：在计算机系统中，CPU 对外围设备的管理除程序查询方式、程序中断方式外，还有 A.____ 方式，B.____ 方式，和 C.____ 方式。

**答案**：A. **DMA**　B. **通道**　C. **I/O 处理机**

> **知识点**：四种 IO 方式——程序查询、中断、DMA、通道（或 IO 处理机）。

## 四、填空题答题技巧

<div id="section-23" class="note-anchor"></div>

### 1. 看空格位置猜词性
- 名词类（硬件部件）：Cache、总线、DMA、通道
- 形容词类（特性）：高速、并行、独立
- 动词类（操作）：映射、刷新、仲裁

<div id="section-24" class="note-anchor"></div>

### 2. 注意"三个"模式
- 填空题特别喜欢考"三个"的问题：
  - 三种总线（DB/AB/CB）
  - 三种仲裁方式
  - 三种 Cache 映射
  - 三种并行技术
  - 四种 IO 方式（有时考"除XX和XX外，还有"→剩下的）

<div id="section-25" class="note-anchor"></div>

### 3. 前后文提示
- "为了解决A和B之间____不匹配"→ 一定是"速度"
- "____和____分设体系"→ 指令Cache和数据Cache
- "除程序查询、程序中断外"→ 剩下 DMA + 通道

<div id="section-26" class="note-anchor"></div>

### 4. 高频词汇必须会写
- **仲裁**（不是"仲载"）
- **映射**（不是"映像"）
- **流水线/pipeline**
- **猝发传送/猝发**
- **全相联/组相联**
