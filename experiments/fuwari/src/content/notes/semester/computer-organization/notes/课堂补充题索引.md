## 速查：每道题的核心公式/结论

| 题号 | 核心结论 |
|:---:|------|
| 1 | 四体交叉，存取时间=存取周期/4；连续读取：首个多花 3 个 τ，其余流水 |
| 2 | 定时查询间隔 ≤ 缓冲区填满时间 / 2；中断可行性看中断开销是否 > 数据到达间隔 |
| 3 | CPU 占比 = (每秒传输次数 × 每次时钟开销) / CPU 主频 |
| 4 | 异步串行 = 1起始 + 7数据 + 1校验 + 1停止 = 10位/字符 |
| 5 | int(32777) → short → 截断低16位，按补码解读 |
| 6 | OP 位数 = ⌈log₂(指令数)⌉；指令字长 = OP + N × 地址码位数 |
| 7 | 扩展编码：先分配短格式，剩余编码空间留给长格式 |
| 8 | 寄存器间接自增：先取操作数，再 Rn+1；机器码 = OP + MOD源 + Rs + MOD目的 + Rd |
