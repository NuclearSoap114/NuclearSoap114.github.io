## 一、第 1 章·计算机系统概论（每套 ~1 题）

<div id="section-2" class="note-anchor"></div>

### 已考真题

**Q1-1**（22-23）：对计算机的产生有重要影响的是：
- A. 牛顿、维纳、图灵
- B. 莱布尼兹、布尔、图灵 ✓
- C. 巴贝奇、维纳、麦克斯韦
- D. 莱布尼兹、布尔、克雷

> **解析**：莱布尼兹（二进制）、布尔（逻辑代数）、图灵（图灵机理论）。选 **B**。

**Q1-2**（21-22）：现代计算机内部一般采用二进制形式，我国历史上的____即反映了二值逻辑的思想，最早记载在____上，距今约有____千年。
- A. 八卦图、论衡、二
- B. 算筹、周髀算经、二
- C. 算筹、九章算术、一
- D. 八卦图、周易、三 ✓

> **解析**：八卦图（阴阳二值）、周易、约三千年。选 **D**。

<div id="section-3" class="note-anchor"></div>

### 常考套路

| 考点 | 频率 | 必背答案 |
|------|:---:|------|
| 计算机历史人物 | ⚠️ | 莱布尼兹(二进制)、布尔(逻辑代数)、冯·诺依曼(存储程序)、图灵(理论模型) |
| 二进制思想起源 | ⚠️ | 八卦图、周易 |
| 主机 = CPU + 主存 | 🔥 | CPU = ALU + CU |
| 完整系统 = 硬件 + 软件 | ✅ | 分清系统软件 vs 应用软件 |
| 冯诺依曼核心思想 | 🔥 | 存储程序 + 顺序执行 |

## 二、第 3 章·系统总线（每套 1~2 题）

<div id="section-5" class="note-anchor"></div>

### 已考真题

**Q2-1**（22-23）：系统总线中控制线的功能是____。
- A. 提供主存、I/O 接口设备的控制信号响应信号 ✓
- B. 提供数据信息
- C. 提供时序信号
- D. 提供主存、I/O 接口设备的响应信号

> **解析**：控制总线 = 控制信号 + 响应信号。数据总线传数据，地址总线传地址。选 **A**。

**Q2-2**（22-23）：IEEE1394 的高速特性适合于新型高速硬盘和多媒体数据传送，它的数据传输率可以是____。
- A. 100兆位/秒
- B. 200兆位/秒
- C. 400兆位/秒 ✓
- D. 300兆位/秒

> **解析**：IEEE1394（FireWire）支持 100/200/400 Mbps，最高 400。选 **C**。

**Q2-3**（21-22）：描述 PCI 总线中基本概念不正确的句子是____。
- A. PCI 总线是一个与处理器无关的高速外围设备
- B. PCI 总线的基本传输机制是猝发传送
- C. PCI 设备一定是主设备 ✗
- D. 系统中只允许有一条 PCI 总线

> **解析**：PCI 设备可以是从设备（不是主设备）。选 **C**。

<div id="section-6" class="note-anchor"></div>

### 常考套路

| 考点 | 频率 | 必背答案 |
|------|:---:|------|
| 总线按信息分三类 | 🔥 | 数据总线(DB)、地址总线(AB)、控制总线(CB) |
| 集中式仲裁三种 | 🔥 | 链式查询、计数器定时查询、独立请求 |
| 独立请求最快、控制线最多 | 🔥 | 每设备需 BR+BG 两根线 |
| 链式查询对故障最敏感 | ✅ | 某设备断链→后面全失效 |
| PCI 总线特点 | ✅ | 与处理器时钟无关、猝发传送、即插即用 |
| 同步 vs 异步通信 | ✅ | 同步有公共时钟；异步有握手(全互锁最可靠) |
| 主设备 vs 从设备 | ✅ | 主设备 = 能主动发起总线请求 |

## 三、第 4 章·存储器（每套 1~3 题）

<div id="section-8" class="note-anchor"></div>

### 已考真题

**Q3-1**（22-23）：某计算机字长 32 位，其存储容量为 16MB，若按双字编址，它的寻址范围是____。
- A. 0~16MB
- B. 0~8M
- C. 0~8MB
- D. 0~16MB

> **解析**：双字 = 32位×2 = 64位 = 8B。16MB/8B = 2M 个地址。选 **B**？（需确认选项）

公式：**按字编址范围 = 总字节数 ÷ (字长/8)**。

双字编址：总字节 16MB，双字 = 8 字节 → 寻址范围 = 16MB/8B = 2M。

**Q3-2**（22-23）：双端口存储器在____情况下会发生读/写冲突。
- A. 左端口与右端口的地址码不同
- B. 左端口与右端口的地址码相同 ✓
- C. 左端口与右端口的数据码相同
- D. 左端口与右端口的数据码不同

> **解析**：两端口同时访问同一地址（一个读一个写，或两个写）→ 冲突。选 **B**。

**Q3-3**（21-22）：某计算机字长 16 位，它的存储容量是 64K，若按字编址，那么它的寻址范围是____。
- A. 0~64K ✓
- B. 0~32K
- C. 0~64KB
- D. 0~32K

> **解析**：字长 16 位 = 2B。64K 指的是 64K 字节？不是——这里"64K"是 64K 个字。按字编址，范围 = 64K 字。选 **A**。

> ⚠️ 注意审题：题目说"存储容量是 64K"要看清是 64KB 还是 64K 字。

<div id="section-9" class="note-anchor"></div>

### 常考套路

| 考点 | 频率 | 必背公式/答案 |
|------|:---:|------|
| 按字/双字编址的寻址范围 | 🔥🔥🔥 | 地址数 = 总字节数 ÷ (每个字的字节数) |
| 双端口存储器冲突条件 | ✅ | 同地址 + (一读一写 或 两写) → 冲突 |
| SRAM vs DRAM | 🔥 | SRAM(触发器,快,无需刷新) / DRAM(电容,慢,需刷新) / 都易失 |
| 主存容量由地址总线决定 | ✅ | 最大容量 = 2^(地址线条数) |
| Cache 目的 | 🔥 | 解决 CPU 和主存速度不匹配 |

## 四、第 5 章·输入输出系统（每套 1~3 题）

<div id="section-11" class="note-anchor"></div>

### 已考真题

**Q4-1**（22-23）：具有自同步能力的记录方式是____。
- A. NRZ0
- B. NRZ1
- C. PM ✓
- D. MFM

> **解析**：PM（调相制）和 MFM（改进调频制）有自同步能力，但 PM 的自同步能力最强（每个位单元中间都有跳变）。选 **C**。

**Q4-2**（21-22）：一张 3.5 寸软盘的存储容量为____MB，每个扇区存储的固定数据是____。
- A. 1.44MB, 512B ✓
- B. 1MB, 1024B
- C. 2MB, 256B
- D. 1.44MB, 512KB

> **解析**：3.5 寸软盘 = 1.44MB，每扇区 512 字节。选 **A**。

**Q4-3**（21-22）：发生中断请求的条件是____。
- A. 一条指令执行结束 ✓
- B. 一次 I/O 操作结束
- C. 机器内部发生故障
- D. 一次 DMA 操作结束

> **解析**：CPU 在**每条指令执行结束时**检查中断请求。选 **A**。

> ⚠️注意区别：中断**请求**随时可以发生，但 CPU 只在指令执行结束时**响应**。

<div id="section-12" class="note-anchor"></div>

### 常考套路

| 考点 | 频率 | 必背答案 |
|------|:---:|------|
| 四种 IO 方式对比 | 🔥🔥🔥 | 程序查询/中断/DMA/通道（传送单位、CPU参与度、速度） |
| 中断响应时机 | 🔥 | 执行完**当前指令**后 |
| 中断 vs DMA 适用场景 | 🔥 | 低速→中断，高速批量→DMA |
| DMA 周期窃取 | ✅ | 窃取的是**一个存取周期** |
| 统一编址 vs 独立编址 | ✅ | 统一=共用指令、独立=专用 IO 指令 |
| 异步串行通信帧格式 | ✅ | 1 起始位 + 数据位 + 校验位 + 停止位 |
| 磁盘/软盘容量 | ⚠️ | 3.5寸软盘=1.44MB, 扇区=512B |
| 自同步记录方式 | ⚠️ | PM 有自同步能力 |

## 五、第 6 章·计算机的运算方法（每套 1~3 题）

<div id="section-14" class="note-anchor"></div>

### 已考真题

**Q5-1**（22-23）：假定下列字符码中有奇偶校验位，但没有数据错误，采用偶校验的字符码是____。
- A. 11001001
- B. 10101010
- C. 10000001
- D. 11001001

> **解析**：偶校验 = 所有位（含校验位）中 1 的个数为偶数。数一下哪个符合。

**Q5-2**（22-23）：按其数据流的传递过程和控制节拍来看，阵列乘法器可认为是____。
- A. 全串行运算的乘法器
- B. 全并行运算的乘法器 ✓
- C. 串-并行运算的乘法器
- D. 并-串型运算的乘法器

> **解析**：阵列乘法器 = 全并行（所有部分积同时相加）。选 **B**。

**Q5-3**（21-22）：8 位补码的表示范围是____。
- A. -128~+127 ✓
- B. -127~+127
- C. -129~+128
- D. -128~+128

> **解析**：n 位补码范围 = $[-2^{n-1},\ 2^{n-1}-1]$。8 位 = [-128, 127]。选 **A**。

**Q5-4**（21-22）：下面浮点运算器的描述中正确的句子是____。
- A. 浮点运算器可用阶码部件和尾数部件实现 ✓
- B. 阶码部件可实现加、减、乘、除四种运算
- C. 阶码部件只进行阶码相加、相减和比较操作
- D. 尾数部件只进行乘法和减法运算

> **解析**：浮点运算器 = 阶码部件（比较、加减）+ 尾数部件（加减乘除）。C 不完全，阶码还能比较。选 **A**。

<div id="section-15" class="note-anchor"></div>

### 常考套路

| 考点 | 频率 | 必背答案 |
|------|:---:|------|
| 补码表示范围 | 🔥 | n 位 = $[-2^{n-1},\ 2^{n-1}-1]$ |
| 原码/反码/补码/移码的 0 表示 | ✅ | 补码和移码 0 唯一 |
| 奇偶校验 | ✅ | 奇校验→1的个数为奇；偶校验→偶数 |
| 溢出判断方法 | ✅ | 单符号位法 / 双符号位法（变形补码）/ 进位异或法 |
| 浮点数 = 阶码部件 + 尾数部件 | ✅ | 阶码→加减比较；尾数→加减乘除 |
| 阵列乘法器 = 全并行 | ⚠️ | 所有部分积同时计算 |
| 算术移位(补符号位) vs 逻辑移位(补0) | ✅ | 负数算术右移=补1 |

## 六、第 7 章·指令系统（每套 ~1 题）

<div id="section-17" class="note-anchor"></div>

### 已考真题

**Q6-1**（22-23）：程序控制类指令的功能是____。
- A. 进行算术运算和逻辑运算
- B. 进行主存与 CPU 之间的数据传送
- C. 进行 CPU 和 I/O 设备之间的数据传送
- D. 改变程序执行顺序 ✓

> **解析**：程序控制类 = JMP/CALL/RET/条件转移 → **改变执行顺序**。选 **D**。

**Q6-2**（21-22）：寄存器间接寻址方式中，操作数处在____。
- A. 通用寄存器
- B. 主存单元 ✓
- C. 程序计数器
- D. 堆栈

> **解析**：寄存器间接 → 寄存器里是地址，操作数在**该地址指向的主存单元**。选 **B**。

<div id="section-18" class="note-anchor"></div>

### 常考套路

| 考点 | 频率 | 必背答案 |
|------|:---:|------|
| 寻址方式速度排序 | 🔥 | 立即=寄存器(0次访存) > 直接(1次) > 间接(≥2次) |
| 程序控制类指令 | ✅ | 改变执行顺序（JMP/CALL/RET/条件转移） |
| 寄存器间接 = 操作数在主存中 | ✅ | 寄存器存的是地址 |
| CISC vs RISC | ✅ | CISC(不等长) / RISC(等长,只有LOAD/STORE访存) |
| 基址 vs 变址 | ✅ | 基址面向系统(重定位)，变址面向用户(数组) |

## 七、第 8 章·CPU 的结构和功能（每套 1~2 题）

<div id="section-20" class="note-anchor"></div>

### 已考真题

**Q7-1**（22-23）：由于 CPU 内部的操作速度较快，而 CPU 访问一次主存所花的时间较长，因此机器周期通常用____来规定。
- A. 主存中读取一个指令字的最短时间 ✓
- B. 主存中读取一个数据字的最长时间
- C. 主存中写入一个数据字的平均时间
- D. 主存中读取一个数据字的平均时间

> **解析**：机器周期 = CPU 从主存中读取一个指令字的最短时间（存取周期）。选 **A**。

**Q7-2**（21-22）：微程序控制器中，机器指令与微指令的关系是____。
- A. 每一条机器指令由一条微指令来执行
- B. 每一条机器指令由一段微指令编写的微程序来解释执行 ✓
- C. 每一条机器指令组成的程序可由一条微指令来执行
- D. 一条微指令由若干条机器指令组成

> **解析**：微程序控制器 = 机器指令 → 译码 → 一段微程序（若干微指令）。选 **B**。

<div id="section-21" class="note-anchor"></div>

### 常考套路

| 考点 | 频率 | 必背答案 |
|------|:---:|------|
| 机器周期 = 主存存取周期 | ✅ | 访存一次的最短时间 |
| 机器指令 vs 微指令 | 🔥 | 1 条机器指令 → 1 段微程序 → N 条微指令 |
| 微程序存放位置 | ✅ | ROM（控制存储器） |
| 取指周期四步 | 🔥 | PC→MAR→M(MAR)→MDR→IR, PC+1/+2 |
| 流水线时间公式 | ✅ | $T = (k+n-1) \times t$ |

## 选择题通用做题技巧

1. **排除法**：明显错误先划掉（如"PCI 设备一定是主设备"→ 错在"一定"）
2. **概念对立法**：互补/对立选项往往一个是正确答案（如 A 和 B 互相矛盾）
3. **数字记忆**：补码范围、软盘容量这些数字必须硬背
4. **最核心概念**：冯诺依曼、总线、Cache、中断、DMA → 一定会考
