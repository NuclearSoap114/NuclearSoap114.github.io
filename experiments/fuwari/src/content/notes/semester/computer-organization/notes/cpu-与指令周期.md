## 一、五大部件及其功能（必背）

| 部件 | 英文 | 核心功能 |
|------|------|----------|
| **运算器** | ALU (Arithmetic Logic Unit) | 算术运算（+−×÷）和逻辑运算（AND/OR/NOT） |
| **控制器** | CU (Control Unit) | 指挥各部件协调工作，发出控制信号 |
| **存储器** | Memory | 存储程序和数据（主存 + 辅存） |
| **输入设备** | Input | 将外部数据送入计算机（键盘、鼠标等） |
| **输出设备** | Output | 将计算结果送出（显示器、打印机等） |

> **冯·诺依曼结构核心**
> - **存储程序**：程序和数据都以二进制形式存放在存储器中
> - **顺序执行**：按地址顺序逐条取指令执行
> - 五大部件通过**总线**（数据总线、地址总线、控制总线）连接

## 二、指令周期数据流 🌟必考

<div id="section-3" class="note-anchor"></div>

### 指令周期三阶段

```
取指周期 → 执行周期 → 中断周期
  (必经过)   (必经过)   (仅中断时)
```

<div id="section-4" class="note-anchor"></div>

### 各阶段数据流（考试填表/填空重点）

<div id="section-5" class="note-anchor"></div>

#### 1. 取指周期（Fetch Cycle）

| 步骤 | 操作 | 数据流路径 |
|:----:|------|------------|
| ① | PC → MAR | 程序计数器内容送入地址寄存器 |
| ② | M(MAR) → MDR | 从存储器读指令到数据寄存器 |
| ③ | MDR → IR | 指令送入指令寄存器 |
| ④ | PC + 1 → PC | 程序计数器+1，指向下一条指令 |

> **最终**：指令在 **IR** 中，控制器对其**译码**，进入执行周期

<div id="section-6" class="note-anchor"></div>

#### 2. 执行周期（Execute Cycle）

- **根据指令类型不同，数据流不同**：
  - 访存指令（LOAD/STORE）：地址码 → MAR → 读/写存储器
  - 运算指令（ADD/SUB等）：操作数 → ALU → 结果 → 寄存器
  - 转移指令（JMP等）：目标地址 → PC

<div id="section-7" class="note-anchor"></div>

#### 3. 中断周期（Interrupt Cycle）

| 步骤 | 操作 | 数据流路径 |
|:----:|------|------------|
| ① | 关中断 | 禁止新的中断响应 |
| ② | SP-1 → SP, PC → MDR | 保存断点（PC值压栈） |
| ③ | MDR → M(SP) | 断点写入堆栈 |
| ④ | 中断向量 → PC | 转入中断服务程序入口 |

> **记忆方法**
> - **取指周期**：PC→MAR→MEM→MDR→IR，PC+1
> - **执行周期**：看指令类型（访存/运算/转移）
> - **中断周期**：关中断 → 保存PC → 转入中断程序

## 同类练习题

> **题目**：简述取指周期的四个微操作步骤，并画出数据流图。

**解析**（以数据流符号表示）：

```
① PC ──→ MAR        (送指令地址)
② M(MAR) ──→ MDR    (读指令)
③ MDR ──→ IR        (指令送IR)
④ (PC)+1 ──→ PC     (PC自增指向下一条)
```

> **考点**：这四步的顺序不能错（先送地址→再读→再送IR→最后PC+1），以及每一步涉及哪些寄存器。

---

> **题目**：中断周期中为什么要"关中断"？断点保存在哪里？

**解析**：
- **关中断**：防止在保存断点（PC值）的过程中又来一个中断，导致无法正确返回原程序
- **断点**（即当前PC值）保存在**堆栈**中（SP指向的位置），中断返回时从堆栈弹出恢复PC
