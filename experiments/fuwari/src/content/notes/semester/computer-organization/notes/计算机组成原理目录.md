## 考前必默写清单

<div id="section-9" class="note-anchor"></div>

### 取指周期微操作（4 步，按顺序）

```
① PC → MAR
② M(MAR) → MDR
③ MDR → IR
④ PC + 2 → PC
```

<div id="section-10" class="note-anchor"></div>

### DMA 流程图（4 阶段）

```
初始化(CPU配置DMA) → 请求与响应(DREQ→HRQ→HLDA) → 直接传输(DMA控制总线) → 结束恢复(中断通知CPU)
```

<div id="section-11" class="note-anchor"></div>

### 总线周期四阶段

```
申请分配 → 寻址 → 传数 → 结束
```

<div id="section-12" class="note-anchor"></div>

### 必须记住的公式

| 公式 | 用途 |
|------|------|
| 按字编址范围 = 总字节数 ÷ (字长/8) | 存储器寻址 |
| T_clk = 1/f，T_cycle = n × T_clk | 总线周期 |
| 带宽 = 总线宽度 / 总线周期 | 总线带宽 |
| CPU 占比 = (每秒操作次数 × 每次时钟开销) / 主频 | IO 时间占比 |
| n 位补码范围 = [−2ⁿ⁻¹, 2ⁿ⁻¹−1] | 补码范围 |
| 流水线 T = (k + n − 1) × t | 流水线时间 |
| EA(基址) = (BR) + A | 基址寻址 |
| EA(变址) = (IX) + A | 变址寻址 |
| EA(相对) = (PC) + A | 相对寻址 |
| [−X]补 = [X]补连符号位取反+1 | 补码变号 |
| 芯片引脚 = log₂(字数) + 数据线 + 2(CS+WE) | 存储器引脚 |

<div id="section-13" class="note-anchor"></div>

### 必须记住的对比表

**四种 IO 方式**：

| | 程序查询 | 中断 | DMA | 通道 |
|------|:---:|:---:|:---:|:---:|
| 传送单位 | 字/字节 | 字/字节 | 块 | 块/多块 |
| CPU 参与 | 全程 | 传送时 | 仅开始/结束 | 几乎不 |
| 速度 | 最慢 | 较慢 | 快 | 最快 |
| 适用 | 低速简单 | 中低速 | 高速批量(磁盘) | 大型机 |

**集中式总线仲裁**：

| | 链式查询 | 计数器定时 | 独立请求 |
|------|:---:|:---:|:---:|
| 速度 | 慢 | 中 | 最快 |
| 控制线数 | 最少(3根) | 少 | 最多(N×2) |
| 优先级 | 固定(近高) | 可变 | 灵活(可编程) |
| 故障敏感 | 最敏感 | 中等 | 不敏感 |

**SRAM vs DRAM**：

| | SRAM | DRAM |
|------|:---:|:---:|
| 原理 | 触发器 | 电容 |
| 刷新 | 不需要 | 需要 |
| 速度 | 快 | 慢 |
| 掉电 | 都丢失！ | 都丢失！ |
