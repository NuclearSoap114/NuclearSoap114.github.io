## 一、考点概述

Cache与主存之间的三种映射方式：**直接映射、全相联映射、组相联映射**。常考：给主存地址格式，判断命中/替换策略。

---

<div id="section-2" class="note-anchor"></div>

## 二、三种映射方式速查

| 映射方式 | 原理 | 特点 |
|----------|------|------|
| **直接映射** | 主存块只能放到**唯一固定**的Cache行 | 简单快速，冲突率高 |
| **全相联映射** | 主存块可放到**任意**Cache行 | 灵活，冲突率低，硬件复杂 |
| **组相联映射** | Cache分组，组间直接，组内全相联 | **折中方案**，最常用 |

---

<div id="section-3" class="note-anchor"></div>

## 三、地址格式

假设 Cache 容量 C，块大小 B，组相联度 K：

**直接映射**：
```
| 标记(Tag) | 行号(Index) | 块内偏移(Offset) |
```

**全相联映射**：
```
| 标记(Tag) | 块内偏移(Offset) |
```

**K-路组相联**：
```
| 标记(Tag) | 组号(Index) | 块内偏移(Offset) |
```

<div id="section-4" class="note-anchor"></div>

### 关键公式

- Cache 总行数 = C ÷ B
- 组数 = C ÷ B ÷ K
- 块内偏移位数 = $\log_2 B$
- 组号位数 = $\log_2(\text{组数})$
- 标记位数 = 主存地址位数 − 组号位数 − 偏移位数

## 四、典型例题

> **例题**：主存容量 64KB，Cache 容量 2KB，块大小 32B。按字节编址。分别给出直接映射、全相联映射、4路组相联的地址格式。

**解析**：

```
已知:
  主存 64KB → 16位地址
  Cache 2KB → 2048B → 64个块 (2048÷32)
  块大小 32B → 块内偏移 = 5位 (2⁵=32)

（1）直接映射:
    Cache行数 = 64
    行号 = log₂(64) = 6位
    标记 = 16 - 6 - 5 = 5位
    地址格式: | 标记 5位 | 行号 6位 | 偏移 5位 |

（2）全相联:
    行号 = 0位 (无固定位置)
    标记 = 16 - 5 = 11位
    地址格式: | 标记 11位 | 偏移 5位 |

（3）4路组相联:
    组数 = 64 ÷ 4 = 16组
    组号 = log₂(16) = 4位
    标记 = 16 - 4 - 5 = 7位
    地址格式: | 标记 7位 | 组号 4位 | 偏移 5位 |
```

## 五、同类练习题

> **题目**：主存 1MB，Cache 8KB，块大小 64B，8路组相联。求地址格式（按字节编址）。

**解析**：

```
主存 1MB → 20位地址
Cache总块数 = 8KB ÷ 64B = 128块
组数 = 128 ÷ 8 = 16组
块内偏移 = log₂(64) = 6位
组号 = log₂(16) = 4位
标记 = 20 - 4 - 6 = 10位

地址格式: | 标记 10位 | 组号 4位 | 偏移 6位 |
```

> **替换策略**
> - **直接映射**：无需替换策略（位置固定）
> - **全相联/组相联**：LRU（最近最少使用）、FIFO、随机
> - 组相联中需在**组内**选择一个块替换
