## 一、考场草稿纸先默写这五组（发卷即写）

<div id="section-2" class="note-anchor"></div>

### 1. 新发展理念（五词+定位）
```
创新(第一动力-动力) 协调(内在要求-不平衡) 绿色(必要条件-人与自然)
开放(必由之路-内外联动) 共享(本质要求-公平正义)
```

<div id="section-3" class="note-anchor"></div>

### 2. 中国式现代化（五个特色+九个本质要求）
```
【五特色】大人全自和
大=人口规模巨大  人=全体人民共同富裕（★区别西方的显著标志）
全=两个文明协调  自=人与自然和谐共生  和=走和平发展道路

【九本质要求】党领导+中特+高质量+全过程民主+精神世界+
共同富裕+人与自然+人类命运共同体+文明新形态
```

<div id="section-4" class="note-anchor"></div>

### 3. 强军目标（三词+定位）
```
听党指挥(灵魂)  能打胜仗(核心)  作风优良(保证)
→ 世界一流军队
```

<div id="section-5" class="note-anchor"></div>

### 4. 总体国家安全观（五要素）
```
人以政法经军国
人民安全=宗旨  政治安全=根本(首要位置)  经济安全=基础
军事科技文化社会=保障  国际安全=依托
```

<div id="section-6" class="note-anchor"></div>

### 5. 改革总目标（两句话，缺一不可！）
```
完善和发展中国特色社会主义制度（根本方向）
+ 推进国家治理体系和治理能力现代化（时代要求）
```

## 三、"最"和"根本"速查（判断10分）

```
最本质特征/最大优势              = 中国共产党领导
最高政治领导力量                 = 中国共产党
最高原则（党的领导）              = 党中央集中统一领导
最高原则（一国两制）              = 维护国家主权、安全、发展利益
最核心（改革方向）               = 坚持和改善党的领导+坚持和完善中特制度
最根本（政治发展道路）            = 坚持党的领导
最本质特征（新发展格局）          = 高水平的自立自强
最广泛最真实最管用（民主）        = 全过程人民民主
更基础更广泛更深厚的自信          = 文化自信

根本政治立场                     = 人民立场
根本政治制度                     = 人民代表大会制度
根本领导制度                     = 党的领导制度
根本法                           = 宪法
根本保证（法治）                 = 党的领导
根本性建设（党建）               = 政治建设
基础性建设（党建）               = 思想建设
根本工作路线/生命线              = 群众路线
建军之本、强军之魂               = 党对军队的绝对领导
根本制度和根本实现形式（军队）    = 军委主席负责制
```

## 四、判断题陷阱大全

```
❌ "改革总目标是完善制度"                     → 缺后半句！
❌ "新发展格局是封闭的国内单循环"               → 是"开放的"双循环
❌ "经济体制改革是全面深化改革的唯一重点"        → 是"重点"但不是"唯一"
❌ "基本政治制度只有一个"                       → 三个！
❌ "党的领导制度是基本领导制度"                  → 是"根本"领导制度
❌ "思想建设是党的根本性建设"                   → 政治建设是根本性，思想是基础性
❌ "主要矛盾变化改变了对历史阶段的判断"          → "两个没有变"
❌ "现代化跟西方一样"                           → 五个特色，本质不同
❌ "一国和两制是并列关系"                       → 一国是前提和基础
❌ "市场起基础性作用"                           → 是"决定性"作用
❌ "高质量发展是从少到多"                       → 是从"有没有"到"好不好"
❌ "国家安全以经济安全为宗旨"                   → 以"人民安全"为宗旨
❌ "跳出历史周期率的第一个答案是自我革命"        → 第一个是毛泽东"让人民监督政府"
❌ "一带一路是地缘政治联盟"                     → 是"经济合作倡议"
❌ "协商民主和选举民主是替代关系"               → 是"相互补充、相得益彰"
```

## 📝 五、大题万能框架（60分）

<div id="section-11" class="note-anchor"></div>

### 材料分析题 → 三步走（每题25分钟）

```
① 理论定位（1-2句）→ "材料反映了XXX"
② 理论展开（3-5句）→ 框架要点+关键词
③ 结合材料（3-5句）→ "材料中...体现了..." "充分说明..."
```

<div id="section-12" class="note-anchor"></div>

### 论述题 → 四段式（30分钟）

```
一、引言：定位+重要性
二、核心展开：3-5个要点（用第一第二第三）
三、实践要求：怎么贯彻落实
四、结语：1-2句升华
```

## 🔗 六、核心关系对对碰

```
党和法            → 党的领导是法治之魂，二者一致
党和军队          → 绝对领导，建军之本强军之魂
"一国"和"两制"   → 一国是前提基础，两制派生于统一于一国之内
政府和市场        → 市场决定性作用+政府更好作用
发展和安全        → 一体两翼驱动双轮，发展=总钥匙
改革和法治        → 重大改革于法有据
依法治国和以德治国 → 规范作用+教化作用，相结合
自我革命和社会革命 → 以自我革命引领社会革命
国家治理体系和能力 → 有机整体，相辅相成
```
