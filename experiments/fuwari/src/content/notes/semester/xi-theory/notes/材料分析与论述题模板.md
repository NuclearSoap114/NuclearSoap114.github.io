## 一、材料分析题答题模板（2×20分）

<div id="section-2" class="note-anchor"></div>

### 通用三步法

```
① 理论定位 → ② 材料结合 → ③ 分析深化
```

<div id="section-3" class="note-anchor"></div>

#### 模板结构

**第一步：亮明理论（4-5分）**
- 材料反映了XXX理论/XXX思想
- 这一理论属于习近平新时代中国特色社会主义思想的XXX方面
- 其核心是......

**第二步：阐述理论（6-8分）**
- 具体展开理论内容（用总纲中的框架）
- 如果有数字框架（如"五个特色""六个坚持"），列出来
- 引用习近平讲话（如果有印象）

**第三步：结合材料分析（6-8分）**
- "材料中......体现了......"
- "材料所指的......正是......"
- "这充分说明......"
- 联系实际，适当拓展

<div id="section-4" class="note-anchor"></div>

### 高频材料类型预测

<div id="section-5" class="note-anchor"></div>

#### 类型1：高质量发展/经济类材料

> 材料特征：产业升级、科技创新、数字经济、区域协调发展、乡村振兴

**理论工具箱**：
- 新发展理念（创新/协调/绿色/开放/共享）
- 高质量发展（从"有没有"到"好不好"）
- 新发展格局（国内大循环为主体、国内国际双循环）
- 现代化经济体系（实体经济+科技创新+现代金融+人力资源）

**答题示例框架**：
```
材料反映了我国推动高质量发展的实践。高质量发展是全面建设社会主义现代化国家的首要任务。
（然后结合材料具体对应哪个理念/哪个方面进行分析）
```

<div id="section-6" class="note-anchor"></div>

#### 类型2：改革开放类材料

> 材料特征：制度改革、开放政策、自贸区、一带一路

**理论工具箱**：
- 改革开放是决定当代中国命运的关键一招
- 全面深化改革总目标（两句话）
- 三个进一步解放
- 一带一路（共商共建共享）
- 制度型开放

<div id="section-7" class="note-anchor"></div>

#### 类型3：共同富裕/人民中心材料

> 材料特征：扶贫、共同富裕、收入分配、区域协调

**理论工具箱**：
- 以人民为中心（第四章，大纲明确）
- 共同富裕是中国特色社会主义的本质要求、中国式现代化的重要特征
- 江山就是人民，人民就是江山
- 中国式现代化是全体人民共同富裕的现代化（区别于西方的显著标志）
- 三次分配

<div id="section-8" class="note-anchor"></div>

#### 类型4：生态文明材料

> 材料特征：污染治理、碳达峰碳中和、绿色转型、生态保护

**理论工具箱**：
- 绿水青山就是金山银山
- 人与自然和谐共生
- 山水林田湖草沙生命共同体
- 绿色发展是发展观的深刻革命

<div id="section-9" class="note-anchor"></div>

#### 类型5：全过程人民民主/法治材料

> 材料特征：人大制度、协商民主、立法、基层治理

**理论工具箱**：
- 全过程人民民主（最广泛最真实最管用）
- 全链条全方位全覆盖
- 党的领导+人民当家作主+依法治国有机统一
- 协商民主是独特独有独到的民主形式

<div id="section-10" class="note-anchor"></div>

#### 类型6：国家安全/军队/统一材料

> 材料特征：安全形势、一国两制、台湾问题、强军

**理论工具箱**：
- 总体国家安全观（五要素）
- 统筹发展和安全（一体两翼）
- "一国"和"两制"的关系
- 强军目标（听党指挥、能打胜仗、作风优良）

## 二、论述题答题模板（1×20分）

> **论述题特点**
> 通常是直接问某个重大理论，不需要结合材料，但需要**框架完整、逻辑清晰、有一定深度**。

<div id="section-12" class="note-anchor"></div>

### 万能答题框架

```
一、引言（2-3分）
   - 点题：XXX是习近平新时代中国特色社会主义思想的重要组成部分
   - 重要性：对于......具有重大意义

二、核心内容展开（10-12分）
   - 分3-5个要点，每个要点3-4句话
   - 用"第一...第二...第三..."或"（一）（二）（三）"
   - 每个要点：观点句 + 阐述 + 意义/作用

三、现实意义/实践要求（3-4分）
   - 对当前和今后的指导意义
   - 如何贯彻落实

四、结语（1-2分）
   - 总结升华，1-2句收尾
```

<div id="section-13" class="note-anchor"></div>

### 高频论述题预测

> **以下话题最有可能出论述题**

<div id="section-14" class="note-anchor"></div>

#### 预测1：中国式现代化的中国特色和本质要求

**框架**：
1. 引言：中国式现代化是强国建设、民族复兴的唯一正确道路
2. 五个特色（展开）：
   - 人口规模巨大
   - 全体人民共同富裕（区别于西方的显著标志）
   - 物质文明和精神文明相协调
   - 人与自然和谐共生
   - 走和平发展道路
3. 本质要求（9条，重点说前几条）
4. 重大原则（5条）
5. 意义：创造了人类文明新形态

<div id="section-15" class="note-anchor"></div>

#### 预测2：全面深化改革总目标

**框架**：
1. 总目标两句话（缺一不可）
2. "完善和发展中国特色社会主义制度"——规定了根本方向
3. "推进国家治理体系和治理能力现代化"——明确了时代要求
4. 两者关系（有机整体，相辅相成）
5. 如何推进（方法论5条）
6. 意义

<div id="section-16" class="note-anchor"></div>

#### 预测3：高质量发展/新发展理念/新发展格局

**框架**：
1. 高质量发展是首要任务
2. 新发展理念（五个，重点说各自的定位和解决的问题）
3. 新发展格局（含义、本质特征、如何构建）
4. 三者关系
5. 意义（3条）

<div id="section-17" class="note-anchor"></div>

#### 预测4：全过程人民民主

**框架**：
1. 全过程人民民主是社会主义民主政治的本质属性
2. 三个"全"（全链条、全覆盖、全方位）
3. 三个"最"（最广泛、最真实、最管用）
4. 制度体系（根本政治制度+基本政治制度）
5. 党的领导、人民当家作主、依法治国有机统一

<div id="section-18" class="note-anchor"></div>

#### 预测5：全面从严治党

**框架**：
1. 全面从严治党是新时代党的建设的鲜明主题
2. 党的建设总要求（原则、方针、主线、统领、根基、着力点、布局、重中之重、目标）
3. 以政治建设为统领（为什么政治建设摆在首位）
4. 自我革命（第二个答案）
5. 反腐败斗争

<div id="section-19" class="note-anchor"></div>

#### 预测6：总体国家安全观 / 统筹发展和安全

**框架**：
1. 国家安全是民族复兴的根基
2. 总体国家安全观五要素（宗旨、根本、基础、保障、依托）
3. 发展和安全的关系（一体两翼、驱动双轮）
4. 以新安全格局保障新发展格局

<div id="section-20" class="note-anchor"></div>

#### 预测7：人类命运共同体 / 一带一路

**框架**：
1. 当今世界正经历百年未有之大变局
2. 人类命运共同体（全人类共同价值）
3. 一带一路（共商共建共享、五通）
4. 中国始终是世界和平的建设者

## 三、拓展题应对（1×10分）

> **拓展题特点**
> 通常是开放性问题，要求联系实际、谈个人理解。

<div id="section-22" class="note-anchor"></div>

### 应对策略
- 不能脱离理论空谈 → 先点出理论依据
- 适当联系实际 → 举身边的例子、社会热点
- 体现个人思考 → 但不要偏离主流观点
- 结构：理论点出（3分）+ 联系实际分析（4分）+ 个人体会/总结（3分）

## 四、答题时间分配建议

| 题型 | 题量 | 建议时间 |
|------|------|----------|
| 单选 | 10题 | 10分钟 |
| 判断 | 5题 | 5分钟 |
| 材料分析 | 2题 | ==50分钟==（每题25分钟） |
| 论述 | 1题 | ==30分钟== |
| 拓展 | 1题 | 15分钟 |
| 检查 | - | 10分钟 |

> 总计：120分钟（2小时），留有余地。

## 五、考场速记卡

> **拿到试卷先写在草稿纸上的核心框架**
> - 新发展理念：==创协绿开共==（创新-第一动力、协调-内在要求、绿色-必要条件、开放-必由之路、共享-本质要求）
> - 中国式现代化五特色：==大人全自和==（大=人口规模巨大、人=全体人民共同富裕、全=两个文明相协调、自=人与自然和谐共生、和=走和平发展道路）
> - 强军目标：==听打得风==（听党指挥-灵魂、能打胜仗-核心、作风优良-保证）
> - 改革总目标：==完善制度+治理现代化==
> - 一带一路：==共商共建共享==（原则）→ 五通（政策、设施、贸易、资金、民心）
> - 安全观五要素：==人以政法经军国==（人民安全-宗旨、政治安全-根本、经济安全-基础、军事科技文化社会安全-保障、国际安全-依托）
