## 一、考点概述

给**磁头当前位置**和**请求柱面序列**，用不同算法计算**平均寻道长度**（磁头移动总距离 ÷ 请求数）。

---

<div id="section-2" class="note-anchor"></div>

## 二、四种调度算法

| 算法 | 全称 | 规则 | 特点 |
|------|------|------|------|
| **FCFS** | 先来先服务 | 按请求顺序服务 | 简单，性能可能很差 |
| **SSTF** | 最短寻道优先 | 选离当前磁头**最近**的 | 可能饥饿（远处永远等） |
| **SCAN** | 电梯算法 | 往一个方向走到头，再反向 | 较公平，类似电梯 |
| **C-SCAN** | 循环扫描 | 单向走到头，**跳回**起点再走 | 各位置等待时间均匀 |

---

## 三、典型例题

> **例题**：磁头初始在 50 号柱面，当前移动方向为**增大**。请求序列：82, 170, 43, 140, 24, 16, 190。分别用 FCFS、SSTF、SCAN、C-SCAN 求平均寻道长度。（假设磁盘 0~199）

<div id="section-4" class="note-anchor"></div>

### （1）FCFS

```
顺序: 50→82→170→43→140→24→16→190

移动距离:
|50-82|=32
|82-170|=88
|170-43|=127
|43-140|=97
|140-24|=116
|24-16|=8
|16-190|=174

总距离 = 32+88+127+97+116+8+174 = 642
平均寻道 = 642/7 ≈ 91.7
```

<div id="section-5" class="note-anchor"></div>

### （2）SSTF（最短寻道优先）

```
当前50, 请求: 82,170,43,140,24,16,190

最近是43(|50-43|=7), 下一个43
当前43, 最近是24(|43-24|=19)→16→82→140→170→190

顺序: 50→43→24→16→82→140→170→190

距离: |50-43|=7, |43-24|=19, |24-16|=8, |16-82|=66,
       |82-140|=58, |140-170|=30, |170-190|=20
总距离 = 7+19+8+66+58+30+20 = 208
平均寻道 = 208/7 ≈ 29.7
```

<div id="section-6" class="note-anchor"></div>

### （3）SCAN（电梯算法，初始方向增大↑）

```
方向↑, 当前50 → 走到最大199再折返

往上: 50→82→140→170→190→199（尽头）
折返: 199→43→24→16

顺序: 50→82→140→170→190→199→43→24→16

距离: 32+58+30+20+9+156+19+8 = 332
平均寻道 = 332/7 ≈ 47.4
```

<div id="section-7" class="note-anchor"></div>

### （4）C-SCAN（循环扫描，只走单方向）

```
方向↑, 50→190往上的都服务→到199后跳回0→再从0往右服务剩余的

往上: 50→82→140→170→190→199
跳回: 199→0
再往上: 0→16→24→43

顺序: 50→82→140→170→190→199→0→16→24→43

距离: 32+58+30+20+9 + 199 + 16+8+19 = 391
（跳回199→0算199，因为C-SCAN磁头要移动过去）
平均寻道 = 391/7 ≈ 55.9
```

<div id="section-8" class="note-anchor"></div>

### 结果对比

| 算法 | 总距离 | 平均寻道 |
|------|:------:|:--------:|
| FCFS | 642 | 91.7 |
| SSTF | 208 | 29.7 |
| SCAN | 332 | 47.4 |
| C-SCAN | 391 | 55.9 |

> **SSTF 平均寻道最短**，但可能造成饥饿。

## 四、同类练习题

> **题目**：磁头在 100，方向向**减小**（↓）。请求：55, 178, 92, 180, 38, 120, 15。用 SCAN 和 C-SCAN 计算平均寻道长度。（0~199）

**解析**：

**SCAN（方向↓）**：
```
往下: 100→92→55→38→15→0
折返: 0→120→178→180

顺序: 100→92→55→38→15→0→120→178→180
距离: 8+37+17+23+15+120+58+2 = 280
平均寻道 = 280/7 = 40.0
```

**C-SCAN（方向↓）**：
```
往下: 100→92→55→38→15→0
跳回: 0→199
再往下: 199→180→178→120

顺序: 100→92→55→38→15→0→199→180→178→120
距离: 8+37+17+23+15+199+19+2+58 = 378
平均寻道 = 378/7 = 54.0
```

> **得分要点**
> 1. **起始方向**要看题目给的条件
> 2. SCAN：走到**最尽头**再折返（即使尽头没有请求）
> 3. C-SCAN：走到尽头 → 跳回另一端 → 继续同方向
> 4. 磁头从 199 跳回 0，距离算 **199**（不是0）——磁头物理移动
> 5. 计算过程写清楚每段距离，便于检查
