## 从空白开始

你看到的这篇文章，是博客的交互效果演示。几个彩色光标会分工协作：铺开卡片、放入图片，再把文字一行行写下来。

页面的布局来自 **Fuwari**，光标动画为这个博客独立实现。背景、卡片和排版保留主题原本的样子，让动画结束后，阅读仍然是主角。

:::tip[试着往下滚动]
光标会跟着阅读进度，继续搭建下方内容。想直接读文章，可以随时点击底部的「跳过」。
:::

## 一起把想法搭出来

一张卡片先被画出轮廓，再填入底色。标题出现，段落接上，细小的标签也找到自己的位置。

它模拟的是一次轻松的协作过程。你不需要安装扩展，也不用登录；打开网页，就能看到这场小小的搭建。

:::note[更多光标，一起工作]
桌面上先有 18 个光标集结，工作繁忙时会陆续增援，最多 48 个；手机上会适当减少。它们会画框、输入文字、拖出参考线，也会复制已经完成的组件。这里的光标都是页面动画，不代表在线访客。
:::

### 留下适合阅读的页面

- **可以跳过**：立即显示完整页面，直接开始阅读。
- **可以重播**：回到页面顶部，再看一遍搭建过程。
- **可以调速**：在 1×、2×、3× 之间切换。
- **可以自动导览**：页面缓缓下移，光标接着搭建。

### 文字与代码

代码块也可以参与搭建。动画结束后，复制按钮仍然能够正常使用。

```javascript title="a-small-idea.js"
const idea = "把一个想法，慢慢做出来。";

function write() {
  return idea;
}
```

## 让动效适可而止

搭建完成后，光标还会短暂跟随你的鼠标。点击「开始阅读」就能收起，也可以等它们自然离场。底部的「音效」可以打开轻柔的输入和落位声音。

---

动画是一段开场，不应该成为阅读的门槛。手机上会减少光标数量；如果你的系统偏好减少动态效果，页面会直接显示完整内容。

:::important[内容始终在这里]
即使关闭 JavaScript，正文也可以正常阅读。光标动画只改变呈现过程，不负责加载文章。
:::
